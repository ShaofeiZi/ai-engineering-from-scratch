# 曲度检查器

如何验证优化问题是否曲,以及如何处理答案.

## 决策检查清单

1. 目标函数是曲的吗 (检查赫西式正面半确定性或使用组合规则).
2. 没有任何形式的不平等限制 g_i(x) <= 0 在哪里每个g_i是凸?
3. 所有平等的限制都是相对的 (线性)?
4. 如果三个都是肯定的,问题是曲的.使用曲的解决器,
5. 如果没有,问题是不凸. SGD亚当和接受当地优势.

## 如何测试函数的曲性

| 测试 | 适用于 | 方法 |
|---|---|---|
| 第二个 derivative >= 0 | 尺度函数 f ((x) | 如果 f'(x) >=0为所有 x,凸. |
| 赫西安是 PSD | 多变函数 f  | 计算H (x). 如果所有 eigenvalues >= 0 everywhere, convex. |
| 定义测试 | 任何功能 | 检查 f(tx + (1-t) y) <= t*f(x) + (1-t) *f(y) 对采样的 x,y,t. |
| 组成规则 | 组合函数 | 参见下面的组合表. |
| 限制一个线 | 多变量 f | f 是形的 g(t) = f(x + tv) is convex in t 对于所有x,v. |

## 常见 ML 目标:形还是不形?

| 目标 | 曲的? | 原因 |
|---|---|---|
| MSE总数: (1/n) 总数 | 现在 | 在w中方形,赫西亚式 = (2/n) X^T X是 PSD |
| 后勤损失:总数(log(1 + exp(-y_i * w^T x_i))) | 现在 | 曲函数的总和 (log-sum-exp家族) |
| 损失:总数 ((最大) 0,1 - y_i * w^T x_i)) | 现在 | 曲式 (线性) 函数的最大值 |
| L2 规律化:  lambda * \ 时时时时 | 现在 | 方形, Hessian = 2*lambda*I |
| L1 规律化: lambda * \ 时时时时_ | 现在 | 绝对值的总和 (形但不可分化) |
| 坡回归: MSE + L2 | 现在 | 两个曲函数的总和 |
| LASSO: MSE + L1 | 现在 | 两个曲函数的总和 |
| 弹性网: MSE + L1 + L2 | 现在 | 曲函数的总和 |
| SVM (初级):子+ L2 | 现在 | 曲函数的总和 |
| 交叉透与软max | 确实 | 记录总和exp是曲的 |
| 神经网络 (任何损失) | 没有 | 非线性激活产生非曲的组成 |
| k-指标目标 | 没有 | 微妙的分配步骤 |
| 矩阵分数: \ 时时X - UV^T\|\|^2 | 没有 | 在U和V中双线 |
| GAN 损失 | 没有 | 子中不的最小量 |
| 对比损失 (InfoNCE) | 没有 | 负样品的指数数比例记录 |

## 基于曲度的溶剂选择

| 问题类型 | 解决器 | 融合保障 |
|---|---|---|
| 形,平滑,不受限制 | 渐进下降 | 1/k) 达到全球最低值 |
| 形,平滑,不受限制 | L-BFGS | 超线性到全球最低 |
| 形,平滑,不受限制 | 牛顿的方法 | 接近最小的四方形 (如果是Hessian可处理的) |
| 形,平滑,紧缩 | 内部点方法 | 多项式时间 |
| 形,不滑 (L1) | 接近梯度 ISTA | 1/k) 达到全球最低值 |
| 形,不滑 (L1) | ADMM | 灵活的,手柄的限制 |
| 形,方形 | 结合梯度 | 在 n 步骤中确切 |
| 形不,平滑 | SGD 亚当 | 转向本地最低值 |
| 形不,平滑 | SGD + restarts | 平均地级最低水平更好 |
| 形不,平滑 | Overparameterize + SGD | 平面最小值,良好的通用化 |

## 常见的错误

- 假设问题是凸,因为损失函数是凸.你正在优化参数中损失必须是凸.横向缩在逻辑中是凸,但从输入到逻辑中整个神经网络映射是非凸.
- 通过使用牛顿的方法来解决一个非曲的问题. 赫西安可能具有负值,导致牛顿向点或最大而不是最小方向移动.
- 忘记了这一点 L1 规律化使目标在零点无法区分.标准梯度下降不起作用.使用近梯度下降或次梯度方法.
- 如果您需要解决最小平方数问题,A是不良条件的,则使用 QR 或 SVD 而不是正常的方程.
- 没有检查的问题. ML 问题 (线性模型, SVMs它们是曲的,并且受益于更强大的解决器.

## 快速测试:我的问题是曲的吗?

```
1. Write out the objective: minimize f(w) subject to constraints
2. For each term in f(w):
   - Is it quadratic with PSD matrix? -> Convex
   - Is it a norm? -> Convex
   - Is it log-sum-exp? -> Convex
   - Does it involve w nonlinearly (sigmoid(w), w1*w2)? -> Likely non-convex
3. Are all constraints linear or convex inequalities?
4. If ALL terms are convex and constraints are convex/linear -> problem is convex
5. If ANY term is non-convex -> problem is non-convex
```
