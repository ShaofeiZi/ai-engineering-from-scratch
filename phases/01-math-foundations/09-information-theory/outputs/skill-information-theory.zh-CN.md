# 信息理论 ML

什么时候使用,交叉, KL 机器学习系统的分化和互通信息.

## 决策检查清单

1. 测量单个分布中的不确定性? **化**.
2. 测量模型是否接近真实标签? **交叉** 您的分类丢失.
3. 测量两个分布之间的距离? **KL 差异性**.
4. 检查两个变量是否相连? **互通信息**.
5. 报告语言模型质量? **困难** (交叉缩的指数值).
6. 减少一个模型? **KL 差异性** 从教师到学生.

## 关键关系

```
Cross-entropy  = Entropy + KL divergence
H(P, Q)        = H(P)   + D_KL(P || Q)

Since H(P) is constant during training:
  Minimizing cross-entropy = Minimizing KL divergence

Mutual information = Entropy - Conditional entropy
I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)

Perplexity = exp(cross-entropy in nats)
           = 2^(cross-entropy in bits)
```

## 常见的错误

- 计算 KL 它们是对象的. D_KL(P||Q) != D_KL(Q||P)为了对称测量,使用詹森-尚农分离: JS = 0.5 * KL(P||M) + 0.5 * KL(Q||M) 在哪里 M = 0.5*(P+Q).
- 忘记一个热标签的交叉缩简化为 -log(p_true_class).当真正的分布是一个热时,你不需要把所有类数总结起来.
- 使用日志基础2编码,但报告NATS (或相反). PyTorch 根据原始的自然日志. log2(e) = 1.4427 转换纳斯成比特.
- 计算空或零概率事件的进化. 公约: 0 * log(0) = 0因为 lim(p->0) p*log(p) = 0.
- 对于不同词汇的模拟,一个词汇尺寸50k和30的模型与一个词汇尺寸10k和30的模型直接相比不起.
