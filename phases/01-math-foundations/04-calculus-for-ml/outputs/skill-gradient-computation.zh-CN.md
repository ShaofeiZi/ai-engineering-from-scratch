# 渐进计算 ML

对于在神经网络中使用的损失函数,激活函数和层操作的计算梯度的实际参考.

## 决策检查清单

1. 函数由简单的原始函数 (功率,exp,log, trig) 组成吗?使用分析衍生函数和链条规则.
2. 函数是个定制操作还是黑盒操作? `(f(x+h) - f(x-h)) / (2h)` 具有h=1e-7的
3. 是从子操作中构建的函数 PyTorch/JAX让Autograd处理,用数字检查查.
4. 需要一个度损失的梯度,或者一个权重矩阵吗?
5. 没有非可分辨的操作 (argmax,圆化,样本采集)?使用直径估计器或重设设法.

## 什么时候使用每种方法

| 方法 | 什么时候使用 | 成本 |
|---|---|---|
| 分析 (手工衍生) | 简单的函数,验证自动排放输出 | 运行时间免费 |
| 数字 (有限差异) | 调试,梯度检查,黑盒功能 | 对于 n 参数的 2n 前进通行 |
| 自动分化 | 任何可分化计算图 (默认) | 一个倒退的通行 |
| 象征性 (SymPy美国 | 论文的闭式梯度推导 | 仅编译时间 |

## 常见的错误

- 遗忘了批次平均损失的1/n因子 (MSE梯度根据批量大小进行扩展.
- 计算软max梯度作为向量,当它实际上是一个Jacobian矩阵.对于交叉缩 +软max相结合,梯度简化为 (p - y),从而避免了完整的Jacobian.
- 运行链条的错误顺序. dL/dW = dL/dy * dy/dW.
- 使用太大的h (h = 0.1) 或太小 (h = 1e-15) 对于数值衍生品. h = 1e-7 对于 float64.
- 忘记了这一点 ReLU 具有不定义的梯度, x = 0在实践中,设置为0或0.5.

## 测量分数的配方

```
For each parameter w:
  numeric_grad = (loss(w + h) - loss(w - h)) / (2h)
  auto_grad = backward pass value
  relative_error = |numeric - auto| / max(|numeric|, |auto|, 1e-8)
  assert relative_error < 1e-5
```

关于1e-3的相对错误意味着有什么不对.
