# 采样策略的选择

如何选择对文本生成,贝叶斯推理,蒙特卡罗估计和训练的正确样本方法.

## 决策检查清单

1. 你正在生成输出 (文字,图像) 或估计数量 (整体,预期)?
2. 您可以直接从目标分布中取样,
3. 目标分布是单独的还是连续的?
4. 样本空间的尺寸是多少?低 (< 5),中 (5-100),高 (> 100)?
5. 你需要准确的样本或接近的样本吗?
6. 需要通过采样操作的梯度吗?

## 什么时候使用每种方法

| 方法 | 什么时候使用 | 复杂性 | 确切吗? |
|---|---|---|---|
| 直接采样 | 你有了 CDF 或可以使用图书馆函数 |  () 样本 | 现在 |
| 逆转 CDF | 已知封闭形式 CDF 逆 (指数,可希) |  () 样本 | 现在 |
| Box-Muller | 需要正常的样本,没有图书馆. |  () 样本 | 现在 |
| 拒绝采样 | 能评估目标 PDF低尺寸 (1-3) | 通过/接受) 按样本 | 现在 |
| 重要性采样 | 需要的预期,而不是个体样本 | 对于n样本 | 约为 |
| 层次采样 | 蒙特卡罗估计,需要更低的变量 | 对于n样本 | 约为 |
| Metropolis-Hastings | 具有高维度,可以评估不正常密度 | O(1) per step + burn-in | 没有任何比喻 |
| 吉布斯样本 | 能从每一个条件分布中取样 |  (d) 每次全扫 | 没有任何比喻 |
| HMC/NUTS | 高维度连续,平稳密度 | O(L * d) per step | 没有任何比喻 |
| 温度采样 | LLM 文字生成,控制创造力 | 对于词形尺寸V | 其他 |
| 顶部样本 | LLM 生成,删除不太可能的代币 | O(V log k) | 其他 |
| 顶部 (核) | LLM 代码,适应性候选组 | O(V log V) | 其他 |
| 复制性 | 需要通过高斯样本采集的梯度 (VAEs) | O(d) | 现在 |
| Gumbel-Softmax | 需要梯度通过分类样本采集 | 对于k类 | 约为 |

## LLM 发电设置

| 使用情况 | 温度 | 顶部 | 顶部 | 备忘录 |
|---|---|---|---|---|
| 实际问题和答案 | 子,子,子,子,子,子 | -- | -- | 确定性,没有随机性 |
| 代码生成 | 0.2-0.5 | 0.9 | -- | 低创意,高一致性 |
| 总体的聊天 | 0.7 | 0.9 | -- | 均衡 |
| 创意写作 | 0.9-1.2 | 0.95 | -- | 更多的多样性 |
| 脑海暴风 | 1.0-1.5 | 0.95 | -- | 极多多化,可能会失去一致性 |

## MCMC 方法选择

| 财产 | Metropolis-Hastings | 吉布斯 | HMC/NUTS |
|---|---|---|---|
| 尺寸 | 任何一个 | 任何 (best < 100) | High (100+) |
| 需要条件 | 没有 | 现在 | 没有 |
| 需要梯度 | 没有 | 没有 | 现在 |
| 接受率 | 调整到23% | 总是100% | 调整到65% |
| 相关性 | 高 (随机走路) | 适度 | 低 |
| 烧伤 | 长时间 | 适度 | 短暂 |
| 最好的 | 探索,简单的模型 | 联合模型,贝叶斯网络 | 连续后面,深度概率模型 |

## 常见的错误

- 通过高维度的拒绝样本采集. 接受率随维度而下降. MCMC.
- 设置 MCMC 太高:大多数提案被拒绝,链接住.太低:所有提案被接受,链接缓慢移动. 目标 ~23%随机步行的接受 MH.
- 首先,我们从"N"中得到了 MCMC 排斥至少1000步 (或更多的复杂分布).
- 采用与目标非常不同的建议的重要样本采集. 少数样本获得了巨大的重量,使得估计不可靠. 监测有效的样本大小: ESS 总数是:
- 使用 temperature > 0 对于需要确定性输出 (例如分类,结构化提取) 的任务.T=0) 或是光束搜索.
- 没有将顶部p与温度结合. 单独的温度不会从长尾中清除垃圾代币.
- 通过标准采样操作向后扩散. 使用连续 (高斯) 和分离 (类) 的Gumbel-Softmax重设方法.

## 快速参考:变异减小技术

| 技术 | 如何运行 | 变量减少 |
|---|---|---|
| 层次采样 | 分开空间成层,每层取样 | Always <= standard MC |
| 异质变体 | 使用U和1-U | 适用于单调函数 |
| 控制变化 | 减去已知平均变量 | 与相关性相对 |
| 重要性采样 | 改量样本来自更好的提案 | 根据提案质量 |
| 拉丁语超立方体 | 单独地层每个维度 | 在高d中更好于分层 |
