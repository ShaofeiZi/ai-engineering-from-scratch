# Phase 14：智能体工程

> 现代 AI 工程的核心。从第一性原理出发构建智能体。

## 在 GitHub 上开始本阶段

**前置条件：**Phase 11 LLM 工程和 Phase 13 工具与协议。

**第一课：**[智能体循环](01-the-agent-loop/)

当你不需要完整阶段时，可以使用两条聚焦路线：

- [智能体辅助工程](../../learning-paths/using-coding-agents.json)涵盖任务框定、仓库证据、测试套件、隔离、验证、审查和持久反馈。
- [产品判断与交付](../../learning-paths/shaping-the-build.json)涵盖成果、工作流发现、假设、切片、规格、指标、分阶段发布和反馈归属。

从仓库根目录运行此命令：

```bash
python3 phases/14-agent-engineering/01-the-agent-loop/code/main.py
```

保留命令、退出码、思考-行动-观察轨迹、最终答案、
轮次数以及结束本次运行的确切停止条件。

**下一步：**修改脚本化任务或轮次预算，预测其影响，
然后继续学习 [ReWOO 与 Plan-and-Execute](02-rewoo-plan-and-execute/)。
