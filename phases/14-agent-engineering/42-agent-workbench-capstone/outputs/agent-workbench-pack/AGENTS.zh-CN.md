# AGENTS.md

你正在一个运行着智能体工作台的仓库中工作。

在行动之前先阅读以下文件：

1. `agent_state.json` — 上次会话停止的位置。
2. `task_board.json` — 正在进行什么、接下来是什么。
3. `docs/agent-rules.md` — 启动、禁止事项、完成、不确定性、审批。
4. `docs/reliability-policy.md` — 此工作台设计旨在吸收的故障模式。
5. `docs/handoff-protocol.md` — 会话结束时必须产出的内容。
6. `docs/reviewer-rubric.md` — 已完成工作如何被评判。

验证命令：见看板中活跃任务的 `acceptance_criteria`。

Pack version: 1.0.0
