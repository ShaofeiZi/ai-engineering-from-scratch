给定任务（语言、可用参考音频长度、适配预算、许可约束、同意状态、部署规模），输出：

1. 方案。零样本克隆（F5-TTS / VibeVoice / Orpheus / OpenVoice V2）· 语音转换（kNN-VC / OpenVoice V2 音色转换）· 说话人适配（XTTS v2 + LoRA / VITS 全量微调）。
2. 参考音频准备。所需时长、信噪比（≥ 20 dB）、单声道 16 kHz 以上、静音裁剪、`ref_text`（F5-TTS 要求完全匹配）。拒绝带有背景音乐的参考音频。
3. 同意凭证。来自声音所有者的明确录音同意。模板包含：姓名 + 日期 + 用途 + 范围 + 撤销流程。保存 7 年以上。
4. 水印。在每个输出中嵌入 AudioSeal 16 位负载。在 CI 中配置检测器，在发布音频前验证水印是否存在。
5. 安全过滤器。命名实体（名人 / 政客 / 未成年人）提示词拒绝；按用户按小时限流；每次克隆生成均记入审计日志；配备熔断开关。

若无水印策略，拒绝交付克隆功能。无论声明何种同意，拒绝克隆具名名人 / 政客 / 未成年人。拒绝时长低于 3 秒或信噪比 &lt; 20 dB 的参考音频。商业部署拒绝使用 F5-TTS（CC-BY-NC）。跨语言克隆必须明确标注口音迁移的差距，否则拒绝执行。

示例输入："无障碍应用：让 ALS 患者在尚能说话时录制并保存自己的声音，待失声后通过 TTS 重新发声。英语，美国。"

示例输出：
- 方案：OpenVoice V2（MIT 许可，零样本，6 秒参考音频）。无障碍场景，同意关系天然成立；患者本人即声音所有者。
- 参考音频准备：在录音棚级条件（安静房间、USB 麦克风、24 kHz）下录制 5 段 6 秒音频片段。保存原始录音与文字稿。构建质心参考以提升稳定性。
- 同意：数字签名 + 视频确认，声明用途（"诊断后声音再利用"），存储于加密卷并保留 10 年。设置撤销热线。
- 水印：AudioSeal 16 位负载编码 `patient_id` + `clip_id`；CI 中对每次生成都运行检测器。
- 安全：硬过滤命名实体提示词；记录每次生成；使用范围限定在患者已登录的应用实例内，不开放 API。
