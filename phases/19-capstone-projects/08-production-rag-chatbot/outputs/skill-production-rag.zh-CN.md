给定一个受监管领域的语料库（法律合同、临床试验方案、保险条款或类似内容），部署一个聊天机器人，能够以可验证的引用回答问题，遵守角色和司法管辖区访问策略，并接受漂移监控。

构建计划：

1. 使用 docling 或 Unstructured 解析语料库；将视觉富文档路由至 ColPali。输出带有角色和司法管辖区标签的文本块。
2. 将稠密向量（Voyage-3 或 Nomic-embed-v2）索引入 pgvector + pgvectorscale；稀疏 BM25 通过 Tantivy 实现。
3. 编排 LangGraph 对话智能体：检索（按角色 + 司法管辖区过滤，稠密+BM25 混合，倒数排名融合），重排（bge-reranker-v2-gemma-2b 或 Voyage rerank-2），生成（Claude Sonnet 4.7，启用提示词缓存）。
4. 使用稳定前缀组装提示词：系统序言 -> 策略块 -> 重排后上下文 -> 用户查询。目标提示词缓存命中率 60-80%。
5. 安全护栏：输入和输出侧部署 Llama Guard 4，NeMo Guardrails v0.12 用于域外和策略禁止问题，输出侧 Presidio PII 清洗，引用强制后置过滤。
6. 构建一个 200 题专家标注黄金集，包含（答案，引用）。评分维度：精确引用匹配、答案正确性、RAGAS 忠实度。
7. 构建一个 50 条提示词的红队（PAIR、TAP、PII 提取、域外、跨司法管辖区探测）。
8. Arize Phoenix 漂移看板，每周追踪检索 nDCG 和引用忠实度；下降 5% 时告警。
9. Langfuse 成本报告：提示词缓存命中率、每查询 token 数、各阶段 $/query。

评分标准：

| 权重 | 评估维度 | 测量方式 |
|:-:|---|---|
| 25 | RAGAS 忠实度 + 答案相关性 | 200 题黄金集上的在线评分 |
| 20 | 引用正确性 | 答案中具有可验证来源锚点的比例 |
| 20 | 安全护栏覆盖率 | Llama Guard 4 通过率 + 越狱套件结果 |
| 20 | 成本 / 延迟工程 | 提示词缓存命中率、p95 延迟、$/query |
| 15 | 漂移监控看板 | 实时 Phoenix 看板，含每周检索质量趋势 |

一票否决项：

- 任何泄漏跨司法管辖区数据的聊天机器人。角色+司法管辖区过滤必须在检索之前强制执行，而非之后。
- 破坏缓存前缀的生成提示词（在系统和上下文之间重排策略块）。这将摧毁缓存经济性。
- 未记录红队运行的安全护栏配置。
- 无引用的答案；无可验证锚点的引用。

拒绝规则：

- 拒绝在受监管领域中部署未对每个文本块标注司法管辖区标签的系统。
- 拒绝在专家标注黄金集问题上训练检索。数据污染会摧毁评估可信度。
- 拒绝在 README 中未提供明确的 SOC2/HIPAA/GDPR 适用性矩阵的情况下声称"合规"。

交付物：一个仓库，包含数据摄取流水线、LangGraph 对话智能体、200 题黄金集、50 条提示词红队、Phoenix 漂移看板、Langfuse 成本看板，以及一篇报告你观察到的三种最常见的引用断裂模式及其对应检索或提示词修复方案的文章。
