# 第 19 阶段：毕业项目

> 用实践证明你所学到的一切。构建可入作品集的系统。

## 在 GitHub 上开始本阶段

**前置条件：** 选择一个项目，并确保你已完成该项目列出的前置阶段。
终端原生编码智能体要求完成第 11、13、14、15 和 17 阶段。

**入门项目：** [终端原生编码智能体](01-terminal-native-coding-agent/)

在仓库根目录运行以下命令：

```bash
python3 phases/19-capstone-projects/01-terminal-native-coding-agent/code/main.py
```

保留命令、退出码、最终计划状态、预算总计、追踪事件，
以及在接入真实模型之前你会更改的架构决策。

**下一步操作：** 从[完整的第 19 阶段项目列表](../../README.md#phase-19)中选择与你目标匹配的毕业项目。
项目是可选项，而非必须按数字顺序完成。在构建之前先编写验收标准。

使用[跨阶段路线图](../../ROADMAP.md)来弥补任何前置知识缺口。
