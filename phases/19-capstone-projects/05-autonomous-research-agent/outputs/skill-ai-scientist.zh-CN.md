给定一个种子想法、一个狭窄领域和 30 美元计算预算，构建一个智能体，运行实验树搜索，撰写可评审的 LaTeX 论文，并生成可复现性包。

构建计划：

1. 文献调研：Semantic Scholar Graph API + OpenAlex；将摘要缓存在 FAISS 中；生成一页领域摘要。
2. 树搜索：对实验节点实现最佳优先扩展，`expand(node) -> children`（每个子节点一次配置编辑），`score(node) = novelty*0.4 + quality*0.5 + budget*0.1`。
3. 逐节点沙箱：每个实验运行 `docker run --network=none --memory=8g --cpus=2 --pids-limit=256 --read-only` 或 E2B 等价方案；确定性种子；强制资源上限。
4. 规划-执行-验证：验证步骤检查损失是否收敛、基准是否运行、消融是否隔离了声明。
5. 撰写器：生成 LaTeX，编译为 PDF，将 PDF 交给 Claude Opus 4.7 视觉模式进行布局和声明-证据对齐评审，最多迭代 3 次。
6. 评审者群体：五位评委（Opus 4.7、GPT-5.4、Gemini 3 Pro、DeepSeek R1、Qwen3-Max）按 NeurIPS 评分标准（新颖性、严谨性、清晰度、可复现性、影响力）评分；均值 < 4.0 则退回撰写器。
7. 红队：集成对抗任务（fork 炸弹、文件系统逃逸、LLM 编写的网络调用）。确认全部被阻止。生成 `red_team.md`。
8. 可复现性包：paper.pdf + review.md + 树搜索轨迹 JSON + 种子 + W&B 运行链接 + 沙箱配置 + 一行重跑命令。

评估标准：

| 权重 | 标准 | 测量方式 |
|:-:|---|---|
| 25 | 论文质量 | 针对同一种子主题的已发表研讨会论文进行盲评评分 |
| 20 | 实验严谨性 | 基准、种子、消融；每个声明都有结果表中的一个单元格支撑 |
| 20 | 成本与计算纪律 | 每篇论文 30 美元上限强制执行，Langfuse 追踪 |
| 20 | 安全性 | 沙箱红队通过；网络策略和紧急停止经记录的攻击尝试验证 |
| 15 | 可复现性 | 一行命令重跑以相同种子复现论文 |

硬性否决项：

- 在沙箱外运行的实验。本毕业项目的核心论点是执行被隔离。
- 不重新阅读编译 PDF 的撰写步骤（视觉评审是承重环节）。
- 没有基准、种子或消融部分的论文。
- 成本预算仅作为事后警告而非硬上限执行。

拒绝规则：

- 拒绝在评审者均值低于 4.0/5 且无明确人工覆盖的情况下发布论文。
- 拒绝在需要从沙箱内部访问网络的种子想法上运行。改为添加单独的只读数据卷。
- 拒绝重跑红队未执行且未记录的论文。

输出：一个仓库，包含树搜索引擎、沙箱策略、撰写器/评审者循环、三个带可复现性包的示例运行、一份红队报告、一份成本台账 csv，以及一份书面报告，说明你复现了哪些 Sakana v2 失败模式以及缓解措施如何奏效。
