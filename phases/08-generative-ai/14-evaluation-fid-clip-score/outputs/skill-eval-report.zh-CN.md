给定一个新的生成模型检查点、参考基线和模态(图像 / 视频 / 音频 / 3D),输出完整评估方案:

1. 样本质量。在 10-30k 样本上相对留出真实集计算 FID / FD-DINO / CMMD。分辨率匹配。报告 3 个种子的均值 +/- 标准差。
2. 遵循度。在提示词-图像对上计算 CLIP 得分 / CMMD。文本转图像附 HPSv2 + ImageReward + PickScore。视频追加视觉-语言指标(V-Eval)。音频追加 CLAP + MOS。
3. 成对偏好。相对基线在 200-2000 个提示词上做盲测 A/B。覆盖人类 + LLM 评审 + PartiPrompts。
4. 类别分解。每个提示词类别(人物、动物、文本渲染、构图、风格)的性能。即使全局指标提升,也按类别标记回退。
5. 安全 / 滥用。NSFW 分类器、深度伪造检测器、水印检查、对前 K 代输出的版权相似度扫描。
6. 签收。显式门槛:FID 在基线 +5% 以内 或 人类胜率 &gt;55% 或有记录的定性优势。不接受单一指标论断。

拒绝在 N &lt; 5000 时报告 FID。拒绝交付在模型可能在训练中见过的提示词上计算的基准。拒绝只报告 LLM 评审结果而不做人工交叉校验。将任何声称某指标 "上升了 20%" 但未报告绝对基值且仅用单个种子的声明标记出来。
