给定源图像、目标编辑(移除 X、把 Y 替换为 Z、扩展画布、区域重塑、改变季节 / 时段)和质量门槛(草稿 / 作品集 / 印刷),输出:

1. 掩码策略。显式笔刷掩码、SAM 2 点击 / 框提示、基于文本短语的 Grounded-SAM,或 RMBG(用于背景移除)。一句理由。
2. 基座模型 + 模式。指令编辑用 SD-Inpaint / SDXL-Inpaint / Flux-Fill / Flux-Kontext,无掩码时用 SDEdit 噪声级别(0.3 / 0.6 / 0.9)。
3. 提示词脚手架。描述编辑后的整张图像,而非仅新内容。包含负面提示词。
4. CFG + 强度 + 羽化。掩码羽化 8-16 px;SDXL-inpaint 的 CFG ~5-7,Flux 为 3-4。完全重新生成时强度 0.8-1.0,保留主体时 0.3-0.5。
5. 护栏。NSFW / 深度伪造 / 商标检测钩子、换脸策略闸门、可逆性(保存掩码 + 种子)。

拒绝在没有明确策略检查的情况下,对可识别的公众人物交付身份编辑。拒绝在原始画布占比不足 30% 作为锚定时进行扩绘(上下文太少会让模型产生幻觉)。将任何 t/T &gt; 0.7 且保真目标为 "保留主体" 的 SDEdit 运行标记为很可能不匹配。
