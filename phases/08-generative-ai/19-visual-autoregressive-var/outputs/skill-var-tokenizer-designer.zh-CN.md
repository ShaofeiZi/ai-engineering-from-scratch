给定图像目标(分辨率、通道数、彩色还是灰度、数据集大小、下游 LM 算力预算、目标 FID),输出:

1. 尺度调度。列出从 1x1 到 (H/p) x (W/p) 的 K 个分辨率层级。256x256 默认 10 个尺度,512x512 默认 14 个。结合 LM 有效序列长度(各尺度面积之和)和每轮尺度内并行预算来论证 K。
2. 码本。所有尺度共用单一码本,大小 V(典型 4096 / 8192 / 16384)。依据数据集大小和解码器容量选择 V。确认在校准批次上码本利用率保持在 50% 以上,否则缩小 V。
3. 残差共享。确认尺度 1..K 通过求和的上采样嵌入重建潜在向量(残差 VQ)。声明 patch 大小 p 和 VAE 主干(VQGAN 式判别器开 / 关、感知损失权重)。
4. 解码器。将求和后的潜在向量映射回像素的 VAE 解码器。从 VQGAN 解码器、VAR 论文解码器或更轻量的 MAGVIT 式解码器中选择。依据 FID 目标和解码器 VRAM 论证。
5. 位置嵌入。确认 (scale_index, row, col) 三元组,每个尺度一个学习嵌入,尺度内用 2D 正弦-余弦。拒绝扁平 1D 位置;LM 需要尺度标签来施加正确的条件。

拒绝为 VAR 使用非残差多尺度分词器。没有求和残差,下一尺度的条件将无法定义,且 LM 优化的目标与论文所证不同。拒绝为每个尺度单独设码本,除非 V 已针对较小尺度的像素数进行校准并缓解了码本塌陷。当 K x 平均尺度面积超过 LM 最大序列长度减去文本条件预留余量时,拒绝使用下一尺度预测。

示例输入:"ImageNet 类条件 256x256,数据集 1.2M,LM 预算 1.5B 参数,目标 FID 低于 5.0。"

示例输出:
- 尺度调度:K=10,尺寸 1、2、3、4、5、6、8、10、13、16。总 token 数 671。
- 码本:共享,V=4096。在 256 的 ImageNet 上预期利用率 70-80%。
- 残差共享:确认;p=16,VQGAN 主干含感知 + 对抗损失,残差求和重建 f。
- 解码器:VQGAN 解码器,4 个上采样块,无额外精修器。
- 位置嵌入:(scale, row, col) 三元组,学习尺度 token + 尺度内 2D 正弦-余弦。
