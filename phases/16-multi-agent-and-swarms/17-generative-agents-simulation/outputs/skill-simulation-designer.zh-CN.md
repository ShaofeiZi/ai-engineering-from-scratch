给定一个需要智能体群体产生涌现行为的场景（社会仿真、游戏 NPC、政策预演、市场动态），设计该仿真。

需产出：

1. **群体规模与异构性。** N 个智能体；哪些共享基础模型、哪些不同；提示族；角色分布。Smallville 使用了 25 个同质智能体配以个性化人设；更大群体受益于异构性。
2. **记忆模式。** 每条目字段：`(ts, kind, content, importance, embedding_ref, source_ids)`。近因衰减常数；重要性评分流程；相关度指标（与嵌入模型 X 的余弦相似度）。压缩的留存策略。
3. **反思节奏。** 触发条件：未处理重要性之和 > 阈值，或每 N 条观察，或周期性 tick。每次触发的反思数量。反思提示模板。
4. **规划周期。** 日 / 小时 / 动作层级。哪些是强制的、哪些可选。修订触发：一条新的重要性 > 阈值的观察与当前计划矛盾。
5. **世界模型。** 空间网格、社交图谱、资源约束。什么构成一次观察（视线范围、对话、通知）。架构无法学习且必须显式编码的规范约束有哪些（容量限制、营业时间、私密空间）。
6. **种子目标。** 哪些智能体被赋予哪些优先级。可能竞争的重叠目标；应共存的非竞争目标。
7. **预算。** 每个智能体每 tick 的 LLM 调用（观察 + 检索 + 反思 + 规划 + 行动）。每 tick 每智能体预期 token 数。T 个 tick 的总仿真成本。
8. **评估指标。** 可信度（人工评分）、目标达成率、协调事件计数、空间规范违反作为失败信号。

硬性否决条件：

- 没有显式空间/社会规范编码的设计。架构会违反它们（来自 Park 2023 的关门商店、单人卫生间失败）。
- 具有可变记忆的设计。记忆必须仅追加；更正是新条目。
- 每 tick 都运行反思的设计。这预算效率低；反思成本高，触发应基于阈值。
- 大规模 N（> 50）下无记忆压缩策略的仿真。检索成本随流长度增长。

拒绝规则：

- 若场景需要的是涌现式*任务执行*而非涌现式*社会行为*，建议改用 supervisor / roles / primitives 模式（第 16 阶段 · 05-08）。Smallville 用于社会仿真。
- 若预算允许每 tick 总计 < 100 次 LLM 调用，建议 N = 3-5 配以密集交互，而非更大群体。
- 若场景不受益于涌现（脚本化任务），建议单智能体 + 工具。

输出：一份一页设计简报。以单句总结开头（"Smallville 风格仿真：15 个异构智能体，重要性之和 > 120 时反思，3 层规划周期，带容量约束的空间网格，以可信度 + 协调事件衡量。"），然后是上述八个部分。以预期涌现行为和前三个需警惕的失败模式结尾。
