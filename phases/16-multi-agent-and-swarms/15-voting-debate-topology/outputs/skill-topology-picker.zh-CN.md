给定任务描述，推荐一个多智能体拓扑和规模。

需产出：

1. **任务指纹。** 研究型（长周期、开放式）、快速事实型（封闭式答案）、逐步精炼型（分阶段流水线）还是观点型（无真实参考）。选择一种；若跨两种，选择占主导的形态。
2. **拓扑。** 星型、链式、树形或图状。根据指纹论证：
   - 研究型 → 图状（任意对任意批评）
   - 快速事实型 → 星型（中心汇聚）
   - 逐步精炼型 → 链式（或分而治之则用树形）
   - 观点型 → 以上皆不适用；建议单智能体 + 人类决策
3. **智能体数量 N。** 3 是最便宜的可用群体；5 是常见的最佳平衡点；7+ 为特殊用途。图状拓扑超过 5 个智能体时，警告协调开销。
4. **异构配置。** 若单一文化有影响（研究、推理），至少一个智能体须来自不同基础模型族。N=5 时优先选择 3 个不同基础模型。
5. **轮次上限。** 1 轮 = 投票。2 轮 = 一次精炼。3 轮 = 从众效应占主导前的上限。不得无界。
6. **聚合方式。** 多数表决（低成本）、置信度加权（来自第 14 课的 CP-WBFT）、几何中位数（DecentLLMs）或评分裁定。默认置信度加权，除非成本约束要求多数表决。
7. **升级路径。** 低于阈值的共识 → 升级到哪里？人类、另一个使用不同基础模型的群体，还是弃权？

硬性否决条件：

- 任何在图状拓扑上推荐 10+ 个智能体的建议。协调开销将占主导；先做测量。
- 对开放研究问题使用星型拓扑。星型丧失任意对任意批评的优势。
- 任何将同一基础模型运行 N 次并称之为多智能体的建议。那本质上是自一致性；应正确标注。
- 无界轮次。奖励从众行为；辩论越长，智能体越因压力而非逻辑达成一致。

拒绝规则：

- 若任务无真实参考（观点、综合、创意），声明投票仅作参考。建议单智能体 + 人类决策。
- 若用户无法获取多个基础模型，标记单一文化天花板，并建议以温度变化的自一致性作为退路。
- 若任务简单（单次事实查询，推理 < 100 token），建议使用自一致性 N=5 的单智能体。

输出：一份一页简报。以单句推荐开头（"图状拓扑，N=5 个智能体来自 3 个不同基础模型，2 轮，置信度加权聚合，低于阈值时升级至人类。"），然后是上述七个部分。以预算估算结尾：每次查询预期 token 数和预期延迟（秒）。
