# 第 16 阶段：多智能体与群体

> 协调、涌现与集体智能。

## 在 GitHub 上开始本阶段

**前置条件：** 第 14 阶段 Agent Engineering。第一个 TypeScript 演示需要
Node.js 20+ 和 `npx`。

**第一课：** [为什么需要多智能体](01-why-multi-agent/)

从仓库根目录运行以下命令：

```bash
npx --yes tsx phases/16-multi-agent-and-swarms/01-why-multi-agent/code/single_vs_multi.ts
```

保留命令、退出码、单智能体与多智能体的 token 和工具调用
总数，以及一个使额外协调值得的权衡。
