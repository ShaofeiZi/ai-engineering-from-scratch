# 特征选择策略

选择和应用正确的特征选择方法的快速参考。

## 第 1 步：从清理开始

在应用任何方法之前，删除明显无用的特征：

- **恒定特征**：方差 = 0。删除它们。
- **接近恒定的特征**：方差 < 0.01（或您的阈值）。删除它们。
- **重复特征**：相同的列。留下一个，剩下的扔掉。
- **ID 列**：每行唯一，不携带可概括的信息。删除它们。

这需要几秒钟的时间，并且可以消除杂乱的现实数据集中 10-30% 的特征。

## 第二步：根据自己的情况选择方法

### 快速决策树

1. **< 50 个特征？** 从互信息排名开始。保留上K。
2. **50 - 500 个特征？** 如果使用线性模型，则首先使用方差阈值，然后使用 L1 (Lasso)，或者如果使用树，则使用树重要性。
3. **> 500 个特征？** 链式方法：方差阈值 -> 互信息过滤器（前 50%） -> 对幸存者进行 RFE。
4. **需要可解释性？** L1 正则化为您提供精确的零/非零。树的重要性给出了排名分数。
5. **需要捕获非线性关系？** 互信息或基于树的重要性。避免 L1（仅限线性）。
6. **需要功能交互？** RFE 或基于树的重要性。过滤方法会错过交互。

### 方法参考

|方法|何时使用 |何时避免 |
|--------|------------|----------------|
|方差阈值 |始终作为第一步 |永远不要跳过这个 |
|互信息 |快速排名，非线性关系|当您需要功能交互检测时 |
| RFE |彻底的选择，适度的特征数量 |非常昂贵的型号，> 1000 个功能 |
| L1 / 套索 |线性模型，快速嵌入选择|非线性问题，高度相关的特征 |
|树的重要性|非线性关系、特征交互 |高基数特征的偏差 |
|排列重要性 |与模型无关的验证，最终检查 |初步筛选速度太慢 |

## 第 3 步：验证您的选择

- 比较所选特征与所有特征的模型性能
- 使用交叉验证，而不是单个训练/测试分割
- 如果性能下降超过 1-2%，您可能已经删除了有用的功能
- 如果性能提高，则说明您已成功消除噪音

## 步骤 4：处理常见陷阱

### 相关功能
- L1 从相关组中任意选择一个，并将其他组归零
- 首先计算相关矩阵并决定保留哪些相关特征
- 树的重要性将重要性分散到相关特征上

### 数据泄露
- 仅根据训练数据拟合特征选择
- 对测试数据应用相同的选择
- 在交叉验证中，特征选择必须在每个折叠内进行

### 过拟合to 特征选择
- 迭代次数过多的 RFE 可能会过度拟合训练集
- 验证保留的数据，而不是用于选择的数据
- 使用稳定性选择（在子样本上重复）以获得更可靠的结果

## 步骤 5：生产清单

- [ ] 方差阈值用作第一个过滤器
- [ ] 特征选择仅适用于训练数据
- [ ] 记录选定的功能（名称、使用的方法、分数）
- [ ] 性能比较：选定的功能与所有功能
- [ ] 交叉验证，而非单次评估
- [ ] 特征选择集成到训练管道中（不是手动完成）
- [ ] 监控功能漂移（所选功能可能会变得过时）
