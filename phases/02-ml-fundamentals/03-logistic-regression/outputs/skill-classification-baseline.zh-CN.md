# 分类基线指南

在尝试复杂模型之前，请使用逻辑回归建立基线。它可以在几秒钟内完成训练，产生概率，并且是完全可解释的。数量惊人的现实世界问题根本不需要更奇特的东西。

## 决策清单

1. 决策边界可能是线性的吗？
   - 是的：逻辑回归可能就足够了
   - 否：您仍然希望将其作为衡量改进的基准

2.你有多少功能？
   - 50 岁以下：标准逻辑回归效果良好
   - 50 到 10,000：添加 L2 正则化（Ridge）
   - 超过 10,000 个（例如 TF-IDF 文本特征）：使用 L1 正则化 (Lasso) 或 LinearSVC

3. 数据集是否不平衡？
   - 比例低于 5:1：无需调整可能没问题
   - 5:1 到 50:1：在 sklearn 中使用 `class_weight="balanced"`
   - 超过 50:1：将类别权重与适当的指标（精确率、召回率或 F1）相结合

4. 特征是否具有不同的尺度？
   - 始终在逻辑回归之前进行标准化。它使用基于梯度的优化，未缩放的特征会减慢收敛速度或扭曲决策边界。

5. 是否存在缺失值？
   - 拟合前进行估算。逻辑回归无法处理 NaN。
   - 对数字列使用中值插补，对分类使用模式。

## 当逻辑回归足够好时

- 具有大部分线性特征关系的二元分类
- 你需要概率输出（不仅仅是类标签）
- 需要可解释性（系数表示标准化后特征重要性方向和相对大小）
- 训练数据很小（数百到数千个样本）
- 您需要一个用于实时服务的快速模型（推理时的单点积）
- 监管或合规要求需要可解释性

## 何时升级

- 准确度远低于目标，并且您已尝试过特征工程
- 特征和目标之间的关系明显是非线性的（检查残差图）
- 您有大量表格数据（10k+ 行）：尝试梯度增强（XGBoost 或 LightGBM）
- 特征具有多项式特征无法捕获的复杂交互作用
- 您有图像、文本或序列数据：原始输入的逻辑回归将不起作用

## 分类基线的预处理步骤

1. **在任何预处理之前首先进行训练/测试分割**。这可以防止数据泄露。
2. **处理缺失值**：中值插补数值，众数插补校准类别。
3. **编码分类**：低基数（​​低于 10 个值）的单热，较高基数的目标编码。仅在训练折叠上拟合目标编码（使用折叠外编码以防止泄漏）。
4. **尺度数字**：StandardScaler（零均值，单位方差）。适合火车，改造两者。
5. **拟合逻辑回归** wi`C=1.0`（默认正则化）。
6. **评估**：混淆矩阵、精度、召回率、F1。不仅仅是准确性。
7. **调整阈值**：默认 0.5 很少是最佳值。扫描 0.1 到 0.9，然后选择与您的精确度/召回率优先级相匹配的阈值。

## 常见错误

- 仅评估不平衡数据的准确性（预测多数类别得分高但无用的模型）
- 忘记缩放特征（具有未缩放特征的逻辑回归训练缓慢并收敛到更差的解决方案）
- 使用测试集调整决策阈值（使用验证或交叉验证）
- 跳过基线并直接跳到 XGBoost（你失去了可解释性并且没有参考点）
- 不检查多重共线性（高度相关的特征会增加系数方差）
