# 集成方法选择指南

集成结合了多个模型，可以产生比任何单个模型更好的预测。问题始终是：哪种类型、何时？

## 决策清单

1. 你们当前模型的主要问题是什么？
   - 高方差（过度拟合）：使用装袋（随机森林）
   - 高偏差（欠拟合）：使用Boosting（Gradient Boosting、XGBoost）
   - 两者兼而有之，或者您想要最大的准确性：使用堆叠

2.你有多少数据？
   - 1,000 行以下：随机森林（稳健、不易配置错误）
   - 1,000 到 100,000：XGBoost 或 LightGBM（表格总体最佳）
   - 超过 100,000：LightGBM（最快的梯度提升，可以很好地处理大数据）

3. 您可以投入多少调优时间？
   - 最小：默认的随机森林（几乎总是有效）
   - 中等：XGBoost，learning_rate=0.1，通过提前停止调整 n_estimators
   - 最大值：带有贝叶斯超参数搜索的 LightGBM 或 XGBoost

4. 你需要可解释性吗？
   - 是：单个决策树或具有特征重要性的小型随机森林
   - 部分：使用 SHAP 值进行梯度提升
   - 否：堆叠或深度集成

5. 数据是否有噪音，有很多异常值？
   - 是：随机森林（装袋对噪声具有鲁棒性）
   - 否：梯度提升（可以进一步提高干净数据的准确性）

## 何时使用每种方法

**随机森林（Bagging）**：您安全的第一选择。根据引导样本和平均值训练许多树。减少方差而不增加偏差。几乎不可能对中等数据进行过度拟合。需要最少的调整：设置 n_estimators=100-500 并保留默认值。

**AdaBoost**：通过样本重新加权进行顺序提升。与简单的基础学习器（决策树桩）配合良好。对异常值和噪声标签敏感，因为它会增加错误分类点的权重。在实践中很大程度上被梯度提升所取代。

**梯度提升**：将每棵新树与迄今为止集成的残差相匹配。减少偏见。适用于表格数据的最强大方法。需要调整：learning_rate、n_estimators、max_depth、min_child_weight、subsample。

**XGBoost**：具有正则化、二阶优化和系统级加速的梯度提升。本机处理缺失值。 Kaggle 竞赛和表格数据生产 ML 的默认设置。

**LightGBM**：通过叶方向生长（而不是水平方向）进行梯度增强。在大型数据集上比 XGBoost 更快。使用基于直方图的分割。最适合超过 50k 行的数据集。

**CatBoost**：使用本机分类特征处理进行梯度提升。无需进行one-hot 编码。当你有很多分类特征时很好。

**堆叠**：训练元学习器对多个不同基础模型的预测。当您需要绝对最佳精度并具有计算能力时使用备用。始终通过交叉验证生成基本模型预测，以避免泄漏。

**投票**：最简单的集成。硬投票（多数类别）或软投票（平均概率）。无需元学习器即可快速组合 2-3 个不同模型的方法。

## 常见错误

- 使用梯度提升而不提前停止（如果让它运行太多轮，它会过度拟合）
- 将learning_rate设置得太高（高于0.3通常会导致不稳定）
- 不调整 max_depth 进行梯度提升（默认无限或非常深的树过度拟合）
- 与所有相同类型的模型堆叠（多样性是堆叠的重点）
- 在噪声数据上使用 AdaBoost（每轮异常值的权重越来越高）
- 期望随机森林修复欠拟合（它减少方差，而不是偏差）

## 通过方法调整优先级

**随机森林：**
1. n_estimators：100-500（更多很少会更糟，只是更慢）
2. max_深度：无（让树木充分生长）或上限为 10-20 以提高速度
3. max_features：“sqrt”用于分类，“log2”或n/3用于回归

**XGBoost / LightGBM：**
1.learning_rate：0.01-0.3（如果您有更多树的计算，则越低越好）
2. n_estimators：在验证集上使用提前停止而不是猜测
3.最大深度：3-8（从6开始）
4. min_child_weight / min_data_in_leaf：1-20（较高可防止过度拟合）
5.子样本：0.7-1.0
6.colsample_bytree：0.7-1.0
7. reg_alpha (L1) 和 reg_lambda (L2): 0-10

|阿达Boost |偏见|快|低|简单的基础学习器，干净的数据 |
|梯度提升|偏见|中等|高|表格数据、竞赛 |
