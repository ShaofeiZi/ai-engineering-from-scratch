# 回归策略指南

回归预测连续值。正确的方法取决于特征和目标之间的关系、特征的数量以及过度拟合的风险。

## 决策清单

1. 特征和目标之间的关系是否近似线性？
   - 是：从普通线性回归开始
   - 否：尝试多项式特征或非线性模型

2. 与样本相关的特征有多少？
   - 特征少，样本多：普通线性回归效果很好
   - 特征较多，样本较少：使用正则化（Ridge 或 Lasso）
   - 比样本更多的特征：Lasso (L1) 用于选择特征，或 Ridge (L2) 用于缩小所有权重

3. 你需要可解释性吗？
   - 是：具有很少特征的线性回归，或用于自动特征选择的 Lasso
   - 否：多项式特征，或转向基于树的模型或神经网络

4. 您的数据集很小（少于 10,000 行）吗？
   - 使用正规方程（封闭式解）计算速度
   - 交叉验证对于可靠评估至关重要

5. 您的数据集很大（数百万行）吗？
   - 使用随机梯度下降（SGD）或小批量梯度下降
   - 由于 O(n^3) 矩阵求逆，正规方程太慢

## 何时使用每种方法

**普通线性回归**：任何回归任务的基线。从这里开始。如果 R 方可以接受并且模型很简单，则到此为止。

**多项式回归**：散点图显示一条曲线，而不是一条直线。从 2 级开始。只有在验证性能合理的情况下才增加。度数 > 5 几乎总是过拟合。

**岭回归 (L2)**：许多相关特征。所有权重都缩小到零，但没有一个权重完全为零。当您相信所有功能都有贡献时，这很好。

**套索回归 (L1)**：许多特征，但您怀疑只有少数特征重要。 Lasso 将不相关的特征权重精确为零，从而执行自动特征选择。

**弹性网**：结合了 L1 和 L2 惩罚。当您有许多相关特征并需要进行一些特征选择时使用。

## 常见错误

- 在梯度下降之前跳过特征缩放（收敛变得非常慢）
- 使用测试集性能来调整超参数（使用验证集或交叉验证）
- 拟合高次多项式而不检查验证错误（训练 R^2 总是随次数增加）
- 忽略残差图（如果残差显示模式，R^2 可能会产生误导）
- 将 R^2 视为唯一指标（检查残差分布、MAE 和特定于域的阈值）
