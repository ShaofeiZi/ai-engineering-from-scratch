# 不平衡数据策略

用于处理不平衡分类的决策清单。按照此顺序为您的问题选择正确的方法。

## 步骤 1：测量不平衡度

- 计算每类的样本数
- 计算不平衡比率（多数/少数）
- 轻度：比例 < 3:1（例如 70/30）
- 中等：比例为 3:1 至 20:1（例如 95/5）
- 严重：比率> 20:1（例如，99/1）

## 第 2 步：选择正确的指标

对于不平衡的数据集，更喜欢精度/召回率/F1 而不是准确性。根据您的问题选择：

|情况|主要指标 |次要指标 |
|----------|--------------|-----------------|
|错过阳性结果的代价非常高昂（欺诈、疾病）|回忆| F2 分数 |
|误报代价高昂（垃圾邮件过滤器、建议）|精密| F0.5成绩|
|两者的重要性大致相同| F1成绩|中冶 |
|需要单一排名指标 |亚太研究中心 | AUC-ROC |
|需要跨数据集比较 |中冶 |亚太研究中心 |

## 第 3 步：选择再平衡策略

### 按不平衡严重程度

|不平衡|第一次尝试 |第二次尝试 |避免 |
|------------|------------|------------|--------|
|轻度 (< 3:1) |班级权重 |阈值调整|过采样（不必要）|
|中等（3:1 至 20:1）| SMOTE + 班级重量 |顶部阈值调整|欠采样（数据丢失过多）|
|严重 (> 20:1) | SMOTE + 类别权重 + 阈值 |具有平衡装袋的合奏 |单独欠采样 |

### 按数据集大小

|数据集大小 |首选策略 |原因 |
|------------|--------------------|--------|
| < 1,000 个样本 |过采样或 SMOTE |无法承受丢失大部分数据 |
| 1,000 - 10,000 | SMOTE + 阈值调整 |足够的少数样本用于 k-NN |
| > 10,000 |类别权重或欠采样 |快速、充足的少数派数据 |

## 步骤 4：应用该技术

### 班级权重（始终先尝试）
- 在 sklearn 中：`class_weight='balanced'`
- 无需修改数据
- 适用于任何基于损失的模型
- 相当于期望中的过采样

### 打击
- 仅适用于训练数据（从不测试/验证）
- 使用 k=5 邻居（默认）
- 与班级权重相结合以获得最佳效果
- 留意边界附近的嘈杂合成点

### 阈值调整
- 训练模型，获取验证集的预测概率
- 扫描阈值从 0.05 到 0.95
- 选择最大化您选择的指标的阈值
- 始终调整验证数据，而不是测试数据

## 步骤 5：正确验证

- 使用分层交叉验证（保留每次折叠中的类别比率）
- 报告原始（未重新采样）测试集的指标
- 切勿在分割前应用 SMOTE - 仅适用于训练折叠
- 与“总是预测多数”基线进行比较

## 步骤 6：要避免的常见错误

- 在训练/测试分割之前将 SMOTE 应用于整个数据集（数据泄漏）
- 使用以准确率作为评价指标
- 不首先尝试班级权重（最简单的方法，通常就足够了）
- 过采样然后交叉验证（合成点在折叠处泄漏）
- 忽略阈值调整（自由性能，无需重新训练）
- 对小数据集使用随机欠采样（丢弃太多数据）

## 快速决策树

1、不平衡比是否<3:1？ -> 仅尝试班级权重
2. 数据集是否> 10,000 个样本？ -> 类别权重+阈值调整
3. 数据集是否少于 1,000 个样本？ -> SMOTE + 班级权重
4.否则->SMOTE+类别权重+阈值调整
5. 还是不够好？ -> 平衡装袋整体
