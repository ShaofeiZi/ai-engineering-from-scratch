# 聚类算法选择指南

聚类没有单一的最佳算法。正确的选择取决于簇的形状、您是否知道簇的数量、数据中的噪声有多少以及数据集有多大。

## 决策清单

1.你知道簇的数量吗？
   - 是：K-Means 或 GMM
   - 否：DBSCAN（自动查找聚类）或分层（在不同级别切割树状图）

2. 簇的形状是什么？
   - 大致球形（斑点状）：K-Means
   - 不同尺寸的椭圆机：GMM
   - 任意形状（新月形、环形、链形）：DBSCAN
   - 嵌套或分层：分层聚类

3. 数据是否包含噪音或异常值？
   - 是：DBSCAN（明确标记噪声点）或 GMM（低概率点是异常值）
   - 否：K-Means 没问题

4. 你需要软分配（概率）吗？
   - 是：GMM 为每个簇给出 P(簇 | 数据点)
   - 否：K-Means 或 DBSCAN 给出硬作业

5. 数据集有多大？
   - 10,000 以下：任何算法都有效
   - 10,000 到 1,000,000：K-Means（快速）、小批量 K-Means（更快）
   - 超过 1,000,000：小批量 K 均值或 BIRCH。分层太慢了。

## 何时使用每种方法

**K-Means**：默认起点。快速（O(n * k * 迭代））、简单且足以解决许多问题。使用肘法或轮廓分数来选择 K。 局限性：假设球形簇，对初始化敏感（使用 K-Means++ 或运行多次），无法很好地处理不同的簇大小。

**DBSCAN**：最适合发现任意形状的簇并自动检测异常值。两个参数：eps（邻域半径）和min_samples（最小密度）。不需要指定 K。 限制：当簇具有非常不同的密度时会很困难，并且调整 eps 可能很棘手。使用 k 距离图来估计 eps：计算到每个点的第 k 个最近邻点的距离、排序并查找弯头。

**分层（聚合）**：构建合并树。当您想要探索多个粒度的簇结构（在不同高度切割树状图）时很有用。 Ward 的连接最适合紧凑的集群。单联动发现拉长的簇，但对噪声敏感。限制：O(n^2) 内存和 O(n^3) 时间，对于大型数据集来说不切实际。

**GMM（高斯混合模型）**：具有概率分配的软聚类。将每个簇建模为具有自己的均值和协方差的高斯分布。当簇是椭圆形或重叠时，优于 K 均值。使用 BIC（贝叶斯信息准则）来选择组件的数量。局限性：假设高斯分布，在非凸形状上可能失败，对初始化敏感。

## 评估聚类质量（无标签）

|公制|它测量什么 |范围 |使用时 |
|--------|-----------------|--------|----------|
|剪影得分|凝聚与分离| -1 到 1（越高越好）|比较 K 值或算法 |
|惯性（SS 簇内）|簇的紧密度 | 0 到 inf（越低越好）| K-Means 的肘部法 |
| BIC / AIC |具有复杂性惩罚的模型拟合 |越低越好|选择 GMM 分量的数量 |
|卡林斯基-哈拉巴斯指数|方差之间与方差之比 |越高越好|快速比较|
|戴维斯-布尔丁指数 |聚类之间的平均相似度 |越低越好|惩罚重叠集群 |

## 常见错误

- 在没有缩放特征的情况下运行 K-Means（较大尺度上的特征主导距离计算）
- 当实际数据是高维时，通过观察二维数据来选择 K（使用轮廓分数）
- 在非球形集群上使用 K-Means（新月形或环形数据需要 DBSCAN）
- 将 DBSCAN eps 设置得太大（所有内容都在一个集群中）或太小（所有内容都是噪声）
- 将聚类标签视为基本事实（聚类是探索性的；使用领域知识进行验证）
- 在超过 20,000 个点的数据集上运行层次聚类（内存和时间爆炸）
