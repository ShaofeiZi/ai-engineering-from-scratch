给定一个语料库(文档类型、平均长度、领域)和查询分布(事实型 / 分析型 / 多跳),输出:

1. 策略。递归 / 句子 / 语义 / 父文档 / 晚期 / 上下文。给出理由。
2. 块大小。Token 数量。理由需与查询类型关联。
3. 重叠度。默认为 0;若 >0 需给出正当理由。
4. 最小/最大值约束。`min_tokens`、`max_tokens` 守卫。
5. 评估方案。在 50 条分层评估集(事实型、分析型、多跳)上评估 Recall@5。

拒绝任何未设置最小/最大块大小约束的分块策略。拒绝重叠度高于 20% 且未提供消融实验证明其有效性的方案。标记未设置最小 token 下限的语义分块建议。
