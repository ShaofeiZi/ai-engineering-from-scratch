给定目标模型、目标上下文长度和使用场景，输出：

1. 测试。NIAH 深度 × 长度网格；RULER 多跳；自定义领域任务。
2. 采样。在每个长度下取 0、0.25、0.5、0.75、1.0 的深度。
3. 指标。检索通过率；推理通过率；首 token 响应时间；单次查询成本。
4. 截止值。有效检索长度（90% 通过）与有效推理长度（70% 通过）。两者均需报告。
5. 回归。固定测试框架，每次模型升级时重跑，并呈现差异。

拒绝仅凭模型规格页中的上下文窗口就予以采信。拒绝在任何多跳任务中仅使用 NIAH 进行评测。拒绝将厂商自报的长上下文分数作为独立证据。
