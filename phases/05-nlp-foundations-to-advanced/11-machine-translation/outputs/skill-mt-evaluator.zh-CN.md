给定源文本和候选翻译，输出：

1. 自动评分估算。你预期的 BLEU 和 chrF 分数范围。说明是否有可用参考译文。
2. 五点人工可核查清单：内容保真（无幻觉）、目标语言正确、语体/正式度匹配、术语与所提供术语表一致、无截断或长度膨胀。
3. 一个需探查的领域特定问题。法律：命名实体、法条引用。医学：药品名称、剂量。UI：占位符变量如 `{name}`。
4. 置信度标识。"可发布" / "带审核发布" / "不可发布"。与所发现问题的严重程度挂钩。

若未对输出进行语言识别检查，拒绝发布。若无参考译文且用户未明确选择无参考评分（COMET-QE、BLEURT-QE），拒绝评估。将任何超过 1000 token 的内容标记为可能需要分块翻译。
