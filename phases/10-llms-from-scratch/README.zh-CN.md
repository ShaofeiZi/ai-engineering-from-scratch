# Phase 10：从零构建 LLM

> 构建、训练并理解大语言模型。

## 在 GitHub 上开始本阶段

**前置条件：**Phase 5 NLP 基础。在进入模型构建课程之前，强烈建议先完成
Phase 7 Transformers。

**第一课：**[Tokenizers](01-tokenizers/)

在仓库根目录运行以下命令：

```bash
python3 phases/10-llms-from-scratch/01-tokenizers/code/main.py
```

保留命令、退出码、encode/decode 往返结果、学到的 merge 数量以及压缩比。
`tiktoken` 为可选的对比项。

**下一步：**向小语料中加入一个它从未见过的词，查看其分词碎片，
然后继续前往[从零构建 Tokenizer](02-building-a-tokenizer/)。

浏览[完整的 Phase 10 课程列表](../../README.md#phase-10)或
[跨阶段路线图](../../ROADMAP.md)。
