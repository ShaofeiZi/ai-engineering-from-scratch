对照协议版本 `2026-07-28` 审查所提供的 MCP 工具接口。

如果缺少以下输入，请主动索取：

1. 完整的 `tools/list` 描述符分页，包括每一个 `nextCursor` 字段。
2. 每个工具至少一个成功结果和一个失败结果。
3. Streamable HTTP 参数头映射（若使用）。
4. 补全引用、调用方类别及示例建议。
5. 可改变可见工具集的授权上下文。

生成包含以下章节的紧凑报告。

## 描述符准入

对每个工具：

- 验证存在非空的稳定名称；
- 要求 `inputSchema` 为对象类型；
- 识别 JSON Schema 方言，省略时默认为 2020-12；
- 在存在时验证 `outputSchema`；
- 将注解列为不受信任的提示，而非策略；
- 返回 `ADMIT`、`REJECT` 或 `CONDITIONAL`，并给出一个精确理由。

拒绝一个格式错误的描述符时，不得拒绝其他不相关的有效工具。

## 结果契约

对每一个完整结果，包括 `isError: true` 的结果：

- 要求 `resultType: complete`；
- 按类型验证每一个内容块；
- 将 `structuredContent` 视为任意 JSON 值，而非仅限对象；
- 当存在 `outputSchema` 时，要求 `structuredContent` 并符合该 schema；
- 对结构化结果要求提供兼容性文本块；
- 区分资源链接与内嵌资源；
- 声明大小和媒体类型限制。

将格式错误的请求归类为 JSON-RPC 错误。将可操作的执行失败归类为 `isError: true` 的完整结果，且不得绕过已发布的输出契约。

## 参数头

对每一个 `x-mcp-header`：

- 要求为有效的、非空的 HTTP 字段名 token；
- 要求大小写不敏感的唯一性；
- 要求为字符串、整数或布尔类型；
- 遍历整个输入 schema，包括嵌套属性、组合器、数组项以及 `$ref` 引用的定义；
- 仅允许在直接的 `inputSchema.properties` 成员上使用该注解，拒绝在其他任何位置或 `outputSchema` 中发现的注解；
- 拒绝超出 `-9007199254740991` 到 `9007199254740991` 范围的 `number` 和整数值；
- 根据部署策略拒绝凭据、令牌、密钥、密码、授权及 PII 字段；
- 仅当值为非空可见 ASCII 且不以 `=?base64?` 开头时，才原样传输该值；
- 否则精确输出 `=?base64?{Base64UTF8}?=`，不裁剪或规范化原始值；
- 对 Unicode、空字符串、空白、控制字符、CR 或 LF、填充及哨兵样式的字符串进行编码，并将布尔值渲染为小写文本；
- 在 HTTP 边界处，解码已识别的 `Mcp-Param-*` 值，对头名进行大小写不敏感比较，对解码后的值与 JSON 主体进行精确比较，将缺失、重复、意外、格式错误或不匹配的副本拒绝为 HTTP `400` 加 JSON-RPC `-32020`；
- 记录最终的头名和拒绝类别，绝不记录参数值或编码后的载荷。

## 分页

追踪每一个列表请求。只要 `nextCursor` 存在且非 null，即继续，包括其为空字符串的情况。绝不解码、修改、递增、排序或从游标中推导含义。报告重复工具、缺失页面和不稳定排序。

## 补全

对每个提示词或资源引用：

- 验证引用和参数；
- 通过调用方的授权过滤建议；
- 将结果上限设为 100 个值；
- 定义客户端去抖动和服务器速率限制；
- 测试隐藏的租户、资源和环境名称不会泄露。

## 验证矩阵

返回至少以下检查项：

| 检查项 | 夹具 | 预期结果 |
|------|---------|-----------------|
| 非对象结构化输出 | 有效的数组、标量或 null schema | 符合时接受 |
| 输出不匹配 | JSON 类型错误或缺少属性 | 在模型使用前拒绝 |
| 错误输出不匹配 | `isError: true` 且缺少或无效的结构化内容 | 在模型使用前拒绝 |
| 空游标 | `nextCursor: ""` | 后续请求发送完全相同的游标 |
| 不安全的头 | 令牌或无效字段名 | 描述符被拒绝 |
| 嵌套头注解 | `oneOf`、`items`、嵌套对象或 `$ref` 定义 | 全树准入期间描述符被拒绝 |
| 编码的头值 | Unicode、换行、填充或哨兵样式文本 | 精确的 base64 UTF-8 哨兵可往返还原原始值 |
| 整数头值 | 两个安全边界值及各边界外一个值 | 安全边界通过；不安全值被拒绝 |
| 头与主体一致性 | 大小写变体、缺失副本和解码不匹配 | 大小写变体通过；缺失或不匹配返回 HTTP 400 和 JSON-RPC -32020 |
| 混合内容 | 文本、媒体、链接、内嵌资源 | 每个块独立验证 |
| 补全隔离 | 低权限调用方 | 不返回任何特权建议 |
| 错误分层 | 未知工具和业务失败 | JSON-RPC 错误和 `isError: true` 保持区分 |

当证据仅包含一次成功的工具调用时，拒绝批准。要求提供发现页面、准入决策和已验证的结果夹具。
