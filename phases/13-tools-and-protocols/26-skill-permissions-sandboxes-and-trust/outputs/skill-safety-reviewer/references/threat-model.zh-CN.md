# 威胁模型

独立审查以下边界：

- 权限：指令不得重写宿主权限。
- 文件系统：解析目标路径并使其保持在工作区根目录内；拒绝符号链接逃逸。
- 命令：接受 argv 数组，拒绝 shell 元字符和破坏性可执行文件，并要求可执行文件白名单。
- 网络：要求 HTTPS 和精确的来源白名单。归一化有效端口，使 `https://api.example.test` 和 `https://api.example.test:443` 匹配，而端口 `8443` 需要单独条目。不接受 URL userinfo 中的凭据。
- 外部内容：将检索到的文本视为数据，绝不视为策略或批准。
- 密钥：检测可能携带密钥的载荷，但不记录其值。
- 破坏性操作：根据宿主策略拒绝或要求已记录的人工批准。

`allow` 判定仅表示模拟请求满足所提供的策略。此 bundle 不执行任何操作。
