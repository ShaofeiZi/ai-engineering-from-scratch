# 原语决策模型

按职责选择。可能有不止一个原语是正确的。

| 需求 | 原语 | 边界 |
|---|---|---|
| 一次性指令 | Prompt | 仅存在于当前交互 |
| 仓库级默认约定 | AGENTS.md | 在该仓库作用域内生效 |
| 可复用的任务方法 | Agent Skill | 为任务加载过程性知识 |
| 外部操作或数据 | MCP tool | 暴露一个带有输入契约的可调用能力 |
| 对运行时事件的响应 | Hook | 在宿主定义的生命周期节点运行 |
| 确定性变换 | 普通代码 | 无需模型判断即可产生可重复的输出 |
| 隔离或并行的上下文 | Subagent | 将一个有边界的任务委托到独立的上下文窗口 |

一个查询远程服务的发布评审方法可能同时使用 Agent Skill 和 MCP tool。仓库测试约定可能附加 AGENTS.md。工具调用后审计可能附加一个 hook。稳定的解析应归入普通代码。需要上下文隔离的独立研究可以使用一个 subagent。
