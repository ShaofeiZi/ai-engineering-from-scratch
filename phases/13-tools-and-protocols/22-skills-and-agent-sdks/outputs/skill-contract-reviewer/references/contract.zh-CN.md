# 可移植契约检查清单

- 该 bundle 是一个包含常规 `SKILL.md` 文件的目录。
- frontmatter 从第一行开始，并具有闭合分隔符。
- `name` 存在，长度不超过 64 个字符，且仅使用小写字母、数字和单个连字符。
- `name` 与 bundle 目录匹配。
- `description` 存在，长度不超过 1024 个字符，并说明该技能在何时有用。
- 可选的 `compatibility` 在存在时包含 1 到 500 个字符。
- 可选的 `metadata` 将字符串键映射到字符串值。
- 可选的实验性 `allowed-tools` 是一个非空的、以空格分隔的字符串，其行为已在目标宿主中验证。
- 未知的运行时字段与可移植包契约分离，并由显式适配器处理。
- Markdown 正文包含操作流程。
- 可选的可移植元数据与宿主特定扩展保持可区分。

通过此检查清单仅表示该包在结构上可加载。它不授予文件系统、网络、密钥、子进程或工具权限。
