给定一个开放 VLM 检查点及其配置（层结构、交叉注意力调度、门控参数化、训练配方），识别其使用的 Flamingo 血统元素，并诊断门控设置不当的常见症状。

产出：

1. 血统清单。标注以下元素是否存在（Perceiver 重采样器 Y/N、门控交叉注意力频率 M、tanh vs sigmoid 门控、alpha 初始值、LLM 冻结深度）。
2. 交错输入支持。解析模型所期望的提示词格式；确认或否认对多图像、视频和少样本上下文提示的支持。
3. 视觉 token 预算。计算每张图像的成本：K 个潜变量 x N 个交叉注意力插入点。与相同图像数量下的 BLIP-2 风格单输入桥接进行对比。
4. 门控诊断。给定训练损失曲线或基准退化情况，建议门控是否开启过快（丧失文本能力）、过慢（未能使用视觉输入）或校准不当（视觉 token 在竞争而非补充）。
5. 修复配方。具体的参数修复：若文本退化则将 alpha 初始化更接近 0，提高门控参数的学习率，或在最初 N 步冻结门控。

硬性拒绝：
- 在未检查重采样器和门控调度的情况下将任何开放 VLM 视为"Flamingo"。Idefics2 放弃了重采样器；不加限定地将其标记为 Flamingo 血统是错误的。
- 假设零初始化总能在训练中存活。一些开放复现版本使用小的非零初始化，以牺牲初始稳定性换取更快的收敛。
- 声称门控交叉注意力对所有任务都严格优于单一的 BLIP-2 桥接。在小型 LLM 上的单图像 VQA 中，额外的交叉注意力层纯属成本。

拒绝规则：
- 如果检查点的训练配方不公开，则拒绝并解释为何门控诊断需要了解门控调度。
- 如果调用者要求与 Gemini 或 Claude（专有）进行比较，则拒绝——其门控机制未公开。
- 如果范围内的 VLM 是早期融合模型（Chameleon、Emu3），则拒绝——门控仅适用于适配器风格的 VLM。

输出：一份一页的诊断，包含血统清单、交错输入能力矩阵、token 预算、门控诊断和具体的修复配方。以一段"接下来读什么"结尾，指向第 12.05 课（LLaVA）了解替代投影器方法，或第 12.11 课（Chameleon）了解早期融合的逃生路径。
