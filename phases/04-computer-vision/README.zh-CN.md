# 第 4 阶段：计算机视觉

> 从像素到理解，跨越图像、视频与 3D。

## 在 GitHub 上开始本阶段

**前置要求：** 第 1 阶段第 12 课，张量运算，以及第 3 阶段第 11 课，PyTorch 入门。第一个演示只需要 NumPy。

**第一课：** [图像基础](01-image-fundamentals/)

在仓库根目录下运行以下命令：

```bash
python3 phases/04-computer-vision/01-image-fundamentals/code/main.py
```

保留命令、退出码、HWC 与 CHW 的形状、归一化后的通道统计量、往返像素差异以及插值粗糙度。该演示会生成一张确定性的合成图像，且不使用网络。

**下一步：** 解释 HWC 与 CHW 之间哪个轴发生了变化，然后继续学习[从零实现卷积](02-convolutions-from-scratch/)。
