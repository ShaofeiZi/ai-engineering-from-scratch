# 认证课程体系

> 一项证书应当是你能够胜任相关工作的证明，而非你背诵了题库的证明。

本部分将公开认证考试大纲转化为免费、以实践为先的学习路径。每条路径将现有的《AI 工程从零开始》课程与认证专属的课程、实验、诊断测试以及原创模拟考试相结合。

首个项目是 [Claude 认证](claude/README.md)，涵盖 2026 年 7 月考试指南中发布的全部四项 Claude 认证证书。

## 规则

- 公开考试指南定义考试范围与分值权重。
- 官方产品文档定义当前的技术行为。
- 每一节课和练习题均为原创。
- 不包含考试真题泄露、机密题目、包过承诺或答题套路技巧。
- 练习成绩是课程中的原始得分，并非 Anthropic 官方的标准化分数。
- 动手实践成果比被动阅读更重要。
