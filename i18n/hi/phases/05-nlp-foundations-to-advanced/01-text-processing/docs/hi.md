## अवधारणा

तीन ऑपरेशन, प्रत्येक में एक काम और एक विफलता मोड है।

**टोकनकरण** "टोकन" जानबूझकर अस्पष्ट है क्योंकि सही granularity कार्य पर निर्भर करता है. NLP. ट्रांसफार्मर के लिए उपशब्द। सफेद स्थान के बिना भाषाओं के लिए वर्ण।

**मतदान** नियम के साथ प्रत्ययों को काटता है। `running -> run`. `organization -> organ`. . दूसरा है विफलता मोड.

**लिमिटिकेशन** एक शब्द को व्याकरण ज्ञान का उपयोग करके शब्दकोश में कम करता है। धीमी, सटीक, एक खोज तालिका या मॉर्फोलॉजिकल विश्लेषक की आवश्यकता होती है। `ran -> run` (जानने की जरूरत है "रन" "रन" के अतीत समय है) । `better -> good` (समान रूपों को जानने की आवश्यकता है) ।

अंगूठे का नियम. जब गति महत्वपूर्ण हो और आप शोर को सहन कर सकते हैं (खोज सूचकांक, कच्चे वर्गीकरण) । जब अर्थ महत्वपूर्ण हो (प्रश्न का उत्तर, अर्थपूर्ण खोज, उपयोगकर्ता जो कुछ भी पढ़ता है) ।

## इसे बनाओ

### चरण 1: एक रेजेक्स शब्द टोकनराइज़र

सबसे सरल उपयोगी टोकनराइज़र अपने टोकन के रूप में अंकन को बनाए रखते हुए गैर-अल्फान्यूमेरिक वर्णों पर विभाजित होता है। यह सही नहीं है, अंतिम नहीं है, लेकिन यह एक पंक्ति में चलता है।

```python
import re

def tokenize(text):
    return re.findall(r"[A-Za-z]+(?:'[A-Za-z]+)?|[0-9]+|[^\sA-Za-z0-9]", text)
```

तीन पैटर्न क्रमशः शब्द`don't`, `it's`) शुद्ध संख्याएँ। किसी भी एकल गैर-सफेद स्थान गैर-अल्फान्यूमेरिक वर्ण एक स्वतंत्र टोकन (बिन्दु) के रूप में।

```python
>>> tokenize("The cats weren't running at 3pm.")
['The', 'cats', "weren't", 'running', 'at', '3', 'pm', '.']
```

विफलता मोड नोटिस करने के लिए। `3pm` विभाजित करने के लिए `['3', 'pm']` क्योंकि हम अक्षरों और अंकों के बीच बारी बारी बारी। अधिकांश कार्यों के लिए पर्याप्त है। URLsउत्पादन के लिए, सामान्य से पहले पैटर्न जोड़ें।

### चरण 2: एक पोर्टर stemmer (केवल चरण 1a)

पूर्ण पोर्टर एल्गोरिथ्म में पांच चरणों के नियम हैं। केवल चरण 1 ए में सबसे अधिक अंग्रेजी प्रत्यय शामिल हैं और पैटर्न सिखाया जाता है।

```python
def stem_step_1a(word):
    if word.endswith("sses"):
        return word[:-2]
    if word.endswith("ies"):
        return word[:-2]
    if word.endswith("ss"):
        return word
    if word.endswith("s") and len(word) > 1:
        return word[:-1]
    return word
```

```python
>>> [stem_step_1a(w) for w in ["caresses", "ponies", "caress", "cats"]]
['caress', 'poni', 'caress', 'cat']
```

नियमों को ऊपर से नीचे पढ़ें। `ies -> i` नियम क्यों है `ponies -> poni`नहीं `pony`असली पोर्टर के पास कदम 1 बी है जो इसे ठीक करेगा नियम प्रतिस्पर्धा करते हैं पहले के नियम जीतते हैं आदेश किसी भी नियम से अधिक मायने रखता है

### चरण 3: खोज आधारित लेमेटाइज़र

लम्माकरण के लिए एक प्रकार की संरचना आवश्यक है। एक व्यवहार्य शिक्षण संस्करण में एक छोटी लम्मा तालिका और एक पतन का उपयोग किया जाता है।

```python
LEMMA_TABLE = {
    ("running", "VERB"): "run",
    ("ran", "VERB"): "run",
    ("runs", "VERB"): "run",
    ("better", "ADJ"): "good",
    ("best", "ADJ"): "good",
    ("cats", "NOUN"): "cat",
    ("cat", "NOUN"): "cat",
    ("were", "VERB"): "be",
    ("was", "VERB"): "be",
    ("is", "VERB"): "be",
}

def lemmatize(word, pos):
    key = (word.lower(), pos)
    if key in LEMMA_TABLE:
        return LEMMA_TABLE[key]
    if pos == "VERB" and word.endswith("ing"):
        return word[:-3]
    if pos == "NOUN" and word.endswith("s"):
        return word[:-1]
    return word.lower()
```

```python
>>> lemmatize("running", "VERB")
'run'
>>> lemmatize("cats", "NOUN")
'cat'
>>> lemmatize("better", "ADJ")
'good'
>>> lemmatize("watched", "VERB")
'watched'
```

अंतिम मामला महत्वपूर्ण शिक्षण क्षण है। `watched` हमारे मेज पर नहीं है और हमारे पतन केवल संभालता है `ing`. वास्तविक लेमिटाइजेशन कवर `ed`, अनियमित क्रिया, तुलनात्मक विशेषण, ध्वनि परिवर्तन वाले बहुवचन (`children -> child`) इसीलिए उत्पादन प्रणालियों का उपयोग WordNet, spaCyएक morphologizer, या एक पूर्ण morphological विश्लेषक.

### चरण 4: उन्हें एक साथ पाइप करें

```python
def preprocess(text, pos_tagger=None):
    tokens = tokenize(text)
    stems = [stem_step_1a(t.lower()) for t in tokens]
    tags = pos_tagger(tokens) if pos_tagger else [(t, "NOUN") for t in tokens]
    lemmas = [lemmatize(word, pos) for word, pos in tags]
    return {"tokens": tokens, "stems": stems, "lemmas": lemmas}
```

गायब टुकड़ा एक है POS चरण 5 · 07 (POS टैगिंग) एक बनाता है. अभी के लिए, डिफ़ॉल्ट सब कुछ करने के लिए `NOUN` और सीमाओं को स्वीकार करें।

## इसका प्रयोग करें

NLTK और spaCy उत्पादन संस्करणों जहाज. कुछ पंक्तियों प्रत्येक.

### NLTK

```python
import nltk
nltk.download("punkt_tab")
nltk.download("wordnet")
nltk.download("averaged_perceptron_tagger_eng")

from nltk.tokenize import word_tokenize
from nltk.stem import PorterStemmer, WordNetLemmatizer
from nltk import pos_tag

text = "The cats were running."
tokens = word_tokenize(text)
stems = [PorterStemmer().stem(t) for t in tokens]
lemmatizer = WordNetLemmatizer()
tagged = pos_tag(tokens)


def nltk_pos_to_wordnet(tag):
    if tag.startswith("V"):
        return "v"
    if tag.startswith("J"):
        return "a"
    if tag.startswith("R"):
        return "r"
    return "n"


lemmas = [lemmatizer.lemmatize(t, nltk_pos_to_wordnet(tag)) for t, tag in tagged]
```

`word_tokenize` संकुचन, यूनिकोड, किनारे मामलों को संभालने के लिए अपने Regex याद आती है. `PorterStemmer` सभी पांच चरणों में चलाता है। `WordNetLemmatizer` आवश्यकता है POS टैग से अनुवादित NLTKपेन ट्रीबैंक योजना WordNetअनुवाद के तार ऊपर अधिकांश ट्यूटोरियल छोड़ने के लिए थोड़ा है।

### spaCy

```python
import spacy

nlp = spacy.load("en_core_web_sm")
doc = nlp("The cats were running.")

for token in doc:
    print(token.text, token.lemma_, token.pos_)
```

```
The      the     DET
cats     cat     NOUN
were     be      AUX
running  run     VERB
.        .       PUNCT
```

spaCy पूरी पाइपलाइन पीछे छिपाता है `nlp(text)`. टोकनकरण, POS टैगिंग, और lemmatization सभी चल. NLTK पैमाना पर. अधिक सटीक बॉक्स से बाहर. समझौता यह है कि आप आसानी से अलग-अलग घटकों को आदान-प्रदान नहीं कर सकते हैं.

### कौन सी चुनना है

| स्थिति | चुनें |
|-----------|------|
| शिक्षण, अनुसंधान, आदान-प्रदान घटक | NLTK |

### दो विफलता मोड कोई भी आपको चेतावनी नहीं देता

अधिकांश ट्यूटोरियल एल्गोरिदम को सिखाते हैं और रुकते हैं. दो चीजें एक वास्तविक प्रीप्रोसेसिंग पाइपलाइन काटती हैं, और वे लगभग कभी कवर नहीं होते हैं।

**पुनरुत्पादकता की बहाव।** NLTK और spaCy संस्करणों के बीच टोकनकरण और लेमेटाइज़र व्यवहार को बदलना। `['do', "n't"]` में spaCy 2.x उत्पादन कर सकता है `["don't"]` 3.x में. आपका मॉडल एक वितरण पर प्रशिक्षित किया गया था. इन्फरेंस अब एक अलग पर चल रहा है. सटीकता चुपचाप गिरावट और कोई नहीं जानता क्यों. `requirements.txt`. एक पूर्व प्रसंस्करण regression परीक्षण लिखें जो 20 नमूना वाक्य की अपेक्षित टोकनकरण को फ्रीज करता है. इसे प्रत्येक उन्नयन पर चलाएं.

**प्रशिक्षण / निष्कर्ष असंगतता।** आक्रामक पूर्व प्रसंस्करण (कम अक्षर, स्टॉपवर्ड हटाने, स्टemming) के साथ ट्रेन, कच्चे उपयोगकर्ता इनपुट पर तैनात, घड़ी प्रदर्शन क्रेटर। यह एकल सबसे आम उत्पादन है NLP यदि आप प्रशिक्षण के दौरान पूर्व प्रसंस्करण करते हैं, तो आपको निष्कर्ष के दौरान समान कार्य करना होगा। शिप प्रीप्रसंस्करण मॉडल पैकेज के अंदर एक कार्य के रूप में है, न कि एक नोटबुक सेल के रूप में सेवा टीम को फिर से लिखता है।


1. **- आराम से।** विस्तार `tokenize` रखकर रखने के लिए URLs एकल टोकन के रूप में. परीक्षणः `tokenize("Visit https://example.com today.")` एक उत्पादन करना चाहिए URL टोकन।
2. **मध्यम।** Porter चरण 1b को लागू करें यदि किसी शब्द में स्वर होता है और अंत में `ed` या `ing`दोहरे व्यंजन नियम को संभाल (`hopping -> hop`नहीं `hopp`).
3. **कठिन.** एक lemmatizer बनाने के लिए जो उपयोग करता है WordNet एक खोज तालिका के रूप में लेकिन अपने पोर्टर voters पर वापस गिर जाता है जब WordNet सादा के साथ टैग किए गए कॉर्पस पर सटीकता मापें WordNet और साधारण पोर्टर.
