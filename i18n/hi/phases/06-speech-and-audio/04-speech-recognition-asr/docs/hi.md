## समस्या

आपके पास 10 सेकंड 16 है kHz क्लिप. आप एक स्ट्रिंग चाहते हैंः "किचन लाइट्स को चालू करें।" चुनौती संरचनात्मक हैः ऑडियो फ्रेम अक्षरों के साथ एक-एक से संरेखित नहीं होते हैं। "ठीक है" शब्द में 200 एमएस या 1200 एमएस लग सकता है। मौन बयान को अंकित करता है। कुछ ध्वन्यात्मक अन्य से अधिक हैं। आउटपुट टोकन की संख्या पहले से ज्ञात नहीं है।

तीन सूत्रों ने इस समस्या का समाधान किया हैः

1. **CTC (संलग्नतावादी समय वर्गीकरण) ।** विशेष सहित प्रति फ्रेम टोकन संभावनाओं जारी करें *खाली*. डिकोड समय पर गिरावट दोहराता है और रिक्त. गैर-स्वतः को गिरावट, तेजी से. द्वारा इस्तेमाल किया wav2vec 2.0, MMS.
2. **RNN-T (वार्तालु तंत्रिका नेटवर्क ट्रांसड्यूसर) ।** संयुक्त नेटवर्क अगले टोकन को दिए गए एन्कोडर फ्रेम और पिछले टोकन की भविष्यवाणी करता है. स्ट्रीम करने योग्य. Google के डिवाइस पर उपयोग किया जाता है ASR, NVIDIA परकीट.
3. **ध्यान एन्कोडर-डेकोडर.** एन्कोडर छिपे हुए राज्यों में ऑडियो संपीड़ित करता है, डिकोडर पार-सहायता करता है ऑटोरेग्रेसिव रूप से टोकन उत्पन्न करने के लिए। SeamlessM4T.

2026 में, SOTA WER पर LibriSpeech परीक्षण शुद्धता 1.4% है (पाराकीट-TDT-1.1B, NVIDIA) और 1.58% (विस्पर-लार्ज-v3-turbo) अंतर छोटे हैं; तैनाती में अंतर विशाल हैं।

## अवधारणा

![तीन ASR सूत्रों मेंः CTC, RNN-T, ध्यान-संकेतक-डिसीडर](../assets/asr-formulations.svg)

**CTC अंतर्ज्ञान।** एन्कोडर आउटपुट `T` फ्रेम स्तर पर वितरण `V+1` टोकन (V अक्षर + रिक्त) । एक लक्ष्य स्ट्रिंग के लिए `y` लम्बाई `U < T`, किसी भी फ्रेम संरेखण जो गिर जाता है `y` गिनती. CTC इन सभी संरेखणों पर हानि योग। इन्फरेन्सः प्रति फ्रेम argmax, गिरावट दोहराता है, रिक्त स्थानों को हटाता है।

लाभः गैर-स्वतः-पुनर्निर्माण, स्ट्रीमिंग, शून्य दृष्टि। नुकसानः *सशर्त स्वतंत्रता की धारणा* प्रत्येक फ्रेम भविष्यवाणी दूसरों से स्वतंत्र है, इसलिए कोई आंतरिक भाषा मॉडल नहीं है. बाहरी के साथ फिक्स LM बीम खोज या क्षैतिज संलयन के माध्यम से।

**RNN-T अंतर्ज्ञान।** एक जोड़ता है *भविष्यवाणी* नेटवर्क जो टोकन इतिहास और एक *ज्वाइनर* जो एक संयुक्त वितरण में एन्कोडर फ्रेम के साथ भविष्यवाणी की स्थिति को जोड़ता है `V+1` (संसद `+1` एक शून्य / कोई-प्रसारक है) स्पष्ट रूप से सशर्त निर्भरता मॉडल CTC स्ट्रीमेबल क्योंकि प्रत्येक कदम केवल पिछले फ्रेम और पिछले टोकन पर स्थित है।

लाभः स्ट्रीमिंग + आंतरिक LM. नुकसानः प्रशिक्षण अधिक जटिल और स्मृति-भूख (3D हानि जाल) है; RNN-T हानि कर्नेल अपने आप में एक पूरी पुस्तकालय श्रेणी हैं।

**ध्यान एन्कोडर-डेकोडर.** लॉग-मेल फ्रेम पर एन्कोडर (6-32 ट्रांसफार्मर परतें) । डेकोडर (6-32 ट्रांसफार्मर परतें) ऑटोरेग्रेसिव रूप से टोकन उत्पन्न करने के लिए एन्कोडर आउटपुट की क्रॉस-एटेंडर करता है। कोई संरेखण प्रतिबंध नहीं  ऑडियो में कहीं भी ध्यान देख सकता है। ध्यान को सीमित करने के अलावा गैर-स्ट्रीम करने योग्य (छंटनी हुई व्हिस्पर-स्ट्रीमिंग, 2024) ।

लाभः ऑफ़लाइन पर उच्चतम गुणवत्ता ASR, मानक के साथ प्रशिक्षित करने के लिए आसान seq2seq उपकरन. नुकसानः ऑटोरेग्रेसिव लटेंसी आउटपुट लंबाई के समान है; इंजीनियरिंग के बिना स्ट्रीम नहीं किया जा सकता है।

### WER: एक संख्या

**वर्ड त्रुटि दर** = `(S + D + I) / N`, जहां S=substitutions, D=deletions, I=insertions, N=reference शब्द संख्या. शब्द स्तर पर दूरी को संपादित करने के लिए मेल खाता है. नीचे बेहतर है. एक WER 20% से ऊपर आम तौर पर उपयोग के योग्य नहीं है; 5% से नीचे पढ़ना भाषण के लिए मानव-समरूपता है। 2026 मानक बेंचमार्क पर संख्याएंः

| मॉडल | LibriSpeech परीक्षण-सफाई | LibriSpeech अन्य परीक्षण | आकार |
|-------|------------------------|------------------------|------|
| परकीट-TDT-1.1B | 1.40% | 2.78% | 1.1B पैराम |
| Whisper-Large-v3-turbo | 1.58% | 3.03% | 809M |
| कैनरी-1बी फ्लैश | 1.48% | 2.87% | 1B |
| सुचारू M4T v2 | 1.7% | 3.5% | 2.3B |

ये सभी एन्कोडर-डेकोडर या RNN-T शुद्ध CTC प्रणाली (wav2vec 2.0) परीक्षण-शुद्धता पर लगभग 1.82.1% पर बैठें।

## इसे बनाओ

### चरण 1: लोभी CTC डिकोड

```python
def ctc_greedy(frame_logits, blank=0, vocab=None):
    # frame_logits: list of per-frame probability vectors
    preds = [max(range(len(p)), key=lambda i: p[i]) for p in frame_logits]
    out = []
    prev = -1
    for p in preds:
        if p != prev and p != blank:
            out.append(p)
        prev = p
    return "".join(vocab[i] for i in out) if vocab else out
```

दो नियमः लगातार दोहराव को तोड़ना, खाली छोड़ना। उदाहरणः `a a _ _ a b b _ c` → `a a b c`.

### चरण 2: बीम-सर्च CTC

```python
def ctc_beam(frame_logits, beam=8, blank=0):
    import math
    beams = [([], 0.0)]  # (tokens, log_prob)
    for p in frame_logits:
        log_p = [math.log(max(pi, 1e-10)) for pi in p]
        candidates = []
        for seq, lp in beams:
            for t, lpt in enumerate(log_p):
                new = seq[:] if t == blank else (seq + [t] if not seq or seq[-1] != t else seq)
                candidates.append((new, lp + lpt))
        candidates.sort(key=lambda x: -x[1])
        beams = candidates[:beam]
    return beams[0][0]
```

उत्पादन के साथ पूर्वावलोकन पेड़ बीम खोज का उपयोग करता है LM संलयन; यह अवधारणात्मक कंकाल है।

### चरण 3: WER

```python
def wer(ref, hyp):
    r, h = ref.split(), hyp.split()
    dp = [[0] * (len(h) + 1) for _ in range(len(r) + 1)]
    for i in range(len(r) + 1):
        dp[i][0] = i
    for j in range(len(h) + 1):
        dp[0][j] = j
    for i in range(1, len(r) + 1):
        for j in range(1, len(h) + 1):
            cost = 0 if r[i - 1] == h[j - 1] else 1
            dp[i][j] = min(
                dp[i - 1][j] + 1,
                dp[i][j - 1] + 1,
                dp[i - 1][j - 1] + cost,
            )
    return dp[len(r)][len(h)] / max(1, len(r))
```

## 2026 में भी फंसे हुए जाल

- **नहीं VAD.** चुपचाप चलना "विस्पर" भ्रम पैदा करता है ("देखने के लिए धन्यवाद!") VAD.
- **वर्ण बनाम शब्द बनाम उपशब्द WER.** रिपोर्ट शब्द स्तर WER *बाद में* सामान्यीकरण (कम अक्षर, अंकन हटाया गया) ।
- **भाषा ID बहाव.** विस्मय की कार LID शोर क्लिप को जापानी या वेल्श में गलत तरीके से निर्देशित करना; बल `language="en"` जब आप जानते हैं.
- **बिना टुकड़े किए लंबे क्लिप।** विस्पर 30 सेकंड का एक खिड़की है. `chunk_length_s=30, stride=5` किसी भी लंबे समय के लिए.
