## समस्या

आप एक 10 सेकंड क्लिप प्राप्त करते हैं. आप जानना चाहते हैंः "यह क्या है?" शहरी ध्वनि (सिरिन, ड्रिल, कुत्ते), भाषण आदेश (हाँ / नहीं / रोक), भाषा ID (en/es/ar), स्पीकर भावना (क्रोध/तटस्थ), या पर्यावरण ध्वनि (इनडोर/आउटडोर, बाबल) । ये सभी *ऑडियो वर्गीकरण*, और 2026 में बेसलाइन वास्तुकला परिपक्व हैः लॉग-मेल → CNN या ट्रांसफार्मर → सॉफ्टमैक्स।

मुख्य कठिनाई नेटवर्क नहीं है। यह डेटा है। ऑडियो डेटासेट में क्रूर वर्ग असंतुलन, मजबूत डोमेन शिफ्ट (स्वच्छ बनाम शोर), और लेबल शोर (किसने "शहरी बाबल" बनाम "रेस्टोरेंट शोर" का फैसला किया?) है। 80% समस्या क्यूरेशन, वृद्धि और मूल्यांकन है, आदान-प्रदान नहीं CNN ट्रांसफार्मर के लिए।

## अवधारणा

![ऑडियो वर्गीकरण सीढ़ीः k-NN पर MFCCs करने के लिए AST करने के लिए BEATs](../assets/audio-classification.svg)

**क-NN पर MFCCs (90 के दशक की मूल रेखा) ।** सपाट MFCCs प्रति क्लिप, लेबल बैंक के लिए कॉसिन समानता गणना, शीर्ष K के बहुमत वोट वापस. साफ, छोटे डेटा सेट पर आश्चर्यजनक रूप से मजबूत (भाषण कमांड, ESC-50) बिना रन GPU.

**2D CNN लॉग-मल्स (2015-2019) पर।** उपचार `(T, n_mels)` लॉग मेल को छवि के रूप में लागू करें ResNet-18 या VGG-style. वैश्विक औसत समय अक्ष को पूल, कक्षाओं पर सॉफ्टमैक्स, अभी भी अधिकांश 2026 केगेल प्रतियोगिताओं में आधार रेखा।

**ऑडियो स्पेक्ट्रोग्राम ट्रांसफार्मर, AST (2021-2024).** लॉग-मेल (जैसे 16×16 पैच) को पैच करें, स्थिति एम्बेड करें, एक फ़ीड को फ़ीड करें ViT. नवीनतम स्थिति AudioSet (mAP 0.485) पर्यवेक्षित शिक्षा के लिए।

**BEATs और WavLM-base (2024-2026).** लाखों घंटों पर आत्म-निरीक्षण पूर्व प्रशिक्षण। आपके द्वारा आवश्यक 1-10% पर्यवेक्षित डेटा के साथ अपने कार्य को ठीक से समायोजित करें। 2026 में यह गैर-भाषण ऑडियो के लिए डिफ़ॉल्ट प्रारंभिक बिंदु है। BEATs-iter3 धड़कन AST 1-2 द्वारा mAP पर AudioSet गणना का 1/4 उपयोग करते हुए।

**एक जमे हुए रीढ़ की हड्डी के रूप में विस्पर-एकोडर (2024).** विस्पर के एन्कोडर ले लो, डिकोडर छोड़ दो, एक रैखिक वर्गीकरण संलग्न करो.SOTA भाषा पर ID और शून्य ऑडियो वृद्धि के साथ सरल घटना वर्गीकरण. "मुक्त दोपहर का भोजन" आधार रेखा.

### वर्ग असंतुलन वास्तविक चुनौती है

ESC-50: 50 कक्षाएं, 40 क्लिप प्रत्येक  संतुलित, आसान। UrbanSound8K: 10 वर्ग, असंतुलित 10:1। AudioSet: 632 वर्गों के साथ 100,000:1 लंबी पूंछ.

- प्रशिक्षण के दौरान संतुलित नमूनाकरण (मूल्यांकन में नहीं)
- मिश्रणः दो क्लिप (और उनके लेबल) को विस्तार के रूप में रैखिक रूप से इंटरपोलेट करें।
- SpecAugment: यादृच्छिक समय और आवृत्ति बैंडों का मास्क. सरल; महत्वपूर्ण.

### मूल्यांकन

- बहु-वर्ग विशेष (भाषण आदेश): शीर्ष-1 सटीकता, शीर्ष-5 सटीकता।
- बहु-वर्ग बहु-लेबल (AudioSet, UrbanSound-style): औसत सटीकता (mAP).
- भारी असंतुलनः प्रति वर्ग रिकॉल + मैक्रो F1.

```python
def featurize_mfcc(signal, sr, n_mfcc=13, n_mels=40, frame_len=400, hop=160):
    mag = stft_magnitude(signal, frame_len, hop)
    fb = mel_filterbank(n_mels, frame_len, sr)
    mels = apply_filterbank(mag, fb)
    log = log_transform(mels)
    return [dct_ii(frame, n_mfcc) for frame in log]
```

### चरण 2: निश्चित लंबाई का सारांश

```python
def summarize(mfcc_frames):
    n = len(mfcc_frames[0])
    mean = [sum(f[i] for f in mfcc_frames) / len(mfcc_frames) for i in range(n)]
    var = [
        sum((f[i] - mean[i]) ** 2 for f in mfcc_frames) / len(mfcc_frames) for i in range(n)
    ]
    return mean + var
```

सरल लेकिन मजबूतः औसत + समय के बीच भिन्नता 13 कोफ के लिए 26 अक्षांश निश्चित एम्बेडिंग देती है MFCC. तुरंत चलाता है. अत्याधुनिक से अधिक NN आधार रेखा पर ESC-50 हाल ही में 2017 में।

### चरण 3:NN

```python
def cosine(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    na = math.sqrt(sum(x * x for x in a)) or 1e-12
    nb = math.sqrt(sum(x * x for x in b)) or 1e-12
    return dot / (na * nb)

def knn_classify(q, bank, labels, k=5):
    sims = sorted(range(len(bank)), key=lambda i: -cosine(q, bank[i]))[:k]
    votes = Counter(labels[i] for i in sims)
    return votes.most_common(1)[0][0]
```

### चरण 4: उन्नयन करने के लिए CNN लकड़ी के मिल्स पर

में PyTorch:

```python
import torch.nn as nn

class AudioCNN(nn.Module):
    def __init__(self, n_mels=80, n_classes=50):
        super().__init__()
        self.body = nn.Sequential(
            nn.Conv2d(1, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(64, 128, 3, padding=1), nn.ReLU(),
            nn.AdaptiveAvgPool2d(1),
        )
        self.head = nn.Linear(128, n_classes)

    def forward(self, x):  # x: (B, 1, T, n_mels)
        return self.head(self.body(x).flatten(1))
```

3M पैरामीटर. ~ 10 मिनट में ट्रेनें ESC-50 एक के साथ RTX 4090. 80% से अधिक सटीकता।
