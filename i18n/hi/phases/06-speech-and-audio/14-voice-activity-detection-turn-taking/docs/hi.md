# आवाज गतिविधि का पता लगाना और टर्न-टेकिंग  सिलेरो, कोबरा और फ्लश ट्रिक

> प्रत्येक आवाज एजेंट दो निर्णयों पर रहता है या मर जाता हैः क्या उपयोगकर्ता अब बोल रहा है, और क्या वे समाप्त हो गए हैं? VAD पहले प्रश्न का उत्तर देता है।VAD + चुपचाप-हंगावर + अर्थपूर्ण अंत बिंदु मॉडल) उत्तर देता है। या तो गलत हो जाओ और आपका सहायक या तो उपयोगकर्ताओं को काटता है या कभी चुप नहीं होता।

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 6 · 11 (Real-Time Audio), Phase 6 · 12 (Voice Assistant)
**Time:** ~45 minutes

## समस्या

तीन अलग निर्णय एक आवाज एजेंट हर 20 एमएस टुकड़ा पर करता हैः

1. **क्या यह फ्रेम भाषण है?** — VAD. द्विआधारी, प्रति फ्रेम.
2. **क्या उपयोगकर्ता ने एक नया बयान शुरू किया है?** शुरुआत का पता लगाना।
3. **क्या उपयोगकर्ता ने समाप्त कर दिया है?** अंत-निर्देशन (टर्न-एंड)

कोई भी शोर  यातायात, कीबोर्ड, भीड़ की चुलबुली पर साफ़ उत्तर (ऊर्जा की सीमा) विफल रहता है। 2026 उत्तरः सिलेरो VAD (खुला, गहराई से सीखा) + एक बारी-बारी से पता लगाने मॉडल (सैमंतिक अंतनिर्देशन) + एक VAD-calibrated चुपचाप खांसी।

### तीन स्तरीय VAD कस्केड

**स्तर 1: ऊर्जा गेट।** सबसे सस्ता. RMS -40 पर dBFS. स्पष्ट मौन को फ़िल्टर करता है लेकिन सीमा से ऊपर किसी भी शोर पर फायर करता है।

**स्तर 2: सिलेरो VAD** (2020-2026, MIT) 1M पैरामीटर. 6000+ भाषाओं पर प्रशिक्षित। एक एकल पर प्रति 30 एमएस टुकड़े में ~ 1 एमएस में चलाया जाता है CPU धागा 87.7% TPR 5% पर FPR. ओपन सोर्स डिफ़ॉल्ट।

**स्तर 3: अर्थिक मोड़ डिटेक्टर।** LiveKit"पोज़-मिड-सेंटेशन" को "डॉन-टॉक" से अलग करता है। यह भाषाई संदर्भ (इंटेशन + हालिया शब्द) का उपयोग करता है, न कि सिर्फ चुप्पी।

### प्रमुख पैरामीटर और उनके डिफ़ॉल्ट

- **सीमा।** सिलेरो एक संभावना आउटपुट करता है; भाषण को &gt; 0.5 (डिफ़ॉल्ट) या &gt; 0.3 (संवेदनशील) पर वर्गीकृत करें। कम threshold = fewer पहले शब्द क्लिप, अधिक झूठी सकारात्मक.
- **न्यूनतम भाषण अवधि।** 250 ms से कम समय में बोलने से इनकार करें  आमतौर पर खांसी या कुर्सी की आवाज।
- **मौनता का झटका (अंत-उपदेश)** बाद में VAD 0 पर लौटता है, टर्न समाप्त होने की घोषणा करने से पहले 500-800 ms प्रतीक्षा करें। बहुत कम → उपयोगकर्ता को बाधित करें। बहुत लंबा → धीमा लगता है।
- **पूर्व-रोल बफर.** पहले 300-500 एमएस ऑडियो रखें VAD आग से बचता है "हे" को काटने से।

### फ्लश ट्रिक (क्यूताई 2025)

स्ट्रीमिंग STT मॉडल में आगे देखने में देरी होती है (किउताई के लिए 500 ms) STT-1B, 2.5 सेकेण्ड के लिए STT-2.6Bसामान्य तौर पर आप भाषण के अंत के बाद प्रतिलेख के लिए इतना लंबा इंतजार करेंगे। VAD भाषण के अंत में आग, **फ्लैश सिग्नल भेजें STT** जो तत्काल आउटपुट को मजबूर करता है। STT ~ 4 × वास्तविक समय पर प्रक्रियाओं, तो 500 ms बफर ~ 125 ms में समाप्त होता है।

अंत-से-अंतः 125 ms VAD + flush STT = conversational विलंबता।

### 2026 VAD तुलना

| VAD | TPR @ 5% FPR | विलंबता | लाइसेंस |
|-----|--------------|---------|---------|

## इसे बनाओ

### चरण 1: ऊर्जा गेट

```python
def energy_vad(chunk, threshold_dbfs=-40.0):
    rms = (sum(x * x for x in chunk) / len(chunk)) ** 0.5
    dbfs = 20.0 * math.log10(max(rms, 1e-10))
    return dbfs > threshold_dbfs
```

### चरण 3: टर्न-एंड स्टेट मशीन

```python
class TurnDetector:
    def __init__(self, silence_hangover_ms=500, min_speech_ms=250):
        self.state = "idle"
        self.speech_ms = 0
        self.silence_ms = 0
        self.silence_hangover_ms = silence_hangover_ms
        self.min_speech_ms = min_speech_ms

    def update(self, is_speech, chunk_ms=20):
        if is_speech:
            self.speech_ms += chunk_ms
            self.silence_ms = 0
            if self.state == "idle" and self.speech_ms >= self.min_speech_ms:
                self.state = "speaking"
                return "START"
        else:
            self.silence_ms += chunk_ms
            if self.state == "speaking" and self.silence_ms >= self.silence_hangover_ms:
                self.state = "idle"
                self.speech_ms = 0
                return "END"
        return None
```

### चरण 4: फ्लश ट्रिक कंकाल

```python
def flush_on_end(stt_client, audio_buffer):
    stt_client.send_audio(audio_buffer)
    stt_client.send_flush()
    return stt_client.recv_transcript(timeout_ms=150)
```

## फंदे

- **निश्चित सीमा।** चुपचाप काम करता है, शोर में विफलता। या तो डिवाइस पर मापें या Silero पर स्विच.
- **बहुत कम मौन खांसी।** एजेंट वाक्य के बीच में बाधित करता है. 500-800 एमएस बातचीत भाषण के लिए सबसे अच्छा स्थान है.
- **बहुत लंबे समय से खांसी.** लक्षित उपयोगकर्ताओं के साथ ए / बी परीक्षण.
- **कोई पूर्व-रोल बफर नहीं।** पहले 200-300 एमएस उपयोगकर्ता ऑडियो खो दिया. हमेशा रोलिंग पूर्व रोलिंग रखें.
- **अर्थपूर्ण अंतनिर्देशन को अनदेखा करना।** "हम्म, मुझे सोचने दो"... में लंबे समय तक रुकने की अनुमति है। LiveKitबारी-बारी से डिटेक्टर या इसी तरह के.

## व्यायाम

1. **- आराम से।** दौड़ें `code/main.py`यह एक भाषण + चुप + भाषण + खांसी अनुक्रम अनुकरण और परीक्षण तीन VAD स्तरों।
2. **मध्यम।** स्थापित करें `silero-vad`, 5 मिनट की रिकॉर्डिंग को संसाधित करें, पहले शब्द क्लिप और झूठे ट्रिगर दोनों को कम करने के लिए सीमा समायोजित करें। सटीकता / याद करने की रिपोर्ट करें।
3. **कठिन.** एक मिनी टर्न डिटेक्टर बनाएं: सिलेरो VAD + a 3-layer MLP अंतिम 10 शब्दों के एम्बेड (अनुच्छेद-ट्रांसफॉर्मर का उपयोग करें) पर अभ्यास करें। एक हाथ लेबल टर्न-एंड डेटासेट पर अभ्यास करें। केवल 10% से सिलेरो को हराएं F1.
