# ऑडियो मूल बातें  तरंगों का आकार, नमूनाकरण, फ़ूरियर परिवर्तन

> तरंगों के रूपों कच्चे संकेत हैं। स्पेक्ट्रोग्राम प्रतिनिधित्व हैं। Mel विशेषताएं हैं ML-friendly हर आधुनिक ASR और TTS पाइपलाइन इस सीढ़ी से चलता है, और पहला कदम नमूना और फ़ूरियर को समझना है।

## समस्या

एक माइक्रोफोन दबाव बनाम समय संकेत का उत्पादन करता है। आपके तंत्रिका नेटवर्क टेन्सर का उपभोग करता है। उनके बीच एक ढेर के सम्मेलनों में बैठा है जो, जब उल्लंघन किया जाता है, तो मूक कीड़े पैदा करता हैः मॉडल ठीक है लेकिन WER दोहरे, या TTS एक शोरबाज, या एक आवाज क्लोनिंग प्रणाली स्पीकर के बजाय माइक्रोफोन को याद करती है।

भाषण प्रणाली में प्रत्येक बग तीन प्रश्नों में से एक पर वापस जाता हैः

1. नमूना दर पर डेटा दर्ज किया गया था, और मॉडल क्या उम्मीद करता है?
2. क्या यह संकेत एक उपनाम है?
3. क्या आप कच्चे नमूने या आवृत्ति प्रतिनिधित्व पर काम कर रहे हैं?

इन सही कर लो और शेष चरण 6 ट्रीट करने योग्य है. उन्हें गलत और यहां तक कि विस्पर-बड़ा-v4 कचरा पैदा करता है।

**फ़ूरियर ट्रांसफॉर्म.** किसी भी परिमित संकेत विभिन्न आवृत्तियों पर सिनोसाइड्स का योग है।DFT) के लिए गणना `N` नमूने, `N` जटिल गुणांक  एक प्रति आवृत्ति बिन। `bin k` आवृत्ति के मानचित्र `k · sr / N` हर्ट्ज. परिमाण उस आवृत्ति पर परिमाण है, कोण चरण है।

**FFT.** फास्ट फ़ूरियर ट्रांसफॉर्मः एक `O(N log N)` एल्गोरिथ्म के लिए DFT जब `N` 2. प्रत्येक ऑडियो पुस्तकालय का उपयोग करता है FFT हुड के नीचे। एक 1024-सैंपल FFT 16 पर kHz 08 तक 512 उपयोग योग्य आवृत्ति डिब्बे देता है kHz 15.6 हर्ट्ज रिज़ॉल्यूशन पर।

**Framing + window.** हम नहीं FFT हम इसे ओवरलैप करने में काटते हैं *फ्रेम* (आमतौर पर 25 ms के साथ 10 ms hop), किनारे विरामचिह्नों को खत्म करने के लिए प्रत्येक फ्रेम को एक विंडो फ़ंक्शन (हैन, हैमिंग) से गुणा करें, फिर FFT यह शॉर्ट-टाइम फ़ूरियर ट्रांसफॉर्म है (STFT) पाठ 02 यहाँ से शुरू होता है।

## इसे बनाओ

### चरण 1: क्लिप पढ़ें और तरंग के रूप का चित्रण

`code/main.py` केवल stdlib का उपयोग करता है `wave` मॉड्यूल डेमो निर्भरता मुक्त रखने के लिए. उत्पादन के लिए आप उपयोग करेंगे `soundfile` या `torchaudio.load` (दोनों वापसी `(waveform, sr)` टूपल्स):

```python
import soundfile as sf
waveform, sr = sf.read("clip.wav", dtype="float32")  # shape (T,), sr=int
```

### चरण 2: पहले सिद्धांतों से सिनेस तरंग को संश्लेषित करें

```python
import math

def sine(freq_hz, sr, seconds, amp=0.5):
    n = int(sr * seconds)
    return [amp * math.sin(2 * math.pi * freq_hz * i / sr) for i in range(n)]
```

16 पर 440 हर्ट्ज सिनेस (कंसर्ट ए) kHz एक सेकंड के लिए 16,000 फ्लोट है. `wave.open(..., "wb")` 16 बिट का उपयोग करके PCM एन्कोडिंग।

### चरण 3: गणना DFT हाथ से

```python
def dft(x):
    N = len(x)
    out = []
    for k in range(N):
        re = sum(x[n] * math.cos(-2 * math.pi * k * n / N) for n in range(N))
        im = sum(x[n] * math.sin(-2 * math.pi * k * n / N) for n in range(N))
        out.append((re, im))
    return out
```

`O(N²)` दंड `N=256` सही पुष्टि करने के लिए, असली ऑडियो के लिए बेकार. असली कोड कॉल `numpy.fft.rfft` या `torch.fft.rfft`.

### चरण 4: प्रमुख आवृत्ति खोजें

परिमाण शिखर सूचकांक `k_star` आवृत्ति के मानचित्र `k_star * sr / N`440 हर्ट्ज सिनेस पर चलाने से बीन पर एक शिखर वापस आ जाएगा `440 * N / sr`.

### चरण 5: उपनाम का प्रदर्शन करें

नमूना ए 7 kHz 10 पर सिनेस kHz (Nyquist = 5 kHz) 7 kHz स्वर निक्विस्ट से ऊपर है और `10 − 7 = 3 kHz`. . . FFT शिखर 3 पर दिखाई देता है kHz. यह क्लासिक उपनाम डेमो है और कारण हर DAC/ADC ईंट-दीवार कम-पास फ़िल्टर के साथ जहाज।
