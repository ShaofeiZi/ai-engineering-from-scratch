## المفهوم

![شكل الموجات، أخذ العينات، DFT، و حاويات التردد المرئية](../assets/audio-fundamentals.svg)

**شكل الموجات** مجموعة واحدة من العوامل العائمة `[-1.0, 1.0]`.مؤشرًا حسب عدد العينة. لتحويل إلى ثواني، قم بتقسيمها بمعدل العينة: `t = n / sr`- مقطع 10 ثواني في 16 kHz هو مجموعة من 160,000 عائمة.

**معدل أخذ العينات (sr).** كم عدد العينات في الثانية؟

| السعر | الاستخدام |
|------|-----|
| 8 kHz | الهاتف، التراث VOIP. نيكوست في الرابعة kHz يقتل المتساويات. ASR. |
| 16 kHz | ASR "سيسبر" و "باراكيت" SeamlessM4T v2 جميعهم يستهلكون 16 kHz. |
| 22.05 kHz | TTS تدريبات المستخدمين في مجال المعلومات |
| 24 kHz | الحديثة TTS (كوكورو) F5-TTS, xTTS v2). |
| 44.1 kHz | CD audio, music. |
| 48 kHz | فيلم، صوت محترف، عالية الوفاء TTS (VALL-E 2, NaturalSpeech 3). |

**Nyquist-Shannon.** معدل العينة `sr` يمكن أن تمثل بشكل واضح ترددات تصل إلى `sr/2`- المُتَعَدِّدُ `sr/2` الحدود هي *تردد Nyquist*الطاقة فوق نيكوست تحصل *مستعار* ينحني إلى أسفل إلى ترددات أقل  ويفسد الإشارة. دائماً مرشح منخفض قبل أخذ العينات.

**عمق قليل** 16 بت PCM (موقعة) int16، النطاق ±32,767) هو تنسيق التبادل العالمي. DSP. المكتبات مثل `soundfile` قراءة int16 ولكن كشف float32 المصفوفات في `[-1, 1]`.

**تحويل فوريه** أي إشارة محدودة هي مجموع من السينوسايدات في ترددات مختلفة.DFT) الحسابات، `N` العينات `N` معدل معقد  واحد لكل قمامة ترددات. `bin k` خرائط التردد `k · sr / N` الحجم هو الطول عند تلك التردد، الزاوية هي المرحلة.

**FFT.** تحويل فوريه السريع: `O(N log N)` الخوارزمية لل DFT عندما `N` هو قوة 2 كل مكتبة صوتية تستخدم FFT تحت الغطاء. عينة 1024 FFT في 16 kHz يعطي 512 حاوية تردد قابلة للاستخدام تتراوح على 08 kHz عند درجة الحرارة 15.6 هرتز

**Framing + window.** نحن لا FFT شريط كامل، نقصمه إلى متداخل *الإطارات* (عادةً 25 ms مع 10 ms hop) ، مضاعفة كل إطار بمهمة نافذة (هان، هامينغ) لقتل عدم استمرارية الحافة، ثم FFT كل إطار. هذه هي تحويل فوريه القصير (STFTالدروس الثانية تبدأ من هنا

### الخطوة الثانية: قم بتجميع موجة السينوس من المبادئ الأولى

```python
import math

def sine(freq_hz, sr, seconds, amp=0.5):
    n = int(sr * seconds)
    return [amp * math.sin(2 * math.pi * freq_hz * i / sr) for i in range(n)]
```

صناعة 440 هرتز (موسيقى A) عند 16 kHz في ثواني واحدة هو 16000 عائم. اكتب مع `wave.open(..., "wb")` باستخدام 16 بت PCM التشفير

### الخطوة الثالثة: حساب DFT باليد

```python
def dft(x):
    N = len(x)
    out = []
    for k in range(N):
        re = sum(x[n] * math.cos(-2 * math.pi * k * n / N) for n in range(N))
        im = sum(x[n] * math.sin(-2 * math.pi * k * n / N) for n in range(N))
        out.append((re, im))
    return out
```

`O(N²)` - غرامة `N=256` للتأكيد على صحة، لا فائدة من الصوت الحقيقي. `numpy.fft.rfft` أو `torch.fft.rfft`.

### الخطوة الرابعة: العثور على التردد المهيمن

مؤشر ذروة الحجم `k_star` خرائط التردد `k_star * sr / N`إذا قمت بتشغيل هذا على 440 هرتز سينوس يجب أن يعود ذروة في القمامة `440 * N / sr`.

### الخطوة 5: إظهار التعبير

العينة 7 kHz السينوس عند 10 kHz (Nyquist = 5 kHz(السابع) kHz النغمة فوق Nyquist وتجمد إلى `10 − 7 = 3 kHz`- المُتَعَدِّدُ FFT ذروة تظهر في 3 kHz. هذا هو التجربة الكلاسيكية التجريبية والسبب كل DAC/ADC السفن ذات مرشح منخفض الممر.

## الشروط الرئيسية

| المدة | ما يقوله الناس | ما يعنيه هذا في الواقع |
|------|-----------------|-----------------------|
| معدل العينات | كم عدد العينات في الثانية | التردد في هرتز ADC يُقيّم الإشارة. |
| نيكوست | التردد القصوى الذي يمكنك أن تمثله | `sr/2`الطاقة فوقها تُعَوِّضُ إلى أسفل. |
| عمق قليل | قرار كل عينة | `int16` = 65,536 مستوى `float32` = دقة 24 بت في `[-1, 1]`. |
| DFT | تحويل فوريه لترتيبات | `N` العينات `N` معايير تردد معقدة. |
| FFT | الصيام DFT | `O(N log N)` الخوارزمية التي تتطلب `N` = قوة من 2. |
| "بين" | عمود التردد | `k · sr / N` Hz؛ تحديد = `sr / N`. |
| STFT | الطيف تحت الغطاء | Framed + windowed FFT مع مرور الوقت |
| التعبير | أشباح ترددات غريبة | الطاقة فوق نيكوست تتراجع إلى أسفل القمامة |
