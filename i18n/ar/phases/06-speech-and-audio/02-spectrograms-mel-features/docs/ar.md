## المشكلة

خذ 10 ثواني 16 kHz هذا هو 160,000 عائم، كل في `[-1, 1]`، لا علاقة لها بالكامل تقريباً بالعلامة "كلب يلعق" أو "الكلمة القطة". شكل الموجة الخام يحوي المعلومات ولكن في شكل لا يمكن أن يستخرجه النموذج بسهولة.

تصحيح جهاز الطيف هذا. إنه ينهار التفاصيل الزمنية حيث يتجاهلها الإدراك البشري (التزعج في ميكرو ثانية) ويحافظ على الهيكل الذي يشارك فيه الإدراك (التي تكون تردداتها قوية ، على نطاق نافذة زمنية ~ 1025 ms).

يضغط شبكات الطيف الميل إلى أبعد من ذلك. يدرك البشر النطاق اللوغاريثميًا: 100 هرتز مقابل 200 هرتز يسمع "المساواة بينهما" مثل 1000 هرتز مقابل 2000 هرتز. يلتوي مقياس الميل المحور الترددي لتطابقه. شبكات الطيف الميل هي الميزة الوحيدة الأكثر أهمية في الكلام ML من عام 2010 إلى عام 2026.

## المفهوم

![شكل الموجات إلى STFT إلى المجموعة المتطرفة إلى MFCC السلم](../assets/mel-features.svg)

**STFT (تحول فوريه قصير الوقت)** قطع شكل الموجة إلى إطارات متداخلة (معتاد: 25 ms نافذة، 10 ms hop = 400 عينات / 160 عينات عند 16 kHz) ضرب كل إطار من خلال وظيفة النافذة (هان هو الافتراض ؛ هامينغ التداول مختلف قليلا). FFT كل إطار. قم بتجميع الطيفات الكبيرة إلى ماتريكيس من الشكل `(n_frames, n_freq_bins)`هذه هي طيفك

**الكبيرة الحسابية** الحجم الخام يتراوح بين 5-6 ترتيبات من الحجم `log(|X| + 1e-6)` أو `20 * log10(|X|)` كل خط إنتاج يستخدم حجم الحسابات، وليس حجم الخام

**مقياس ميل** التردد `f` في خرائط Hz إلى mel `m` من `m = 2595 * log10(1 + f / 700)`الخريطة خطية تقريباً تحت 1 kHz و تقريباً لوغاريتميكية أعلاه. 80 مل بيني تغطي 08 kHz هو المعيار ASR المدخلات

**(ميل فيلتربانك)** مجموعة من المرشحات الثلاثية المتنافرة على قدم المساواة على مقياس ميل. كل مرشح هو مجموع وزن من المجاور FFT القمامة STFT الكبيرة من خلال المصفاة المصدرة يعطي طيف الميل في واحدة من الممل.

**-تطبيقات الطيف** `log(mel_spec + 1e-10)`دخول (فيسبر) ، دخول (باراكيت) SeamlessM4Tالمدخلات، الجهة الأمامية للصوت العالمي 2026

**MFCCs.** خذ طيف الملفات المختلفة، وطبق DCT (نوع IIيحتفظ المعدلات الثلاثة عشر الأولى. ينسجم الميزات ويضغطها بشكل أكبر. CNNsأجهزة تحويل على المواد الخام المضادة. لا تزال تستخدم في التعرف على المتحدثين (مقاطع x، ECAPA).

**تجارة القرارات** أكبر FFT = better إنّه من المُتَحَلّف أنّه يُحَلّفُ في التردّد، لكنّه من المُحَلّف أنّه في الوقت الأسوأ.ML افتراضياً: 50 ms / 12.5 ms للموسيقى ، 5 ms / 2 ms للتعرف على المقطع (ضربات الطبول ، الخصم).

## بناءها

### الخطوة الأولى: إطار شكل الموجة

```python
def frame(signal, frame_len, hop):
    n = 1 + (len(signal) - frame_len) // hop
    return [signal[i * hop : i * hop + frame_len] for i in range(n)]
```

10 ثواني 16 kHz المقطوعة مع `frame_len=400, hop=160` يُعطى 998 إطار

### الخطوة الثانية: نافذة هان

```python
import math

def hann(N):
    return [0.5 * (1 - math.cos(2 * math.pi * n / (N - 1))) for n in range(N)]
```

ضرب العنصر الحكيم قبل FFT. يزيل التسرب الطيفي الناجم عن التخفيض في نقاط نهاية غير صفر.

### الخطوة الثالثة: STFT الحجم

```python
def stft_magnitude(signal, frame_len=400, hop=160):
    win = hann(frame_len)
    frames = frame(signal, frame_len, hop)
    return [magnitudes(dft([w * s for w, s in zip(win, f)])) for f in frames]
```

### الخطوة الرابعة:

```python
def hz_to_mel(f):
    return 2595.0 * math.log10(1.0 + f / 700.0)

def mel_to_hz(m):
    return 700.0 * (10 ** (m / 2595.0) - 1)

def mel_filterbank(n_mels, n_fft, sr, fmin=0, fmax=None):
    fmax = fmax or sr / 2
    mels = [hz_to_mel(fmin) + (hz_to_mel(fmax) - hz_to_mel(fmin)) * i / (n_mels + 1)
            for i in range(n_mels + 2)]
    hzs = [mel_to_hz(m) for m in mels]
    bins = [int(h * n_fft / sr) for h in hzs]
    fb = [[0.0] * (n_fft // 2 + 1) for _ in range(n_mels)]
    for m in range(n_mels):
        for k in range(bins[m], bins[m + 1]):
            fb[m][k] = (k - bins[m]) / max(1, bins[m + 1] - bins[m])
        for k in range(bins[m + 1], bins[m + 2]):
            fb[m][k] = (bins[m + 2] - k) / max(1, bins[m + 2] - bins[m + 1])
    return fb
```

80 مل تغطي 08 kHz مع `n_fft=400` يعطي `(80, 201)` المصفوفة. ضرب المصفوفة `(n_frames, 201)` STFT الحجم من خلال الانتقال للحصول على `(n_frames, 80)` -ميل) ، (المتصفحات)

### الخطوة 5: المخططات

```python
def log_mel(mel_spec, eps=1e-10):
    return [[math.log(max(v, eps)) for v in frame] for frame in mel_spec]
```

البدائل الشائعة: `librosa.power_to_db` (المعادلة المرجعية) dB), `10 * log10(power + eps)`. يستخدم Whisper كليب أكثر إدماجًا + تطبيع روتين (انظر Whisper's `log_mel_spectrogram`).

### الخطوة السادسة: MFCCs

```python
def dct_ii(x, n_coeffs):
    N = len(x)
    return [
        sum(x[n] * math.cos(math.pi * k * (2 * n + 1) / (2 * N)) for n in range(N))
        for k in range(n_coeffs)
    ]
```

التطبيق DCT لكل إطار من المواد المعدنية، احتفظ بالعاملات الثلاثة عشر الأولى. MFCC المصفوف الأول عادة ما يُسقط (يتم تشفير الطاقة الإجمالية).

## الفخاخ التي لا تزال تشغل في عام 2026

- **-لا تتناسب مع عدد (ميل)** التدريب مع 80 ميل، الإستنتاج مع 128 ميل، فشل صامت، تسجيل الشكل المميز في كلا الطرفين.
- **عدم مطابقة معدل العينات فوق النهر** ميلس محاسبة عند 22.05 kHz تبدو مختلفة عن 16 kHz. إصلاح SR *قبل ذلك* التفاصيل
- **dB مقابل السجل** "السسسل" يتوقع "التسجيل" وليس dB-mel. بعضها HF خطوط الأنابيب تكتشف نفسها، رمزك الخاص لن يفعل.
- **التطبيع يتنقل** التطبيع في التدريب، التطبيع العالمي خلال الإستنتاج. WER.
- **تسرب من التشويش** إضافة الصفر إلى نهاية المقطوعة تنتج طيفاً مسطحاً في الإطارات المتأخرة.
