# MCP الموارد والإشارات: السياق المُعالج للخادمين العاطلين عن الجنسية

> أدوات تقوم بعمليات. الموارد تعرض المحتوى المُعالج. تطلب حزمة قوالب الرسائل التي حددها المستخدم. MCP الخادم يحافظ على تلك العقود منفصلة ومتوقعة.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 13, Lesson 07 (Building an MCP Server), Phase 13, Lesson 09 (MCP Transports)
**Time:** ~60 minutes

## أهداف التعلم

- اختر من بين الأدوات والموارد والإشارات من نية المستهلك.
- الإعلان عن الموارد والسطح السريع من خلال الإجبارية `server/discover`.
- بناء تحديد `resources/list` و `prompts/list` النتائج
- التطبيق `ttlMs` و `cacheScope` بدون تسريب بيانات محددة للمستخدم.
- العودة JSON-RPC خطأ `-32602` لمصدر غير صالح أو مجهول URI.
- افتح `subscriptions/listen` POST-response تحرك وتنسجم كل حدث عن طريق الاشتراك ID.
- تعامل محتوى الموارد والعلامات التشريعية على أنها خروج خادم غير موثوق بها.

## ابدأ من المستهلك

أسهل طريقة لإساءة استخدامها MCP يبدأ مع رمز التنفيذ. تصبح استفسار قاعدة البيانات أداة لأن الوظائف مألوفة. تصبح سير العمل القابل لإعادة الاستخدام مصدرًا لأنه يتم تخزينه في ملف. يصبح الإشارة سياسة مخفية لأن المضيف يمكنه حقنها.

ابدأ من يختار وما يتوقعه

| البدائية | النية الأساسية | صاحب الانتخابات | النتيجة النموذجية |
|---|---|---|---|
| الأداة | أداء عملية | النموذج أو التطبيق | نتيجة العمل المنظم |
| الموارد | قراءة المحتوى في URI | المضيف أو التطبيق أو المستخدم | النص أو المحتوى الثنائي |
| -أسرع | إطلاق سير عمل رسائل قابلة لإعادة الاستخدام | المستخدم عبر المضيف UI | رسالة واحدة أو أكثر |

ملاحظة في `notes://note-1` هو مصدر لأنه محتوى قابل للتعديل. `delete_note` هو أداة لأنه يغير الحالة. `review_note` هو طلب لأن المستخدم يختار سير عمل مراجعة جاهز.

لا تظهر عملية واحدة ككل ثلاثة فقط لتبدو كاملة. كل سطح إضافي يحتاج إلى اكتشاف، والإذن، والخزن الآلي، ومعالجة الأخطاء، والاختبارات، والوثائق.

## غلاف العدالة 2026-07-28

هذا الدروس يهدف MCP مراجعة البروتوكول `2026-07-28`لا توجد أي إضافة يد أو جلسة بروتوكول في هذا الملف. كل طلب يحمل نسخة بروتوكوله و قدرات العميل في محجوز `_meta` المفاتيح

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "resources/list",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/protocolVersion": "2026-07-28",
      "io.modelcontextprotocol/clientInfo": {
        "name": "course-client",
        "version": "1.0.0"
      },
      "io.modelcontextprotocol/clientCapabilities": {}
    }
  }
}
```

يجب على الخادم تنفيذ `server/discover`. إعلانات النتيجة مدعومة
الإصدارات، وقدرات الموارد والإسراع، و هوية التنفيذ،
يُمكن لعميل أن يطلب طريقة أخرى مباشرة، لكن الاكتشاف يعطيه
صورة دقيقة واحدة مستقرة قبل أن تبني UI.

```json
{
  "resultType": "complete",
  "supportedVersions": ["2026-07-28"],
  "capabilities": {
    "resources": {"listChanged": true, "subscribe": true},
    "prompts": {"listChanged": true}
  },
  "ttlMs": 3600000,
  "cacheScope": "public"
}
```

نتيجة طبيعية تعلن `"resultType": "complete"`ردّة `_meta` يحدد تنفيذ خدمة مع `io.modelcontextprotocol/serverInfo`هذه المعلومات مفيدة للتشخيص. انها ليست هوية التصديق. طلب يحمل مراجعة غير مدعومة يعود `-32022` مع كل من مراجعة الطلب والإصلاحات المدعومة من الخادم.

العقد غير الحكومي يغير غرائز التصميم الخاصة بك. ليست القائمة يمكن أن تعتمد على اتصال سابق على اتصال واحد. قد تغير الإذن مجموعة مرئية لأن الإثباتات هي إدخال طلب، ولكن تاريخ الاتصال لا يجب.

## الموارد مستقرة URI العقود

الموارد هي المحتوى الذي يتم تحديده بواسطة URI. تصميم URI قبل المدير

جيد URI الخصائص:

- مستقر بما فيه الكفاية لتعليق أو تمرير بين الطلبات.
- تم تحويل الاسم إلى نطاق الخادم
- مستقل عن عملية ID أو الاتصال
- تم التحقق من التحقق من الوصول إلى المخزن
- مُصرح بكل قراءة

`notes://note-1` هو أفضل من `note-1` لأن مساحة أسمائها واضحة. قد يستخدم خادم الملفات `file://` URIs، ولكن يجب أن تحقق بعد حل الروابط المماثلة والجزء النسبي حدود المجلد الموضحة.

`resources/list` يعيد الموارد التي تظهر حاليا للمتصل. يتم فرزها بواسطة مفتاح مستقرة مثل URI. النظام المحدد يمنع ضجيج التخزين الاحتياطي، وتغيير اللقطات الفورية، والضابط UIs تلك القفزة بين التجديدات

```json
{
  "resultType": "complete",
  "resources": [
    {
      "uri": "notes://note-1",
      "name": "Architecture decision",
      "description": "Why the service uses a stateless boundary",
      "mimeType": "text/markdown"
    }
  ],
  "ttlMs": 300000,
  "cacheScope": "public",
  "_meta": {
    "io.modelcontextprotocol/serverInfo": {
      "name": "notes-server",
      "version": "2.0.0"
    }
  }
}
```

`resources/read` يعيد عنصر أو أكثر من المحتويات. URI ليس قراءة فارغة ناجحة. تخصيص بيان الموارد الحالية الموردة غير صالحة أو مجهولة URIs إلى JSON-RPC المعلمات غير صالحة، الرمز `-32602`.

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "error": {
    "code": -32602,
    "message": "Unknown or invalid resource URI",
    "data": {
      "uri": "notes://missing"
    }
  }
}
```

هذا التمييز يسمح للعميل بفصل غياب من وثيقة فارغة سارية. كما يمنع الانكماش العشوائي إلى بحث أوسع.

### نماذج الموارد

نموذج الموارد يصف عائلة من المعلمات URIs. استخدم واحدة عند إدراج كل عنصر خرق أو غير محدود `notes://projects/{project}/decisions/{decision}` يخبر العميل كيفية تشكيل عنوان صالح دون إرجاع كل قرار

لا يضعف الشكل التحقق من التحقق. تحليل المتغيرات، وتطبيق الإذن، فرض حدود الطول والشخصيات، وبناء استفسارات التخزين مع المعلمات المكتوبة. لا تشبث أبداً سلسلة تعسفية URI التنقل إلى مسار نظام الملفات أو بيان قاعدة البيانات.

### المحتوى ليس تعليم موثوق به

قد يحتوي نص الموارد على حقن سريع أو أسرار أو أوامر مضللة أو علامات خاطئة. يجب على المضيف الحفاظ على منشأ المحتوى ومعاملة محتوى الموارد كبيانات. يجب على الخادم الحد من حجم المحتوى، وعودة دقيقة MIME النمط، إصلاح الحقول التي لا يستطيع المدعو الوصول إليها، وتجنب إرجاع السجلات غير ذات الصلة.

## الإشارات هي نماذج يتم التحكم فيها من قبل المستخدم

MCP يتم تصميم المفاوضات للتحديد الصريح للمستخدم. يمكن للمضيف أن يعرضها كإرشادات شرائح أو عناصر القائمة أو أزرار سير العمل. البروتوكول لا يتطلب واحدة UI.

`prompts/list` يجب أن تكون محددة لنفس إذن الطلب. كل طلب يحتاج إلى اسم ثابت وصف مفيد، وإعلانات الحجج التي تسمح للمضيف بجمع المدخل قبل `prompts/get`.

```json
{
  "resultType": "complete",
  "prompts": [
    {
      "name": "review_note",
      "title": "Review a note",
      "description": "Review one note for a named concern",
      "arguments": [
        {
          "name": "uri",
          "description": "The note resource URI",
          "required": true
        }
      ]
    }
  ],
  "ttlMs": 600000,
  "cacheScope": "public"
}
```

`prompts/get` يحل الحجج في الرسائل. لا يحل محل تعليمات النظام المضيف. يقرر المضيف كيفية إدخال الرسائل المرجعة في سياق النموذج ويضع سياسة الثقة الخاصة به في الأولوية العليا.

تأكييد الحجج المطلوبة في حدود الخادم. URI يجب أن يمر نفس فحص الإذن الذي يقرأه الموارد المباشرة. لا تجعل الإشارة قناة جانبية حول وصول الموارد.

## إشارات الاحتفاظ بها هي جزء من الصواب

`ttlMs` يخبر العميل كم من الوقت يمكن إعادة استخدام النتيجة. `cacheScope` يصف من قد يشارك هذه القيمة المحفوظة.

| نطاق العمل | المعنى | الاستخدام المميز |
|---|---|---|
| `public` | يمكن إعادة استخدامها عبر المستخدمين عندما تسمح الموافقة | الكتالوج العام للمساعدة |
| `private` | مقيدة على السياق المستخدم أو الإثباتات الطلبية | محتوى الملاحظات المملوكة للمستخدم |

اختر TTL من خلال معدل تغيير البيانات وتلف التأخير، قد تستغرق خمس دقائق كتالوجية سريعة عامة، وقد تستغرق ملاحظة خاصة دقيقة واحدة.

MCP يحدد فقط `public` و `private` كما `cacheScope` للنتيجة السرية أو المتغيرة بسرعة، العودة `cacheScope: "private"` مع `ttlMs: 0`، ثم تطبيق أي قاعدة أكثر صرامة لا تخزين في سياسة مخزن المضيف. `no-store` نفسها ليست MCP `cacheScope` قيمة

لا تحل إشارات الاحتفاظ بالمكان أبداً محل الإذن. يجب أن يتضمن مفتاح الاحتفاظ بالمكان كل بعد طلب يغير مرئية ، بما في ذلك المستأجر ، المستخدم ، النطاق ، المحلية ، ومركز البيانات. إذا لم يتمكن الاحتفاظ بالمكان المشترك من تعبير هذه الأبعاد بأمان ، فاستخدم `private` مع صفر TTL وسياسة عدم وجود متجر على مستوى المضيف

## الاشتراكات استخدام تدفق الاستجابة المفتوحة من العميل

النمط الحديث للتسجيل يحل محل السابق `resources/subscribe` RPC والقديم HTTP GET نقطة نهاية الحدث

العميل يرسل `subscriptions/listen` كالمعتاد JSON-RPC الطلب. عبر التسريب HTTP هذا هو POST والتي لا تزال ردودها مفتوحة ك SSE التيار `notifications` المواد هي قائمة السماح. يجب أن لا يقدم الخادم أنواع الإخطارات التي لم يتم طلبها.

```json
{
  "jsonrpc": "2.0",
  "id": 17,
  "method": "subscriptions/listen",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/protocolVersion": "2026-07-28",
      "io.modelcontextprotocol/clientCapabilities": {},
      "io.modelcontextprotocol/clientInfo": {
        "name": "course-client",
        "version": "1.0.0"
      }
    },
    "notifications": {
      "resourcesListChanged": true,
      "promptsListChanged": true,
      "resourceSubscriptions": [
        "notes://note-1"
      ]
    }
  }
}
```

الطلب ID هو الاشتراك ID. قبل أي حدث مطلوب، سيرفر `notifications/subscriptions/acknowledged`. فالتشريعه يحتوي فقط على مجموعة فرعية القبول بها الخادم

```json
{
  "jsonrpc": "2.0",
  "method": "notifications/subscriptions/acknowledged",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/subscriptionId": 17
    },
    "notifications": {
      "resourcesListChanged": true,
      "resourceSubscriptions": [
        "notes://note-1"
      ]
    }
  }
}
```

كل حدث لاحقا على هذا التيار يحمل نفس البيانات

```json
{
  "jsonrpc": "2.0",
  "method": "notifications/resources/updated",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/subscriptionId": 17
    },
    "uri": "notes://note-1"
  }
}
```

الإخطار يقول أن الموارد تغيرت العميل يقرأها مرة أخرى من خلال `resources/read`لا يفترض أن الحدث يحتوي على الوثيقة الجديدة.

يمكن لمعظم الاشتراكات مشاركة قناة استديو واحدة. ID يسمح للعميل بتخفيف عددهم HTTP، إغلاق تدفق الاستجابة إلغاء الاشتراك. خادم الذي ينتهي من تدفق يعود بجد `resultType: "complete"` رد مرتبط بالطلب الأصلي.

لا تستخدم تدفق الاشتراك كجلسة بروتوكول. القراءة اللاحقة لا تزال طلبًا كاملًا يمكن أن يصل إلى أي حالة خادم صحية.

## المختبر التفاعلي

استخدم الرقم لتصنيف خمسة قدرات من متابعة المشروع: تفاصيل الإصدار، إنشاء مشكلة، نموذج مراجعة السباق، سياسة المشروع، وإغلاق مشكلة. ثم تحدد أي القوائم يمكن تخزينها علنا، والتي يجب أن تبقى سرية، والموارد التي تستحق إشعارات تحديث.

لكل تصنيف، اسم المختار. إذا كان النموذج يؤدي إجراءً، استخدم أداة. إذا كان المضيف يقرأ URI-addressed إذا بدأ المستخدم سير عمل رسالة جاهزة، استخدم طلب.

## مختبر التدريب

تشغيل المحاكي من جذور المخبأ:

```bash
cd phases/13-tools-and-protocols/10-mcp-resources-and-prompts/code
python3 main.py
python3 -m unittest discover tests -v
```

تحقق من النسخة في هذا الترتيب:

1. تأكيد `server/discover` يعلن عن المراجعة الحالية وكلا الإمكانيات.
2. تأكد من أن نتائج القائمة مرتبة واستخدامها `resultType: "complete"`.
3. تأكيد القائمة و نتائج القراءة تحمل إشارات مخزنية متعمدة.
4. تغيير القراءة URI إلى `notes://missing` ولاحظ `-32602`.
5. تأكيد تأكيد الاشتراك قبل حدث الموارد.
6. تأكيد الحدث و إغلاق اللطف كل من تحمل الاشتراك ID `5`.

المُسَمِع Python النموذج لا يفتح حقيقية HTTP الاتصال. SDK يجب أن يضع على سلسلة الاستجابة المحددة حسب الطلب. SDK للصياغة والنقل في الإنتاج.

## اتصال كابستون

استخدم هذا العقد عندما يعرض خادم الحجر النهائي المعرفة المطلوبة بالإضافة إلى الإجراءات. URI قضية، ونسخة الاشتراك واحدة.

يجب أن تظهر أدلة أن أي قائمة تعتمد على تاريخ الاتصال وأن حدث الاشتراك لا يمنح أبداً الوصول إلى الموارد الأساسية.

## التمارين

1. إضافة `notes://projects/{project}/notes/{id}` نموذج الموارد وتؤكد على كلا المتغيرين.
2. إضافة صفحة إلى `resources/list` مع الحفاظ على النظام التحديدي
3. تغيير مصدر واحد إلى `cacheScope: "private"` مع `ttlMs: 0`، إضافة سياسة عدم وجود متجر على مستوى المضيف، وتفسير التهديد الذي يبرر كلا التحكمين.
4. إضافة اشتراك لتغيير قائمة الاستعلامات وإثبات عدم إرسال أي حدث عندما يفتقر المرشح `promptsListChanged`.
5. إعداد اشتراكات متزايدة و إثبات كل حدث يحمل الطلب الصحيح ID.
6. إضافة تفويض موضوع إلى المعاملة القراءة وإثبات إدخال التخزين الآلي لا يمكن أن تتقاطع الموضوعات.

## الشروط الرئيسية

- **المصدر:** URI-addressed المحتوى المعروض من قبل MCP الخادم
- **-أسرع** نموذج رسائل يسيطر عليها المستخدم MCP الخادم
- **قائمة تحديديات:** نتيجة اكتشاف مع عضوية مستقرة وتطلب نفس المدخلات الطلب.
- **`ttlMs`:** تخزين مدة الطفولة في الميلي ثانية
- **`cacheScope`:** الحدود المشتركة لنتائج مخزنة
- **`subscriptions/listen`:** طلب طويل الأمد يقدم تدفق الاستجابة فيه إخطارات مختصة صراحة.
- **الاشتراك ID:** طلب الاستماع الأصلي ID، تكرر في البيانات المعدنية للإخطار.
- **المعلمات غير الصالحة:** JSON-RPC خطأ `-32602`، تستخدم لمصدر غير صالح أو مجهول URI.
- **إصدار بروتوكول غير مدعوم:** JSON-RPC خطأ `-32022`، بما في ذلك `supported` و `requested` الإصلاحات
- **`server/discover`:** طريقة خادم إلزامية تعيد الإصلاحات المدعومة والقدرات والهوية والإشارات الاحتياطية الاختيارية.
