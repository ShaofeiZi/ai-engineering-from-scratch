# MCP عقود الأدوات والمحتوى

> أداة آمنة للتلقية فقط عندما يوافق اكتشاف، والحجج، والنتائج، والصفحات، ونقل البيانات المعدنية على عقد واحد.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 13, Lessons 07, 09, and 10
**Time:** ~120 minutes

## أهداف التعلم

- تحديد مدخلات وأخراجات الأدوات مع JSON المخطط 2020-12.
- التحقق من نتائج مهيكلة دون افتراض أنها JSON الأشياء
- اختر بين النص، الصورة، الصوت، روابط الموارد، والموارد المدمجة.
- رفض الخطر `x-mcp-header` التعريفات قبل أن تصل أداة إلى النموذج.
- قم بتشفير قيم المعايير-القب و التحقق من التساوي الدقيق من الرأس إلى الجسم.
- تعريف صفحات المؤشر عبر دون تفسير قيم المؤشر.
- التزامن والإذن `completion/complete` اقتراحات

## المشكلة

الاتصال Python الوظيفة سهلة. استدعاء قدرة عن بعد من خلال AI المضيف مشكلة في العقد

يقوم الخادم بنشر وصف. يقوم العميل بتحويل هذا المصف إلى سياق النموذج واجهة المستخدم. يقوم النموذج بإنشاء حجج. يمكن لبرة توجيه الطلب من رؤوس المرآة. يقوم الخادم بتنفيذ الأداة. ثم يقرر العميل ما إذا كانت النتيجة آمنة وموثوقة بما فيه الكفاية للعودة إلى النموذج.

الحدود الضعيفة واحدة تفسد السلسلة بأكملها

فلننظر إلى خمسة أخطاء:

- المصطلح يقول أن النتيجة هي كائن، ولكن الخادم يعيد صف.
- العميل يتوقف عن البحث عندما `nextCursor` هو سلسلة فارغة.
- يتم تعكس ملامح رمزية في HTTP و يصبح مرئيًا للمساومين.
- يتم إرسال قيمة توجيه يونيكود كقائمة خامة، ثم تفسير البوابة والمصدر بعبارات مختلفة.
- نقطة نهاية الانتهاء تشير إلى بيئة إنتاج للمتصلين الذين لا يستطيعون الوصول إليها.

لا يمكن إصلاح أي من هذه الفشلات من خلال تحذير أفضل.

## JSON المخطط هو حدود الوقت

في MCP `2026-07-28`, `inputSchema` و `outputSchema` استخدام JSON المخطط، متى `$schema` غائب، اللغة الافتراضية هي 2020-12.

يجب أن يكون مخطط الإدخال كائن مخطط. يجب أن تقول أداة بدون حجج ما يقبل به بالضبط:

```json
{
  "type": "object",
  "additionalProperties": false
}
```

هذا أكثر صرامة من `{ "type": "object" }`، والتي تقبل خصائص تعسفية.

مخطط الخروج اختياري. بمجرد نشر الخادم واحد، كل أداة كاملة
التزاما بالعودة المتماثلة `structuredContent`، بما في ذلك النتائج
مع `isError: true`. علامة الخطأ تصنف نتيجة التنفيذ؛ لا
التخلي عن عقد الإنتاج المنشورة. يجب على العملاء تحديد النتيجة بدلاً من ذلك
من الثقة بالوصف

### المحتوى المهيكلي هو أي JSON القيمة

لا تكتبوا شفرة صلبة `structuredContent` كقسم. يمكن أن يكون:

- كائن؛
- المجموعة
- حبل
- رقم؛
- (بوليان)
- `null`.

هذه الأداة تعيد صف:

```json
{
  "name": "tag_catalog",
  "inputSchema": {
    "type": "object",
    "additionalProperties": false
  },
  "outputSchema": {
    "type": "array",
    "items": {"type": "string"}
  }
}
```

النتيجة الناجحة لها صالحة:

```json
{
  "resultType": "complete",
  "content": [
    {
      "type": "text",
      "text": "[\"contracts\", \"mcp\", \"stateless\"]"
    }
  ],
  "structuredContent": ["contracts", "mcp", "stateless"],
  "isError": false
}
```

من أجل التوافق، يجب أن تشمل النتائج المهيكلة أيضاً التسلسل JSON في كتلة نصية. النص ليس مصدر التحقق. `structuredContent` -أجل

### مؤكد صغير لا يزال يعلم الحدود

الدرس يستخدم طريقة متعمدة JSON مجموعة فرعية من الخطة لأنه يبقى داخل Python المكتبة القياسية. فإنها تحقق من الآليات المستخدمة من أدوات العينة:

- النماذج الكائنة، والصف، والسلسلة، والعدد الكامل، والرقم، والبوليان، والصفر؛
- الخصائص المطلوبة
- `additionalProperties: false`;
- عناصر الترتيب
- قيم enum؛
- الحد الأدنى من طول السلسلة

هذا ليس بديلاً عن مؤكدة الإنتاج الكاملة، الدروس القابلة لإعادة الاستخدام هي حيث يحدث التحقق من التحقق من التحقق من التوصيفات، قبل تنفيذ الحجج، وقبل الاستهلاك للنتائج المهيكلة.

## تكلفة المكونات مختلفة

المُسَمِع `content` يمكن أن يجمع المجموعة بين عدة أنواع المحتوى.

| النوع | استخدمها | الحدود الرئيسية |
|------|------------|---------------|
| `text` | ملخصات يمكن قراءتها من قبل البشر والنموذج | تعامل النص كخروج غير موثوق به |
| `image` | الدليل البصري مرموز على base64 | تأكييد نوع وسائل الإعلام وحجمها |
| `audio` | المخرجات المتكلمة أو المسجلة مرموزة على base64 | تأكييد نوع وسائل الإعلام ومحدود مدة العمل |
| `resource_link` | A URI العميل قد يأتي لاحقاً | إعادة تفويض القراءة اللاحقة للموارد |
| `resource` | البيانات المدمجة مباشرة في النتيجة | فرض الحدود على الحمل المفيد والحجم الآن |

لا يثبت رابط الموارد أن الموارد تظهر في `resources/list`. هو مرجع يعود بهذه الدعوة الأداة. لا يزال العميل يطبق سياسة الموارد الخاصة به عندما يتبع URI.

يجنب الموارد المضمنة رحلة ذهابًا وإيابًا أخرى ولكنها تزيد من حجم الاستجابة الحالية. استخدم الروابط للأشياء الكبيرة أو المتغيرة بشكل مستقل. استخدم الموارد المضمنة للأدلة الصغيرة التي يجب أن تسافر بشكل ذري مع النتيجة.

الدرس هو `evidence_bundle` النتيجة تشمل جميع الأنواع الخمسة. يقوم العميل بتصديق كل كتلة قبل قبول النتيجة.

## `x-mcp-header` هل توجيه البيانات المعدنية

ملكية داخل `inputSchema` يمكن أن يعلن `x-mcp-header`- فوق المباشر HTTP، العميل يعكس هذه الحجة في `Mcp-Param-{name}`.

```json
{
  "region": {
    "type": "string",
    "x-mcp-header": "Region"
  }
}
```

مع `region: "eu-west"`، يمكن أن تنتج النقل:

```http
Mcp-Param-Region: eu-west
```

وتوجد الملاحظة بحيث يمكن للموازنة الحمولة أو البوابة أو محرك السياسة توجيه دون تحليل JSON ليس مكاناً لوضع شهادات إعتماد

البروتوكول يفرض القيود على التعليق:

- اسم العنوان غير فارغ ويتبع: HTTP النقاش الزمني لسمة الحقل
- أسماء العناوين فريدة من نوعها بغض النظر عن الحالة.
- نوع العقار هو سلسلة أو عدد كامل أو بولي
- `number` لا يُسمح بذلك.
- الملاحظة تظهر فقط على عضو مباشر من `inputSchema.properties`;
- قيم الأعداد الكاملة تبقى داخل `-9007199254740991` من خلال `9007199254740991`.

قاعدة الموقع هي نحوي وتغلق الفشل.
ليس فقط الخصائص التي يدركها مؤكّدك
التعليقات تحت كائن مستقر `properties`، أ `oneOf` الفرع `items`، أ
التعريف الذي تم التوصل إليه من قبل `$ref`، أو أي مخطط خروجي. حل مرجع لا
لا تحويل العقدة المرجعية إلى خاصية مباشرة من المستوى الأعلى.

هذا الدروس يضيف سياسة نشر: رفض وصفات التي تعكس أسماء مثل `password`, `secret`, `token`, `api_key`أو `authorization`المواصفات الرسمية تنصح مؤلفي الخادمين بعدم انعكاس المعايير الحساسة. يمكن للعميل تحويل هذه النصيحة إلى قاعدة صعبة.

تحقق من اسم العنوان، وليس قيمته. `Mcp-Param-Region` بينما تحافظ `eu-west` خارج حدث التدقيق.

### قيم تشفير قبل البناء HTTP العناوين

قيمة المعايير يمكن أن تسير كنص بسيط فقط عندما يكون سلسلة غير فارغة
من المرئي ASCII حرف من `!` من خلال `~` ولا يشبه
كل شيء آخر يستخدم هذا الشكل بالضبط:

```text
=?base64?{Base64UTF8}?=
```

`Base64UTF8` هو قياسي base64 أكثر من بالضبط UTF-8 البايتات لا تقطع
تعاديل أو استبدال القيمة أولاً.
علامات التبويب، وشخصيات التحكم، CR أو LF، أو المجال الأبيض المباشر أو المتأخر ، وأي
قيمة تبدأ `=?base64?`تشفير قيمة تبدو وكأنها حارس مرة أخرى
ما الذي يسمح للمستلم باسترداد النص الأصلي حرفيا بدلا من فك الشفرة
و هو كـ "نحو النقل"

الكلمات البولية تُسجّل بأحرف صغيرة `true` أو `false`. الأعداد الصحيحة التي تم إعطائها في القاعدة 10 و
يجب أن تبقى داخل JavaScript نطاق الأعداد الكاملة الآمنة. القيم خارج هذا النطاق
يتم رفضها بدلاً من تجويبها بواسطة وسيط.

## السلطات المكرمة لا تظهر

MCP عمليات القائمة تستخدم صفحات السيطرة. الخادم يختار حجم الصفحة ومصطلح السيطرة. يتم اتخاذ قرار واحد للعميل:

```python
if result.get("nextCursor") is None:
    break
cursor = result["nextCursor"]
```

لا تكتب هذا

```python
if not result.get("nextCursor"):
    break
```

السلسلة الفارغة هي مؤشر صالح، الحقيقة ستنتهي مبكراً جداً

يجب على العملاء عدم فك رمزية الوسيط ، أو زيادة ذلك ، أو مقارنته مع السيطرة السابقة للطلب ، أو استنباط رقم الصفحة. يمكن للخادم توقيع السيطرة ، أو ربطها بإصدار الكتالوج ، أو خريطه إلى حالة خاصة. هذا هو تفاصيل تنفيذ الخادم.

الخادم العينية يعود عمدا `""` بعد الصفحة الأولى يجب على العميل إرسال هذا القيمة الدقيقة في الطلب الثاني.

```text
<first request with no cursor>
<second request with cursor "">
```

المعلمات غير صالحة تنتج JSON-RPC المعلمات غير صالحة، الرمز `-32602`.

## الانتهاء هو سطح تفويض

`completion/complete` يقدم اقتراحات للحجج السريعة وحجج نموذج الموارد. هو مفيد للشرائح التفاعلية، ولكنه يمكن أن تسرب الأسماء التي تحميها طرق القائمة العادية.

طلب الإكمال يذكر الإشارة والحجة التي يتم إكمالها:

```json
{
  "method": "completion/complete",
  "params": {
    "ref": {
      "type": "ref/prompt",
      "name": "deployment_review"
    },
    "argument": {
      "name": "environment",
      "value": "st"
    }
  }
}
```

النتيجة تعود إلى 100 قيم على الأكثر ويمكن أن تقرر `total` بالإضافة `hasMore`.

تطبيق نفس حدود الإذن المستخدمة من قبل المرجع أو الموارد. `development` و `staging`فقط المُشغل يمكنه أن يتلقّى `production`.

إن الانتهاء من الإنتاج يحتاج أيضاً إلى:

- التحقق من الصحة
- التصفية المعرفة على المكالمة
- طلب إزالة التكلفة في العميل
- الحد من المعدلات في الخادم
- عدد النتائج المحدودة
- السجلات التي لا تعرض قيم الإشارة الحساسة.

الإكمال هو المساعدة، وليس الاكتشافات المتحول.

## طبقتين من الأخطاء

حافظ على أخطاء البروتوكول منفصلة عن أخطاء تنفيذ الأداة.

استخدم JSON-RPC الخطأ عندما MCP لا يمكن إرسال الطلب بشكل صحيح:

- اسم الأداة غير معروفة
- شكل الطلب المخطط
- البيانات المعدنية المفقودة للطلب
- مؤشر غير صالح

استخدم نتيجة كاملة من الأدوات مع `isError: true` عندما وصل الدعوة إلى الأداة وتبلغ الأداة عن فشل يمكن القيام به:

- مصدر تقرير غير متوفر.
- التاريخ خارج النطاق المدعوم
- قاعدة تجارية ترفض العملية المطلوبة.

يمكن أن تقوم النماذج في كثير من الأحيان بإصلاح خطأ تنفيذ الأداة. لا يمكنها إصلاح خادم انتهك مخطط الخروج الخاص به.

إذا أعلنت الأداة مخطط الخروج، نموذج فشل قابل للتنفيذ داخل ذلك
النموذج `route_report` الفشل يعيد منطقته المطلوبة مع
`accepted: false`، إلى جانب نص خطأ يمكن قراءته من قبل الإنسان `isError: true`.

يقوم الخادم بتنفيذ:

  العائدات HTTP `400` بالإضافة JSON-RPC `-32020` في حالة عدم التطابق
- الإكمال المسموح به ومحدود بالحد من المعدلات.

العميل ينفذ:

- إدخال وصف؛
- الشجرة الكاملة `x-mcp-header` التحقق من التحقق من التمويل والسياسة الحساسة في المجال؛

- الحجة والتحقق من النتيجة
- التحقق من صحة كتلة المحتوى
- أحداث تدقيق الرأس التي تحتوي على أسماء ولكن لا قيم.

وصف غير آمن عمدا هو بيانات تعليمية. فإنه يثبت أن أداة واحدة رفض لا يمنع أدوات صالحة من تحميل.

3. استعادة النظام.
4. احتفظ بالصفحة الأولى `nextCursor` كما `""`، ثم أعيد الصفحة الأخيرة
   `nextCursor: None` بدلاً من إغفال الحقل
5. اجري الاختبارات وقارن آثار المؤشر
6. إضافة `x-mcp-header: "Authorization"` إلى خاصية سلسلة.
7. تصريح التأكيد الوصف الاعتراف يرفض قبل الدعوة.
8. حاولي `region` القيم التي تحتوي على Unicode، خط جديد، المساحات المحيطة بها، و
   النص المكتوب حرفياً `=?base64?SGVsbG8=?=`. فك كل عنوان إصدار و إثبات
   القيمة الأصلية تبقى دقيقة
9. تحريك الملحوظة تحت `oneOf`, `items`أو `$ref` تعريف، تأكيد
   يتم رفض كل وصف حتى لو لم تستخدم هذه الفرع من قبل الديمو.
10. إزالة العنوان المعترف به أو تغيير قيمته المفكورة. تأكيد HTTP
    حالة إرجاع الحدود `400` و JSON-RPC الرمز `-32020`.

النقطة ليست لتذكر JSON هو مشاهدة كل بوابة تفشل عند الحدود التي تمتلكها

## مختبر التدريب

تمديد مختبر العقد مع `search_evidence` أداة

المتطلبات:

1. مخطط إدخاله يقبل `query`, `limit`، و خزينة `region` حقل التوجيه
2. مخططها الخارجي هو مجموعة من الأشياء مع `uri`, `title`و `score`.
3. النتيجة تشمل نص التوافق ورابط الموارد لكل عنصر.
4. الادعاءات ترفض الخصائص غير المعروفة.
5. `limit` يتم تحديدها بموافقة الطلب.
6. المُتصل بدون إمكانية الوصول إلى واحد URI لا ترى ذلك أبداً URI من خلال الانتهاء أو إصدار الأداة.
7. تشمل الاختبارات نتيجة غير متوافقة، وتعليقًا غير صالحًا في العنوان، وقائمة من صفحتين.
8. اختبارات القيمة العنوان تغطي مرئية ASCII, يونيكود , حروف التحكم ,
   الفضاء الأبيض، النص الذي يبدو وكأنه حارس، وكلاهما JavaScript-safe حدود الأعداد الكاملة
9. المُسَمِع HTTP يقبل المكون أسماء العناوين غير الحساسة للقضية لكنه يرفض غيابها
   أو غير متطابقة القيم المعترف بها مع الوضع `400` و الرمز `-32020`.

## الأثاث المُرسل

`outputs/skill-mcp-contract-reviewer.md` هو مهارة مراجعة مسطحة قابلة للاستعمال مرة أخرى. أعطها وصف الأداة ، نتائج العينات ، سلوك البحركات ، وسياسة الإكمال. فإنه يعيد قرار القبول ، خطة تأكيد النتائج ، سياسة العنوان ، واختبارات الفشل الملموسة.

## تحقق من ذلك

الدرس يكمل عندما تكون هذه التصريحات صحيحة:

- `tools/list` يعود نفس الترتيب المنطقي على المكالمات المتكررة.
- يقوم العميل بطلب ثان عندما `nextCursor` هو `""`.
- يتم استبعاد وصف الرأس الحساس غير الآمن بينما تبقى الأدوات الأخرى متاحة.
- تعبر صف المخططات الخروج من صف.
- إنّه لا يُمكن أن يُمكنك أن تُعطي نفس النظام.
- لا يمكن أن تفرغ نتائج الخطأ أو تنتهك مخطط الخروج المنشورة.
- يصدق النص والصورة والصوت والرابط الموارد والبلوكات الموارد المضمنة.
- أحداث مراجعة العناوين تحتوي على أسماء ولا قيم.
- واضحة ASCII يبقى بسيطاً؛ يونيكود، التحكم، المملأ، الفارغ، و
  القيم التي تبدو وكأنها حارس base64 UTF-8 التشفير
- الأعداد الكاملة المرايا خارج JavaScript يتم رفض النطاق الآمن
- الإشارات تحت `oneOf`, `items`، الأشياء المربوطة `$ref` التعريفات، أو
  يتم رفض مخططات الناتج أثناء القبول.
- أسماء العناوين المعترف بها غير حساسة للقضية تم إدخالها فقط عندما يتم فك القيمة
  يطابق تماما الجسم، النسخة المفقودة أو غير المطابقة تنتج HTTP `400`
  و JSON-RPC `-32020`.
- لا يُرجع التكمل المحلل `production`.
- استخدامات فشل الأداة `isError: true`؛ استخدامات مكالمة بروتوكول خاطئة JSON-RPC `error`.

| الوسيط الفارغ المعامل كأكاذيب | الصفحات الأخيرة تختفي | استمر في كل مرة `nextCursor` موجودة وغير صفرية |
| القيمة الحساسة المرئية | السرّ يظهر في الوكالة، WAFأو بيانات تتبع | رفض المصطلح والحفاظ على السر في بيانات الطلب المحمية |
| أوراق يونيكود أو الفضاء الأبيض | البوابة والمصدر لا يتفقون أو يتم تعاديل القيمة | استخدم الدقة base64 UTF-8 تشفير المراقبة ومقارنة بعد تشفير |
| الملاحظات المخفية في فرع النظام | يفتقد العميل البيانات المباشرة أثناء القبول | عبر شجرة النظام بأكمله وسمح فقط خصائص المستوى العلوي المباشر |
| العد الأكمله الكبيرة المرآة | JavaScript الجولات الوسطى قيمة التوجيه | رفض القيم خارج JavaScript نطاق الأعداد الكاملة الآمنة |

| مخطط الخروج تم تجاهله | الكود التدريجي يستهلك بنية فاسدة | التحقق من التحقق من الصلاحية قبل استخدام النموذج أو التطبيق |

| الإكمال يشارك في اقتراحات عالمية | تسريب أسماء المستأجرين الخفية | التصفية حسب المدعو والمراجع والإذن |
| ملاحظات الأدوات التي تعتبر سياسة | عمليات تدمير تتجاوز تأكيد | إنفاذ الترخيص والإقرار خارج التعليقات |
| أداة واحدة غير مُصممة تُكسر الاكتشاف | الخادم بأكمله لا يتوفر | رفض الموصف السيئ والإدراج الأدوات الصالحة بشكل مستقل |

## اتصال كابستون

تحتاج الحجر النهائي للمرحلة 13 إلى بوابة يمكنها دمج الأدوات من عدة خوادم. هذه الدروس توفر جوهر القبول لها.

استخدم الأثاث لتصفية أربعة قطع من الأدلة:

- اكتشافات تحديدية ومكتملة من صفحات
- التحقق من المصادقة مع المصنف قبل التعرض للنموذج.
- المخرجات المهيكلة المصدقة بالإضافة إلى كتلة المحتوى المحدودة
- إكمال وتوجيه البيانات المعدنية التي تحافظ على حدود الترخيص.

لا تدعي مطابقة البوابة من الناجحة `tools/call` فقط. التقاط وصف، تتبع الصفحة، مجموعة أدوات مقبولة، مجموعة أدوات رفض، ونتيجة واحدة معتمدة.

## الشروط الرئيسية

| المدة | المعنى |
|------|---------|
| `inputSchema` | JSON شكل كائن يحدد حجج الأداة المقبولة |
| `outputSchema` | اختياري JSON تعريف النظام `structuredContent` |
| `structuredContent` | أيّة JSON القيمة التي تنتج عن طريق نتيجة الأداة |
| كتلة المحتوى | النص المطبوع، الصورة، الصوت، رابط الموارد، أو الموارد المضمنة |
| `x-mcp-header` | ملاحظة مخطط تعكس حجة بدائية في Streamable HTTP البيانات المعدنية |
| الوسيط الغامض | رمز الصفحة المصدر من الخادم الذي لا يفسر العميل قيمته |
| إشارة الإكمال | الاسم أو الموارد السريعة URI/المعينة التي يتم إكمال حججها |
| القبول | قرار العميل بإخفاء أو رفض وصف اكتشف |
