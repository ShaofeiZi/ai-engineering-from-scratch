# MCP التطبيقات على بروتوكول العدالة عن الجنسية

> النتيجة التفاعلية لا تزال MCP أداة وتبادل الموارد. 2026-07-28 النواة تجعل هذا التبادل مستقل، في حين أن التوسع التطبيقات يضيف سطح المصفحات مربع الرمال.

**Type:** Build
**Languages:** Python
**Prerequisites:** Phase 13 · 07 (MCP server), Phase 13 · 10 (resources)
**Time:** ~75 minutes

## أهداف التعلم

- الإعلان MCP التطبيقات من خلال `server/discover` وقدرات التوسع حسب الطلب.
- إعلان `ui://` الموارد على أداة قبل أن يتم استدعاء الأداة.
- أعيد نتائج الأداة والموارد الكاملة على سلك العزل 2026-07-28.
- فصل التطبيقات `ui/initialize` رسالة الجسر من المزيل MCP ضغط يد
- تطبيق التحقق من المصدر، وتصنيع الساندبوكس، CSP، وذوي أقصى امتيازات

## المشكلة

النتيجة النصية يمكن أن تصف خط زمني. لا يمكن أن تعطى للمستخدم خط زمني يمكن أن تصفح، التفتيش، أو التصرف على.

MCP تطبيقات تحل مشكلة العرض مع امتداد اختياري. تعريف الأداة يشير إلى `ui://` المضيف يمكن أن يحصل على الموردة ومراجعتها قبل تشغيل الأداة ، وتقديمها في إطار أفراد رمل ، ويتوسط جميع إجراءات التطبيق من خلال JSON-RPC -جسر

تم تغيير بروتوكول الأساس في 2026-07-28. لا تغلف تطبيقًا في دورة حياة الاتصال القديمة:

- لا يوجد جوهر `initialize` الطلب أو `notifications/initialized` الإخطار
- لا يوجد `Mcp-Session-Id` رأس
- كل طلب يحمل إصدار بروتوكول و قدرات العميل في `params._meta`.
- تنفيذ خادم `server/discover` حتى يتمكن العملاء من فحص الإصدارات والقدرات الأساسية والإضافات.
- كل نتيجة ناجحة لها `resultType` التمييز
- يمكن تشغيلها HTTP يستخدم واحد POST على الطلب GET و DELETE نقاط الدخول تعود 405.

على جسر التطبيقات لا يزال هناك طريقة تسمى `ui/initialize`إنه ينتمي إلى الإيفرام postMessage اللغة. لا يعيد إنشاء جوهر MCP جلسة

## المفهوم

### بروتوكولين، ميزة واحدة

أبقوا الطبقات واضحة:

1. المُسَمِع MCP الحاملات الأساسية `server/discover`, `tools/list`, `tools/call`, `resources/list`و `resources/read`.
2. المُسَمِع MCP إضافة التطبيقات تعلن UI و يحدد جسر الإطار إلى المضيف
3. قواعد مربع الرمل المتصفح تحد من ما UI يمكن أن تصل.

هوّة التوسع هي `io.modelcontextprotocol/ui`كلا النظاميين يختارون. العميل يرسل دعم التوسع داخل كائن القدرات على كل طلب:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "server/discover",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/protocolVersion": "2026-07-28",
      "io.modelcontextprotocol/clientCapabilities": {
        "extensions": {
          "io.modelcontextprotocol/ui": {}
        }
      },
      "io.modelcontextprotocol/clientInfo": {
        "name": "timeline-host",
        "version": "1.0.0"
      }
    }
  }
}
```

`clientInfo` يوصى به للتشخيص. إنها بيانات ذاتية الإبلاغ، وليس هوية تصريح.

### اكتشاف قبل الترجمة

نتيجة اكتشاف الخادم تعلن عن التوسع:

```json
{
  "resultType": "complete",
  "supportedVersions": ["2026-07-28"],
  "capabilities": {
    "tools": {},
    "resources": {},
    "extensions": {
      "io.modelcontextprotocol/ui": {}
    }
  },
  "ttlMs": 300000,
  "cacheScope": "public",
  "_meta": {
    "io.modelcontextprotocol/serverInfo": {
      "name": "timeline-app-server",
      "version": "2.0.0"
    }
  }
}
```

يجب على الخادم دعم الاكتشاف. لا يجبر العميل على استدعاء الاكتشاف قبل كل عمل لأن كل عمل يحمل قدراته الخاصة.

### إعلان UI بشأن تعريف الأداة

عقداً للتطبيقات الحديثة يربط UI إلى الأداة في `tools/list`:

```json
{
  "name": "notes_timeline",
  "description": "Render a timeline of notes.",
  "inputSchema": {
    "type": "object",
    "properties": {}
  },
  "_meta": {
    "ui": {
      "resourceUri": "ui://notes/timeline.html"
    }
  }
}
```

هذا هو عمدا قبل المكالمة المقدمة. يمكن للمضيف تحميل مسبق، التخزين الآلي، ومراجعة الأمن HTML قبل أن يطلب النتيجة عرضها. قد يتم قبول مفاتيح البيانات المتحركة القديمة بواسطة رمز التوافق ، ولكن يجب أن تنشر الخادمات الجديدة المضغوطة `_meta.ui.resourceUri` النموذج

`tools/list` يمكن التخفيض في النواة الحالية. `ttlMs`و `cacheScope`استخدم `private` عندما تختلف الأدوات المرئية حسب المستخدم أو الوهم.

### أعيد البيانات، ثم دع المضيف يربط الرؤية

يرد نداء الأداة المحتوى العادي بالإضافة إلى البيانات المهيكلة:

```json
{
  "resultType": "complete",
  "content": [
    {"type": "text", "text": "Timeline ready."}
  ],
  "structuredContent": {
    "notes": [
      {"id": "note-1", "title": "Discover", "created": "2026-07-28"}
    ]
  },
  "isError": false
}
```

المضيف يعرف بالفعل أي عرض ينتمي إلى الأداة. تجنب اختراع كتلة محتوى جديدة فقط لتكرار URI.

### استخدم التطبيق كمصدر

الخادم يعلن `resources` في اكتشاف، لذلك فإنه أيضا تنفيذ الاختبار الإلزامي `resources/list` وتشمل إدخال القائمة التحديدية القائمة على القنوات القنونية URI، اسم مستقر وصف ، و MIME النوع. نتيجة القائمة تشمل `resultType`، بيانات المستخدم المستخدمة `ttlMs`و `cacheScope`، تماماً مثل قائمة الأدوات التحديدية

المضيف يرسله `resources/read`على الموسيقى HTTP، يكون الطلب:

```text
POST /mcp
MCP-Protocol-Version: 2026-07-28
Mcp-Method: resources/read
Mcp-Name: ui://notes/timeline.html
```

قيم العنوان و JSON-RPC يجب أن تتطابق الجسم. `-32020`.

النتيجة تحتوي على HTML إشارات الموارد والخزنة:

```json
{
  "resultType": "complete",
  "contents": [
    {
      "uri": "ui://notes/timeline.html",
      "mimeType": "text/html;profile=mcp-app",
      "text": "<!doctype html>...",
      "_meta": {
        "ui": {
          "csp": {
            "connectDomains": [],
            "resourceDomains": [],
            "frameDomains": [],
            "baseUriDomains": []
          },
          "permissions": {}
        }
      }
    }
  ],
  "ttlMs": 60000,
  "cacheScope": "public"
}
```

### الاحتفاظ UI الموارد كمحتوى قابل للتنفيذ

موارد التطبيق لا يمكن التبادل مع النص العادي. إدخال التخزين الآلي يمكن تنفيذ رمز الجسر، وتقديم بيانات الأداة، وتطلب إجراءات منتظمة. مفتاحها من خلال القنوات القنونية `ui://` URI، والهوية والإصدار المعتمدة للخادم ، ومتلازمة محتوى الموارد ، و سياق الموافقة عندما `cacheScope` هو خاص. لا تستخدم أبداً موارد التطبيق الخاصة عبر المبادئ الأساسية لأن HTML أو قد تختلف البيانات المعدنية السياسية حتى عندما تكون URI هو نفس الشيء

إبطال الإدخال عندما يكون `ttlMs` تنتهي صلاحيتها، الأداة `_meta.ui.resourceUri` تغييرات ملزمة، إصدار الخادم أو تغييرات مدرجة تصريح المعتمدة، أو إشارة معترف بها لتغيير الموارد أسماء URI. إعادة التطبيق CSP لا يجب على إطار إيفريم قديم الاحتفاظ بإذنات أوسع فقط لأن نسخة مصدر جديدة لم يتم تحميلها بعد.

### صندوق الرمل هو الحدود، وليس حكم الثقة

مضيف يسيطر على iframe. التطبيق لا يمكن قراءة ملفات تعريف الارتباط المضيف مباشرة، التخزين المحلي، أو الصفحة DOM. كل عمل محظوظ يجب أن يعبر الجسر

استخدم هذه التشغيلات الافتراضية:

- أترك كل شيء CSP قائمة النطاقات فارغة ، ثم أضف فقط الأصول التي يحتاجها التطبيق. `connectDomains` للجلب XHRو WebSocketالاستخدام `resourceDomains` للخطوط، والأساليب، والصور، والخطوط.
- قم بتجميع الرمز والبيانات عندما يكون ذلك ممكناً
- لا تطلب أي تصريح للكاميرا أو الميكروفون أو الموقع إلا إذا كان هناك شيء مرئي يحتاجه.
- الـ "بين" `postMessage` إلى أصل أقرانه بالضبط ورفض الأحداث من كل أصل آخر
- تعامل معدل الأدوات، نتائج الأدوات، نص الموارد، ورسائل الجسر كإدخال غير موثوق به.
- الحفاظ على موافقة المستخدم في المضيف. لا يمكن أن يوافق الإطار على إجراءاتها التالية.

لا تُنسخ إصدار ثابت `sandbox` يجب على المضيف اختيار العلامات بناءً على نموذج أصل التطبيق وتصميم عزله الخاص.

المجال المسموح به لا يزال مسار التخريب `connectDomains: ["https://api.example.com"]` يعني أن أي نص يتم تنفيذه داخل التطبيق يمكنه إرسال البيانات المسموح بها هناك. يمنع التطابق الدقيق في المصدر الخلط في الوجهة، لكنه لا يقرر ما إذا كانت الحمولة المفيدة مناسبة. حافظ على إمكانية الوصول إلى الاتصال فارغة افتراضيًا ، وتجنب وضع رموز حامل في iframe ، وتشغيلات الضيقة من خلال المضيف عندما تكون عملية ، وتحديد حجم الاستجابة والطلب ، والتحقق من عمل المستخدم الذي أدى إلى كل طلب خارجي. العلاج `resourceDomains` بشكل منفصل عن `connectDomains`؛ يجب ألا يسمح الإذن بتحميل الخط أو النص بالتحميل التعسفي للبيانات.

### جسر التطبيقات له دورة حياة خاصة به

جسر التطبيقات هو JSON-RPC اللغة فوق `postMessage`يمكن أن يتبادل `ui/initialize` و `ui/*` الإخطارات ويمكن أن النظام الأساسي الأساليب التي تبدو مثل `tools/call`.

الرؤية تُرسل `ui/initialize` مع `appInfo` و `appCapabilities` المضيف يعيد قدراته و سياق المضيف. فقط بعد ذلك الإجابة يرسل المشاهدة `ui/notifications/initialized`يجب على المضيف الانتظار لهذا الإخطار قبل إرسال الرسائل إلى المشاهدة.

هذا المصافحة المحلية تخلق جسرا بين إيفرام واحد وإطار مضيف واحد. MCP إصدار بروتوكول، إنشاء حالة الخادم، أو وضع جلسة النقل. لاحظ المقبلة الدقيقة: `notifications/initialized` تم إزالة ، بينما تطبيقات `ui/notifications/initialized` طلب أساسي الذي يولد من خلال نداء أداة جبر هو طلب جديد مستقل مع طلب جديد JSON-RPC بيانات الهوية والبيانات المكتملة للمطالبة

### السياق المضيف والإجراءات والإلغاء

يظل المضيف هو السلطة بعد تشغيل الجسر. يمكن للمشاهدة طلب إجراء أداة أو التنقل أو استخدام لوحة المقطوعة أو تأثير امتياز آخر فقط من خلال قدرة يعلن عنها المضيف. يؤكد المضيف الطلب المطبوع والمستخدم الحالي والهدف والحجج ، ويطبق سياسة الموافقة ، ويمكنه رفضه. تنقر زر نقرة رسالة الجسر صالحة على نية تعبير ؛ لا يمنح أي منها السلطة.

تعامل الموضوع والحجم والوصول إلى النطاق المتغير للمضيف بدلاً من إدخال الإصدار المفرد:

- تطبيق رموز الألوان والطباعة التي يقدمها المضيف، ثم التفاعل عندما تتغير تفضيلات الموضوع أو التناقض.
- دع المشاهدة تقرير الأبعاد المرغوبة، ولكن دع المضيف القفز وتطبيق حجم iframe حتى المحتوى لا يمكن أن تفلت من التخطيط أو خلق التداخلات الخادعة.
- الحفاظ على ترتيب لوحة المفاتيح، والتركيز المرئي، والأسماء المتاحة، وحالة قارئ الشاشة، والتباين الكافي، والزيادة، والسلوك الحد من الحركة داخل iframe.
- إعادة اختبار نقل التركيز بين عناصر التحكم في المضيف و إدارة المشاهدة بعد تغيير الحجم وإعادة تقديمها.

يمكن إلغاء القدرات أثناء فتح التطبيق لأن المستخدم يغير الحساب أو تغييرات في السياسة أو يتم تعقيد خادم أو يضييق المضيف الموافقة. تحقق من القدرة والإذن في وقت العمل ، وليس فقط أثناء `ui/initialize`عند الإلغاء، رفض المكالمات المتميزة المنتظرة، وقف نشاط الشبكة التي لم تعد تناسب السياسة، تنظيف الحالة الحساسة المقدمة، وإعادة التثبيت أو الانسحاب إلى النص عندما UI لم يعد المورد نفسه مسموح به. يجب على عرض التعامل مع الرفض كنتيجة طبيعية، وليس محاولة ثانية حتى يستسلم المضيف.

### الاحتمالات العائدة جزء من العقد

يمكن لخادم مطلع على التطبيقات أن يخدم مستضيفين لا يعلنون عن UI التوسع:

- أعد نفس الأداة بدون `_meta.ui` في `tools/list`.
- الحفاظ على النتيجة النصية المفيدة `tools/call`.
- رفض `resources/read` لـ UI مع خطأ في القدرة المفقودة.
- لا نفترض أبدا وجود iframe عند اتخاذ قرار بشأن إتمام الأداة.

```figure
t3-ui-sandbox
```

## بناءها

`code/main.py` يُبني نموذج بروتوكول صغير في العملية دون SDK. يصدق على ملف الطلب الحالي و Streamable HTTP قيم التوجيه، الإعلانات التطبيقات من خلال `server/discover`، يردد الأدوات والموارد، وينفذ الأداة، ويعمل على HTML الموارد

يتلقى النموذج أجسامًا تم تحليلها بالفعل و عناوين توجيه. HTTP المعدل ولا يحلل `Content-Type` أو `Accept`. استخدم الدروس 09 لتحقيق التسريب الكامل HTTP المعدل الذي يتطلب `Content-Type: application/json` و `Accept` القيمة التي تحتوي على كلتا `application/json` و `text/event-stream`.

إشغله

```bash
cd phases/13-tools-and-protocols/14-mcp-apps
python3 code/main.py
python3 -m unittest discover code/tests -v
```

تحقق من أربعة أشياء في الخروج:

1. كل مكالمة مستقلة
2. كل طلب لديه `_meta` القدرات
3. `resources/list` يعيد وصف مستقر قبل أي قراءة للموارد.
4. كل نتيجة لها `resultType` و البيانات المعدنية لتحديد هوية الخادم
5. لا يظهر أي معرف الجلسة الأساسية.

## استخدمها

ابدأ `server/discover`تأكّد `io.modelcontextprotocol/ui` يظهر في خريطة امتداد الخادم. ثم الاتصال `tools/list` مرتين، مرة مع قدرة التطبيقات ومرة بدونها. الإجابة الأولى تعلن الموارد. الثانية تظل أداة نصية فقط قابلة للاستخدام.

اقرأ `ui://notes/timeline.html`- أبحثوا في HTML لـ `hostOrigin` و `event.origin` هذه الخطتين هي أدنى دليل مرئي على أن الجسر لا يستخدم هدفًا

## التمارين

1. تغيير قدرة العميل إلى خريطة امتداد فارغة. تأكيد `tools/list` يحتفظ الأداة لكنه يزيل UI ملزمة
2. أرسل `Mcp-Name: ui://notes/other.html` مع جسم يقرأ الخط الزمني. تأكيد الخطأ `-32020`.
3. تغيير الموارد إلى `cacheScope: private`. وصف حالة المستخدم المحددة التي تبرهن ذلك.
4. تحرك النص إلى `https://static.example.com/app.js`إضافة هذا الأصل إلى `resourceDomains` ويشرح مخاطر سلسلة التوريد الجديدة
5. إضافة `notes_open` أداة وتوجيه زر النقل من خلال المضيف. الحفاظ على موافقة المستخدم في المضيف.

## الشروط الرئيسية

| المدة | المعنى |
|------|---------|
| MCP التطبيقات | التوسع الاختياري للاتصال التفاعلي HTML تم تقديمه من قبل MCP المضيف |
| `io.modelcontextprotocol/ui` | معرف التوسع الذي يعلن عنه كلا الأقران |
| `ui://` | نظام الموارد لـ App UI القالب |
| `text/html;profile=mcp-app` | MIME نوع لل MCP التطبيق HTML |
| `server/discover` | الحالي RPC للاكتشاف البروتوكول والقدرة |
| `resources/list` | طريقة إدراج الموارد الإلزامية عندما يعلن الخادم عن الموارد |
| `resultType` | المتميز المطلوب لنتائج ناجحة حديثة |
| `ui/initialize` | طلب أول تطبيقات الجسر ، منفصل عن إزالة البداية الأساسية |
| `ui/notifications/initialized` | تطبيقات عرض إشعار الاستعداد المرسل بعد استجابة المضيف |
| CSP | سياسة المتصفح التي تقيد النصوص والأساليب والصور وأصل الشبكة |
| إرجاع النص | سلوك الأداة المحفوظة لضيف بدون دعم التطبيقات |
