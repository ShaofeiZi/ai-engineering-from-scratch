# LLM طبقة التوجيه LiteLLM, OpenRouter(بورتكي)

> إغلاق مزود مكلف. تحميلات عمل مختلفة للدعوة إلى الأدوات تناسب نماذج مختلفة. بوابات التوجيه تعطى واحدة API السطح، التجربات المُرجّعة، الإفشل، تتبع التكاليف، والحواجز. ثلاثة أنواع رئيسية تهيمن على عام 2026: LiteLLM (مصدر مفتوحة تستضيف نفسها) ، OpenRouter (مدارة) SaaS), Portkey (معدل الإنتاج، مفتوح المصدر في مارس 2026). هذه الدروس تعطي أسماء لمعايير القرار وتشغل بوابة توجيهية.

**Type:** Learn
**Languages:** Python (stdlib, routing + failover + cost tracker)
**Prerequisites:** Phase 13 · 02 (function calling), Phase 13 · 17 (gateways)
**Time:** ~45 minutes

## أهداف التعلم

- تمييز خيارات التوجيه المضيفة الذاتية والمتدارة ومرحلة الإنتاج.
- تنفيذ سلسلة إرجاعية تستعيد فشل المزودين في ترتيب أولويات محدد.
- تتبع تكلفة الطلب واستخدام الرمز بين المقدمين.
- قرر بين LiteLLM, OpenRouterو (بورتكي) لقيود إنتاج معينة

## المشكلة

سيناريوهات حيث يكون التوجيه للمزود مهم:

1. **تكلفة** Claude سعر الصوت ثلاث مرات تكلفة هايكو، لمهام التجديد، هيكو كافية، لمهام التجميع، سعر الصوت يستحق ذلك.

2. **الفشل** OpenAI كل طلب يفشل تريد ان تعود تلقائيًا إلى Anthropic بدون إعادة نشر

3. **التأخير** دردشة مباشرة UI تحتاج إلى وقت سريع إلى أول رمز. لا مخطط لفة. طريق من خلال التأخير SLA.

4. **التوافق** EU يجب على المستخدمين البقاء في EU مناطق، مسار حسب المنطقة

5. **التجربة** طرازين على نفس الحمل، طريقًا بتحديد المختبرات

التشفير اليدوي لكل هذا لكل تكامل هو متكرر. بوابة توجيه يعطي واحد OpenAI-compatible API ويتولى الباقي

## المفهوم

### OpenAI-compatible شكل النظام

الجميع يتحدث OpenAI-shape. بوابة التوجيه تعرض `/v1/chat/completions`، يقبل OpenAI النظام، والوكالات الداخلية إلى Anthropic / Gemini (كوهير) ، (أولاما) ، أي شيء، العميل لا يهتم

### الاسم الاسمية النموذجية

بدلاً من تحديد المقطع، رمزك يقول `our_smart_model`عندما يقوم مزود بعمل جيل جديد، تغير اسم الخادم الجانب؛ رمزك لا يلمس شيئا.

### السلاسل الخلفية

```
primary: openai/gpt-4o
on 5xx: anthropic/claude-3-5-sonnet
on 5xx: google/gemini-1.5-pro
on 5xx: refuse
```

و يحدد البوابات هذا في إعداد، وتعد التجربات المتأخرة مقابل ميزانية حتى لا تنفجر التكاليف.

### الاحتفاظ بالتخزين

يصل الإشارات المتماثلة أو شبه المتماثلة إلى التخزين بدلاً من المقدم. يمكن أن تكون التوفيرات على حلقات الوكيل المتكررة 30 إلى 60 في المائة. المفاتيح تستند إلى التضمين. تشترك الإشارات المتماثلة تقريباً في فتحة التخزين.

### الحراسة

مستوى البوابة:

- **PII تحرير** (ريجكس) أو ML-based تمر قبل إرسال الإشارات
- **انتهاكات سياسية** رفض الإشارات التي تحتوي على محتوى محظور
- **مرشحات الخروج** أزفوا الأجزاء من أجل التسرب

(بورتكي) و (كونغ) كلاهما يمتلكان حواجز حراسية LiteLLM يتركهم اختيارياً

### حدود أسعار كل مفتاح

واحد API key = one الميزانيات لكل مفتاح تمنع فريق واحد من استهلاك الحصة المشتركة معظم البوابات تدعم هذا

### التداولات المضيفة ذاتيا مقابل التداولات المدارة

| العامل | LiteLLM (مضيفة ذاتية) | OpenRouter (managed) | (إنتاج) |
|--------|----------------------|----------------------|----------------------|
| الرمز | المصدر المفتوح Python | إدارة SaaS | Open source (Mar 2026) + managed |
| الإعداد | تنشر وكيل | إلتحق | إما |
| المقدمين | 100+ | 300+ | 100+ |
| الفواتير | مفاتيحك الخاصة | OpenRouter الإئتمانات | مفاتيحك الخاصة |
| الملاحظة | OpenTelemetry | لوحة التحكم | كامل OTel + PII تحرير |
| أفضل من ذلك | فرق تريد السيطرة الكاملة | النماذج الأولية السريعة | إنتاج مع الامتثال |

LiteLLM فاز عندما يكون لديك SRE فريق و يريدون سيادة البيانات OpenRouter فوزت عندما تريد اشتراكا واحدا و لا يوجد إضفاء التضارب

### تتبع التكاليف

كل طلب يحمل `provider`, `model`, `input_tokens`, `output_tokens`. مضاعفة بالأسعار لكل نموذج لكل رمز (مستمدة من ورقة الأسعار التي يحتفظ بها البوابة).

### MCP بالإضافة إلى التوجيه

بوابة يمكن أن يتوجه كلاهما LLM المكالمات AND MCP طلبات أخذ العينات. عندما يتم طلب أخذ العينات modelPreferences يفضل نموذج محدد، ويتم ترجمة البوابة إلى الخلفية اليمنى.MCP وبوابة توجيه هذه الدروس في بعض الأحيان تتجمع في خدمة واحدة.

### استراتيجيات التوجيه

- **الأولوية ثابتة** أول من قائمة، تراجع عن الخطأ.
- **توازن الحمولة** - كرة حلقة أو مُزنة
- **-تعاطف التكلفة** اختر أرخص نموذج لقاء تأخير / جودة.
- **-مُتعاطفٌ بالبطء** اختر أسرع طراز في آخر 9 دقائق
- **-مُتوعّد بالمهمة** طرق التصنيف السريع التشفير إلى نموذج واحد، والتمويل إلى آخر.

```figure
tp-router-failover
```

## استخدمها

`code/main.py` يطبق بوابة توجيه في ~ 150 خط: يقبل OpenAI-shaped تترجم إلى أجزاء لكل مزود، وتشغل سلسلة إرجاع الأولوية، وتتبع تكلفة كل طلب، وتطبق PII إرسال إصدار إدخالات. إشغيله مع ثلاثة سيناريوهات: طلب طبيعي، انقطاع مزود أساسي يسبب الإعاقة، PII تسريبات تم التقاطها من خلال تحرير.

ما الذي يجب أن ننظر إليه:

- `ROUTES` dict: alias -> قائمة مقدمي الخدمات المحددة حسب الأولوية.
- حاولوا مرة أخرى على 5xx
- متابعة التكاليف تضاعف استخدام الرمز بالأسعار لكل نموذج.
- PII ملفات تحرير SSN-shaped الأنماط قبل الإرسال.
