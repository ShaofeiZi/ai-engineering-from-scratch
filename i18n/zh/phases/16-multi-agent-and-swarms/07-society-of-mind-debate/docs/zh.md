# 心智社会与多智能体辩论

> 明斯基在 1986 年提出：智能是一个由专家组成的社会。这个想法几乎每十年都会被重新发现一次。到了 2023 年，Du 等人把它变成了具体算法：多个 LLM 实例先各自提出答案，再互相阅读、批评并更新答案。经过 N 轮之后，它们会收敛到一个共识，而这个共识在六项推理与事实性任务上都优于零样本思维链和自我反思。有两个发现尤其重要：**多个智能体**和**多个轮次**都会独立带来提升。智能体“社会”优于单个智能体的独白，多轮交流又优于一次性投票。

**Type:** 学习 + 构建
**Languages:** Python（标准库）
**Prerequisites:** 第 16 阶段 · 04（原语模型）
**Time:** 约 60 分钟

## 问题

自洽性（self-consistency），也就是从同一个模型中多次采样再取多数答案，是成本最低的推理增强手段之一。它确实有效，但很快就会进入平台期：即使把采样数翻倍，也未必还能获得有意义的提升。

辩论可以突破这个平台期。它不再从同一个模型取得 N 个彼此独立的样本，而是让 N 个智能体阅读彼此的推理并修正答案。样本不再独立同分布，智能体之间的交流会改变误差相关性；原本独立投票会“自信地答错”的问题，经过辩论后往往能收敛到正确答案。

## 概念

### Du 等人 2023 年提出的算法

出自 arXiv:2305.14325（ICML 2024）：

1. N 个智能体各自先对问题给出初始答案。
2. 从第 r = 2..R 轮开始，每个智能体都会看到其他智能体在第 r-1 轮的答案，并被要求“考虑这些观点后，给出更新后的答案”。
3. 在 R 轮结束后，对最终答案做多数投票。

论文在 MMLU、GSM8K、人物传记、MATH 和事实性基准上进行了测试。结果显示，多智能体辩论稳定优于思维链和自我反思。

### 两个相互独立的调节因素

同一篇论文里的消融实验显示：

- **只增加智能体数量**（1 轮，对 N 个答案做多数投票）在大多数任务上都比单个智能体更强，但很快会进入平台期。
- **只增加轮数**（1 个智能体反复查看自己前一轮的推理）提升很有限，这正是自我反思的已知弱点。
- **两者同时增加**才会带来明显跃升。真正推动收益的是多个智能体之间的多轮交流。

### 为什么有效

有两个机制在起作用：

1. **接触不同意见。** 当一个智能体看到另一个智能体给出了不同结论的推理链时，它必须为自己的答案辩护或更新观点。无论选择哪一种，第 r+1 轮的上下文都比第 r 轮更丰富。
2. **降低错误相关性。** 在自洽性方法中，所有样本都来自同一个模型，因此错误天然相关，投票可能只是把多次错误汇成一个“很有信心但依然错误”的答案。不同模型或不同随机种子会降低相关性，经过辩论形成的不同观点则会进一步降低相关性。

### 异质辩论

A-HMAD 以及相关后续工作会让不同智能体使用*不同的基座模型*。例如让 Llama、Claude 与 GPT 一起参与辩论，可以降低单一模型文化崩溃（第 26 课）的风险，因为一个模型家族中的相关错误不会被其他模型家族共享。

缺点是，较弱的模型参与辩论时，也可能把共识拖向自己的错误答案。参见《Should we be going MAD?》（arXiv:2311.17371）。

### NLSOM：扩展到 129 个智能体

Zhuge 等人在《Mindstorms in Natural Language-Based Societies of Mind》（arXiv:2305.17066）中把这个想法扩展到了 129 个成员的社会。结果显示，随着规模上升，专业化与自组织开始出现，而且系统在视觉问答等任务上优于单个智能体。

### 失败模式

- **谄媚级联。** 所有智能体都开始迎合听起来最自信的那个智能体，辩论退化成“谁声音最大谁赢”。一种有效的缓解方法是加入对抗角色提示，例如“必须有一个智能体始终为反方辩护”。
- **话题漂移。** 辩论轮数一多，就会逐渐偏离原始问题。缓解方式是每一轮都重新注入原问题。
- **计算量爆炸。** N 个智能体进行 R 轮辩论，就意味着 N·R 次 LLM 调用，而且每次调用的上下文还在增长。一次由 5 个智能体参与、持续 5 轮的辩论会产生 25 次调用，成本很容易超过单次思维链调用的 10 倍。

## 动手构建

`code/main.py` 会在一道数学题上运行一次由 3 个智能体参与、持续 3 轮的辩论。每个智能体起始时都有不同答案，其中一些可能是错的。智能体由脚本驱动：每个智能体会根据预设置信度，对相邻智能体的答案做加权平均，以此“更新”自己的答案。你可以在逐轮日志中直接看到收敛过程。

这个演示展示了两个关键现象：

- 一轮交流就能让智能体更接近正确答案。
- 超过第 2 轮之后，额外轮次的收益开始明显递减，这与 Du 等人的平台期结论一致。

运行：

```
python3 code/main.py
```

## 实际使用

`outputs/skill-debate-configurator.md` 可以为新任务配置辩论：智能体数量、轮数、异构性（相同模型还是混合模型）、角色分配（对称角色还是加入一个对抗角色）。它还会在运行前预估 token 成本。

## 交付成果

如果要把辩论系统真正上线：

- **轮数最多为 3。** Du 等人表明，3 轮已经获得大部分收益。继续增加的主要是成本，而不是质量。
- **智能体最多为 5 个。** 超过 5 个后，上下文膨胀和成本会压倒收益。
- **默认采用异质组合。** 池中至少使用两种不同的基座模型。
- **设置对抗席位。** 明确提示某个智能体始终提出异议，以打破谄媚倾向。
- **记录每一轮。** 如果中间轮次不可见，系统既无法调试，也无法审计。

## 练习

1. 运行 `code/main.py`，再把轮数调到 5，观察收益递减。到了第几轮之后，进一步收敛就停止了？
2. 加入第四个代理，并赋予它对抗角色：始终反对当前多数。这样会破坏收敛还是改善收敛？
3. 绘制（或打印）每一轮的 agreement score，也就是站在多数答案上的代理占比。它在什么时候达到 1.0？而达到 1.0 是否就等价于“答案正确”？
4. 阅读 Du et al. Section 4 的消融实验，用这份代码复现 “agents-only” vs “rounds-only” vs “both” 的结果。
5. 阅读 “Should we be going MAD?”（arXiv:2311.17371），列出两种 round-robin 之外的辩论变体，例如 judge-led、chain-of-debate、adversarial。

## 关键术语

| 术语 | 常见说法 | 实际含义 |
|------|----------------|------------------------|
| 心智社会 | “明斯基的思想” | 智能由相互作用的专家组成；1986 年的构想如今通过 LLM 辩论得到具体实现。 |
| 多智能体辩论 | “智能体相互争论” | N 个智能体提出答案、互相批评，并在 R 轮中修订，最后进行多数投票。 |
| 共识 | “它们意见一致” | 并不等于认识论上的真理，只是选择多数答案的智能体所占比例；也可能“自信地答错”。 |
| 轮次 | “交流步骤” | 一轮指每个智能体读取其他智能体的答案并更新一次。 |
| 异质辩论 | “混合不同模型家族” | 通过使用不同基座模型来降低错误相关性。 |
| 谄媚级联 | “所有人都附和声音最大的那个” | 一种辩论失败：智能体不论对错，都开始迎合最自信的智能体。 |
| NLSOM | “129 个智能体组成的社会” | 自然语言心智社会，即 Zhuge 等人提出的大规模版本。 |
| 相关错误 | “同一模型，同一缺陷” | 它解释了自洽性为何会进入平台期；让不同观点相互辩论可以降低这种相关性。 |
