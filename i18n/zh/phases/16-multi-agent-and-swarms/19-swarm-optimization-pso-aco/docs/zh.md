# 面向 LLM 的群体优化（PSO、ACO）

> 仿生优化正在 LLM 领域重新兴起。**LMPSO**（arXiv:2504.09247）采用 PSO，其中每个粒子的速度由提示表示，LLM 负责生成下一个候选项；这种方法尤其适合结构化序列输出（数学表达式、程序）。**Model Swarms**（arXiv:2410.11163）把每个 LLM 专家视为模型权重流形上的一个 PSO 粒子，仅使用 200 个样本，就在 9 个数据集上相对 12 项基线取得**平均 13.3% 的增益**。**SwarmPrompt**（ICAART 2025）把 PSO 与灰狼优化混合用于提示优化。**AMRO-S**（arXiv:2603.12933）则采用受 ACO 启发的信息素专家机制完成多智能体 LLM 路由——实现 **4.7 倍加速**，提供可解释的路由证据，并通过质量门控的异步更新把推理与学习解耦。本课会在提示参数空间上实现 PSO，并把 ACO 用于智能体路由，分析这些经典算法为何适合 LLM 时代，以及它们何时不适用。

**Type:** 学习 + 构建
**Languages:** Python（标准库）
**Prerequisites:** 阶段 16 · 09（并行群体网络），阶段 16 · 14（共识与 BFT）
**Time:** 约 75 分钟

## 问题

你有一条提示，在任务评估中得到 62% 的分数，希望进一步改进它。最朴素的做法是不使用梯度、靠人工反复调整，但这种方法难以扩展。强化学习需要奖励信号和足够多的 rollout 才能训练。也无法真正对提示进行反向传播——提示是离散字符串，不是可微参数。

经典仿生优化——用于连续搜索空间的 PSO、用于路径选择的 ACO——正是为这种场景设计的：无需梯度、基于群体，而且单次评估成本低。让 LLM 负责无梯度搜索步骤，就能得到一种出人意料地实用的优化器。

同样的模式也适用于多智能体系统中的智能体*路由*。ACO 风格的信息素轨迹会记录哪类任务由哪个智能体处理得最好，让路由器利用这些轨迹，同时让信息素逐渐衰减，以便重新发现路由。

## 概念

### PSO 回顾（Kennedy 与 Eberhart，1995）

粒子群优化（Particle Swarm Optimization）：在连续搜索空间中维护一组粒子。每个粒子都有位置 `x_i` 和速度 `v_i`。每次迭代执行：

```
v_i <- w * v_i + c1 * r1 * (p_best_i - x_i) + c2 * r2 * (g_best - x_i)
x_i <- x_i + v_i
evaluate fitness(x_i)
update p_best_i if improved
update g_best if global best
```

其中，`p_best` 是粒子自己的历史最佳解，`g_best` 是整个群体的最佳解，`w, c1, c2` 分别是惯性权重、认知权重与社会权重，`r1, r2` 是随机因子。

### 在 LLM 输出上使用 PSO——LMPSO

arXiv:2504.09247 将 PSO 适配到 LLM 生成的结构化输出，例如数学表达式与程序。每个粒子都是一个候选输出；速度则是一条*提示*，描述如何把当前输出朝个体最佳与全局最佳方向修改。LLM 根据速度提示生成新输出。速度的“惯性”由类似“进行小幅增量修改”的提示来表达。

这种方法在以下条件下效果较好：
- 输出是结构化的（可以解析和评估）。
- 适应度可以自动计算（运行测试、算术求值）。
- 群体规模较小（约 10–30 个粒子），使 LLM 总调用量保持可控。

当适应度需要人工审查时，它的效果较差——每轮迭代的成本会高得无法承受。

### 模型群体

arXiv:2410.11163 把 PSO 从输出层推进到*模型*层。每个“粒子”都是一个专家 LLM（参数）。群体通过无梯度更新，让参数向集体最优方向移动。报告结果是：每次迭代仅使用 200 个样本，在 9 个数据集上相较 12 项基线平均提升 13.3%。

核心洞见是：LLM 专家模型已经位于共享参数流形中的邻近位置（适配器权重、LoRA 增量）。在这个低维子空间上使用 PSO，既便宜又有效。

### ACO 回顾（Dorigo，1992）

蚁群优化（Ant Colony Optimization）：蚂蚁在图中移动，每条路径都带有信息素轨迹。蚂蚁移动到某条边的概率按信息素强度加权。完成任务的蚂蚁根据解的质量沉积信息素，而信息素会随时间衰减。

### AMRO-S——用于智能体路由的 ACO

arXiv:2603.12933 使用 ACO 完成多智能体路由。每种任务类型都是一个“目的地”，每个智能体都是一条可能路线。产生优质输出的路线会得到更强的信息素。关键贡献包括：

- **可解释的路由证据。** 信息素强度是人类可读的信号。
- **质量门控的异步更新。** 只有质量检查通过后才更新信息素，从而把推理与学习解耦。
- 在多智能体路由基准上实现 **4.7 倍加速**。

质量门很重要：没有它，速度快却经常出错的智能体也会积累信息素，系统最终会锁定错误路线。

### 何时将 PSO / ACO 用于 LLM

**适合使用 PSO 的情况：**
- 搜索空间是连续的，或能映射为连续参数（提示嵌入、LoRA 权重、数值型生成参数）。
- 适应度计算便宜且可自动化。
- 群体规模可以保持较小（10–30）。

**适合使用 ACO 的情况：**
- 面对的是路由或路径选择问题。
- 决策会随时间强化（相同任务类型反复出现）。
- 路由决策需要可解释证据。

**以下情况不应使用二者：**
- 适应度需要人工审查（每轮成本过高）。
- 搜索空间离散且具有 PSO 无法覆盖的组合性质（应改用遗传算法）。
- 实时决策有严格延迟要求（与单遍启发式方法相比，PSO/ACO 收敛较慢）。

### 仿生算法为何仍能胜出

基于梯度的方法需要可微信号。LLM 输出和路由决策并非天然可微。伪梯度方法（通过强化学习训练的路由器、DPO 风格的提示调优器）虽然有效，却需要昂贵训练。

PSO 与 ACO 只需要一个*评估器*函数。只要能够为候选输出或路由决策评分，就能在该空间中进行优化。这显著降低了适用门槛。

### 实际限制

- **群体预算。** N 个粒子 × T 次迭代 × 单次评估成本。若每次 LLM 评估约为 0.02 美元，一个包含 20 个粒子并运行 50 次迭代的 PSO 约需 20 美元，应提前规划。
- **探索与利用。** 信息素衰减率与 PSO 惯性体现这种权衡；衰减过快会忘记解，衰减过慢则会困在早期局部最优。
- **灾难性漂移。** 当适应度地形发生变化（出现新的数据分布）时，两种算法都可能在收敛后再次发散。应监控最佳适应度的稳定性。

## 动手构建

`code/main.py` 实现：

- `LMPSO`——在数值型提示参数（temperature、top_k 权重）上运行 PSO。每个粒子的“LLM 生成”由脚本化适应度函数模拟。算法运行 30 次迭代，并展示 g_best 的收敛过程。
- `AMRO_S`——ACO 风格路由。包含 3 个智能体、4 种任务类型、一张信息素矩阵和 100 个已路由任务。它会随时间打印“任务类型 → 智能体选择”分布，以展示轨迹形成过程。
- 对比：在相同任务流上比较随机路由与 ACO 路由，并测量质量和延迟。

运行：

```
python3 code/main.py
```

预期输出：
- LMPSO：在 30 次迭代中，g_best 适应度从随机水平提升到接近最优。
- AMRO-S：信息素表稳定到每种任务类型的正确智能体上；ACO 路由在质量上比随机路由高约 30%–40%，同时因重试更少而降低延迟。

## 交付成果

- **从小规模开始。** 使用 10–20 个粒子和 20–50 次迭代。只有收敛曲线显示明确增益时才扩大规模。
- **记录每次迭代的信息素或 g_best。** 没有轨迹时，调试群体优化器非常痛苦。
- **为更新设置质量门。** 尤其是 ACO 路由：速度快但错误的智能体不能积累信息素。
- **分布漂移时重置衰减。** 评估分布变化后，旧信息素已经过时；应重置，或暂时把衰减率提高一倍。
- **限制单轮成本。** 输出每轮成本指标。如果 PSO 每轮花费 500 美元却只提升 0.5%，就不具备上线价值。

## 练习

1. 运行 `code/main.py`，观察 LMPSO 收敛。把群体规模分别设为 5、10、20、50。规模达到多少后，收敛时间不再改善？
2. 实现一个“灾难性漂移”实验：在第 30 次迭代后改变适应度函数。PSO 适应新函数需要多久？重置 `p_best` 是否有帮助？
3. 为 AMRO-S 添加质量门：只有评估分数 > 0.7 的运行才能沉积信息素。与无门控版本相比，收敛有何变化？
4. 阅读 LMPSO（arXiv:2504.09247）。把论文中的“以提示表示速度”映射回数值速度。模拟中丢失了什么，又保留了什么？
5. 阅读 AMRO-S（arXiv:2603.12933）。实现带异步信息素更新的解耦“推理快速路径”。这会如何改变持续负载下的系统延迟？

## 关键术语

| 术语 | 人们通常怎么说 | 实际含义 |
|------|----------------|------------------------|
| PSO | “粒子群优化” | Kennedy-Eberhart 1995 年提出的基于群体、无梯度优化器。 |
| ACO | “蚁群优化” | Dorigo 1992 年提出的、通过信息素轨迹优化路径/路由的方法。 |
| LMPSO | “使用 LLM 生成的 PSO” | arXiv:2504.09247；速度由提示表示，LLM 负责生成候选项。 |
| Model Swarms | “在专家权重上运行 PSO” | arXiv:2410.11163；在模型参数子空间上进行无梯度更新。 |
| AMRO-S | “用于智能体路由的 ACO” | arXiv:2603.12933；在任务类型 × 智能体矩阵上维护信息素。 |
| p_best / g_best | “个体最佳 / 全局最佳” | 每个粒子以及整个群体迄今发现的最佳解。 |
| 信息素 | “路由记忆” | 边上的强度；随时间衰减，并在高质量结果上沉积。 |
| 质量门控更新 | “只从优质运行中学习” | 只有质量检查通过时才沉积信息素。 |
| 灾难性漂移 | “分布漂移” | 适应度地形发生变化；旧 p_best 与信息素变得过时。 |
