# Chameleon 与早期融合的纯词元多模态模型

> 此前介绍的每种 VLM 都把图像与文本分开处理。视觉词元来自视觉编码器，流入投影器，再在大语言模型内部与文本相遇；视觉与文本词表从不重叠。Chameleon（Meta，2024 年 5 月）提出：如果让它们重叠会怎样？训练一个 VQ-VAE，把图像转换为来自共享词表的离散词元序列。于是，每份多模态文档都变成一条序列——文本词元与图像词元交错，只使用一个自回归损失。副作用是：模型可以生成混合模态输出——在一次推理调用中交替输出文本与图像词元。本课会解读早期融合观点，并端到端构建一个玩具版本。

**Type:** 构建
**Languages:** Python (stdlib, VQ-VAE tokenizer + interleaved decoder)
**Prerequisites:** 第 12 阶段 · 第 05 课、第 8 阶段（生成式 AI）

## 学习目标

- 解释共享词表 + 单一损失为何会改变模型能够完成的任务。
- 描述 VQ-VAE 如何把图像离散化为与 Transformer 下一词元目标兼容的序列。
- 说出 Chameleon 的训练稳定性技巧：QK-Norm、Dropout 位置、LayerNorm 顺序。
- 比较 Chameleon 与 BLIP-2 的 Q-Former 方案，并说明各自适合什么情况。

## 问题

基于适配器的 VLM（LLaVA、BLIP-2、Qwen-VL）把文本与图像视为两种不同事物。文本词元经过 `embed(text_token)`，图像则经过 `visual_encoder(image) → projector → ... pseudo_tokens`。模型有两条输入路径，在中途才汇合。

这会导致三个结果：

1. 大语言模型只能接收图像，无法输出图像。输出仅限文本。
2. 混合模态文档（像文章那样交替出现段落与图像）很难处理——你必须在模型外解析多模态输入，或串联多次生成。
3. 分布不匹配。视觉词元和文本词元位于隐藏空间的不同区域，会产生微妙的对齐问题。

Chameleon 拒绝接受这个前提：图像不过是来自共享词表的离散词元序列。用一个损失、一个自回归解码器，在交错文档上训练模型，就能自然获得混合模态生成能力。

## 概念

### 使用 VQ-VAE 作为图像分词器

这里的分词器是向量量化变分自编码器，其架构包括：

- 编码器：CNN + ViT，把图像映射为空间特征图，例如 32x32 个 256 维特征。
- 码本：由 K 个学习向量组成的词表（Chameleon 使用 8192 个），每个向量也是 256 维。
- 量化：对每个空间特征，按 L2 距离查找最近的码本条目，并用相应整数索引替换连续特征。
- 解码器：把量化特征还原为像素的 CNN。

训练使用 VAE 重建损失 + 承诺损失 + 码本损失。码本索引构成图像的离散字母表。

对于 Chameleon，一幅图像会变成 32*32 = 1024 个词元，它们来自大小为 8192 的词表。将这些词元与文本词元（来自大语言模型的 BPE 词表，例如 32000 个）拼接，最终词表大小为 40192。Transformer 只看到一条序列、一个损失。

### 共享词表

Chameleon 的词表结合了文本词元、图像词元和模态分隔符，每个词元都有唯一 ID。输入嵌入层把每个 ID 映射为 D 维隐藏向量，输出投影则把隐藏状态映射回词表 Logit。Softmax 选择下一个词元，而不关心它属于哪种模态。

分隔符很重要：`<image>` 和 `</image>` 标签包围图像词元序列。生成时，如果模型输出 `<image>`，下游软件就知道接下来的 1024 个词元是 VQ 索引，需要交给解码器渲染为像素。

### 混合模态生成

推理就是在共享词表中预测下一个词元。例如输入提示“画一只猫并描述它”，Chameleon 会输出：

```
<image> 4821 1029 2891 ... (1024 image tokens) </image>
The cat is orange, sitting on a windowsill...
```

模型会自主选择顺序——可以先图像后文本、先文本后图像，也可以交错输出。解码器相同，损失也相同。

相比之下，基于适配器的 VLM 只能生成文本。Chameleon 重新打开了“模型可以输出哪些模态”这个问题。

### 训练稳定性——QK-Norm、Dropout 与 LayerNorm 顺序

早期融合训练在大规模下并不稳定。Chameleon 论文记录了三项技巧：

- QK-Norm。在注意力内部、计算点积之前，对查询投影与键投影应用 LayerNorm，防止深层网络中的 Logit 大小爆炸。2024 年之后的多个大型模型都采用了这种方法。
- Dropout 位置。在每次残差相加之后执行 Dropout，而不只是放在注意力层和 MLP 之后。图像词元的梯度可能占据主导，因此需要更强的正则化。
- LayerNorm 顺序。在残差分支上使用 Pre-LN（标准做法），并在最后一个块的跳跃连接上额外添加一层 LN，以稳定末层梯度流。

没有这些技巧时，34B 参数的 Chameleon 会在多个检查点上训练发散；使用这些技巧后，它能够收敛。训练配方与架构本身一样，都是这项工作的贡献。

### 分词器的重建上限

VQ-VAE 是有损的。对于大小为 8192 的码本，以及每幅 512x512 图像 1024 个词元，重建 PSNR 的上限约为 26～28 dB。生成的图像足以辨认，但明显不如连续空间扩散模型（Stable Diffusion 3 可达到 32 dB 以上）。

分词器就是瓶颈。更好的分词器（MAGVIT-v2、IBQ、SBER-MoVQGAN）可以抬高这个上限。Emu3（第 12.12 课）仅依靠更好的分词器，就达到了 SDXL 级别的生成质量。

### Chameleon 与 BLIP-2 / LLaVA 对比

Chameleon（早期融合，共享词表）：
- 一个损失，一个解码器。
- 可以生成混合模态输出。
- 分词器决定质量上限。
- 成本高：生成每幅图像时，推理路径都要运行 VQ-VAE 解码器。

BLIP-2 / LLaVA（后期融合，独立双塔）：
- 视觉输入，纯文本输出。
- 复用预训练大语言模型。
- 理解任务不受分词器瓶颈限制。
- 成本低：只需一次前向传播。

根据任务选择。如果需要生成图像，选择 Chameleon 家族；如果只需要理解，适配器式 VLM 更简单，也能复用更多预训练计算。

### Fuyu 与 AnyGPT

Fuyu（Adept，2023）采用相关方法：完全跳过独立视觉编码器，把原始图像块当作词元，经由大语言模型输入投影送入模型，不使用分词器。它比 Chameleon 更简单，但失去了共享词表所带来的输出生成能力。

AnyGPT（Zhan 等，2024）把 Chameleon 扩展到四种模态：文本、图像、语音与音乐。每种模态都使用相同的 VQ-VAE 技巧，并共享一个 Transformer，实现任意模态到任意模态的生成。第 12.16 课会更深入地介绍。

## 投入使用

`code/main.py` 构建了一个端到端的玩具早期融合模型：

- 一个微型 VQ-VAE 风格量化器，把 8x8 图像块映射到码本索引（K=16）。
- 一个共享词表：（文本 ID 0..31）+（图像 ID 32..47）+（分隔符 48、49）。
- 一个玩具自回归解码器（Bigram 表），在合成说明文字 + 图像词元序列上训练。
- 给定提示词后，输出交替文本 + 图像词元的采样循环。

代码刻意把 Transformer 简化为 Bigram，让你能端到端跟踪信号流。

## 练习

1. Chameleon 使用 K=8192 个码本条目，每幅 512x512 图像使用 1024 个词元。估算它相对于 24 位 RGB 图像的压缩率。它是否有损？损失有多大？

2. 一幅 4K 图像（3840x2160）按照相同 VQ-VAE 密度会产生多少图像词元？Chameleon 风格模型能否在一次推理调用中生成 4K 图像？上下文、分词器质量与 KV 缓存中，哪一个会先成为瓶颈？

3. 使用纯 Python 实现 QK-Norm。给定 64 维查询与键，展示执行 LayerNorm 前后的点积。为什么控制大小对于深层网络很重要？

4. 阅读 Chameleon 第 2.3 节关于训练稳定性的内容。说明在没有 QK-Norm 的情况下，论文观察到的 34B 模型确切失效模式。“范数爆炸”会呈现什么迹象？

5. 扩展玩具解码器，使其在给定纯文本提示词后输出混合模态响应。在训练数据分布为 60% 文本优先、40% 图像优先的情况下，测量模型选择先图像后文本与先文本后图像的频率。

## 关键术语

| 术语 | 人们常说 | 实际含义 |
|------|-----------------|------------------------|
| 早期融合 | “统一词元” | 从第一步起就把图像转换为共享 Transformer 词表中的离散词元 |
| VQ-VAE | “图像分词器” | CNN + ViT + 码本，将图像映射为 Transformer 可以预测的整数索引 |
| 共享词表 | “一本词典” | 同一个词元 ID 空间，覆盖文本 + 图像 + 模态分隔符 |
| QK-Norm | “注意力稳定器” | 在查询与键执行点积之前应用 LayerNorm，防止范数爆炸 |
| 混合模态生成 | “文本 + 图像输出” | 在一次推理中自主生成相互交错的文本与图像词元 |
| 码本大小 | “K 个条目” | VQ-VAE 可量化到的离散向量数量；在压缩率与保真度之间取舍 |
| 分词器上限 | “重建极限” | 解码 VQ 词元能够达到的最佳 PSNR；它限定模型的图像质量 |
