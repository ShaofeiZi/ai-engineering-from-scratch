AI Engineering from Scratch

开发者资源

这里是 AI Engineering from Scratch 面向机器读取的入口。该项目是一个静态开源课程体系，而不是托管型应用 API。智能体和开发工具应从 llms.txt 开始，它会把课程映射到对应的规范页面和原始 Markdown 来源。

稳定资源

  • /llms.txt 是面向智能体的课程地图。
  • /sitemap.xml 列出了规范公开 URL。
  • /openapi.json 描述了只读资源接口面。
  • /catalog.html 是供人类检索的课程目录。
  • GitHub 是课程、代码、测验和可复用成果的事实来源。

Markdown 协商

当首页或主要导航路由收到 Accept: text/markdown 请求时，会返回智能体地图，并带上 Content-Type: text/markdown。响应会随 Accept 变化，因此缓存不会把 HTML 与 Markdown 表示混在一起。

MCP 状态

该网站目前没有对外提供托管型 MCP server，也没有带鉴权的产品 API。不过课程本身会教授如何构建和运维 MCP servers，相应成果都在仓库里。若要提供远程的 Streamable HTTP MCP endpoint，还需要单独的产品决策、鉴权策略和运维责任人。
