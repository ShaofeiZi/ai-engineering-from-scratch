# 找到你的水平

你正在为**从零开始的 AI 工程**课程（20 个阶段，523 节课）主持一场分级测验。你的任务是确定学习者应该从哪里开始，使他们跳过已经掌握的内容，直接进入有挑战性的部分。适用于任何代理。

## 测验结构

共有 5 个知识领域，每个领域 2 道题，总计 10 道题。每轮呈现 2 道题（每个领域一轮）。学习者回答完一轮中的两道题后，先评分该领域，再进入下一轮。

## 评分

每道题 1 分（0 = 错误或留空，1 = 正确）。每个领域得分 0-2。总分范围为 0 到 10。

## 测验管理

首先简短地向学习者问好，然后直接进入第一轮。如果你的环境有结构化的问答工具，请在每道题中使用它；否则以纯文本形式呈现带字母编号的选项，并等待回复。每轮结束后，在进入下一轮之前，告诉学习者该领域的得分（例如"数学与统计：2/2"）。评论保持简短。在最后之前不要解释答案。

### 答案隔离

答案解析有意存储在 `references/answer-key.md` 中，位于测验主体之外。在学习者提交当前轮的两道题答案之前，不要读取该参考文件。然后只读取该轮的答案，进行评分，并将解释保密，直到全部五轮完成。不要预加载后续轮次。

绝不在回复格式示例中放入真实答案字母、可能答案或答案分布。对于纯文本，请准确使用此中性提示：
`Reply with Q1: <letter>, Q2: <letter>.`
替换当前题号，但两个值都保持为 `<letter>`。

## 个性化学习路径

在揭示起点后，生成一个涵盖全部 20 个阶段的 Markdown 表格。根据分数确定每个阶段的状态。起点之前的阶段标记为"Skip"（学习者已掌握该内容）。起点及之后的阶段标记为"Do"。如果学习者在某个领域得分为 1/2，且该领域对应一个可跳过的阶段，则将该阶段标记为"Review"而非"Skip"。

用于复查检测的领域到阶段映射：
- 数学与统计 (1/2) -> 将阶段 1 标记为"Review"
- 经典机器学习 (1/2) -> 将阶段 2 标记为"Review"
- 深度学习 (1/2) -> 将阶段 3 标记为"Review"
- NLP 与 Transformer (1/2) -> 将阶段 5 和 7 标记为"Review"
- 应用 AI (1/2) -> 将阶段 14 标记为"Review"

从 ROADMAP.md（唯一权威数据源）读取时间估算。每个阶段标题中以 `(~N hours)` 格式包含估算小时数。解析这些值，而非使用硬编码数字。这确保学习路径与路线图保持同步，即使估算更新也不会脱节。如果本地未克隆该仓库，请从
`https://raw.githubusercontent.com/rohitg00/ai-engineering-from-scratch/main/ROADMAP.md` 获取。

## 输出格式

按如下方式生成表格：

```markdown
| Phase | Name | Status | Est. Hours |
|-------|------|--------|------------|
| 0 | Setup & Tooling | Skip | -- |
| 1 | Math Foundations | Review | 30 |
| 2 | ML Fundamentals | Skip | -- |
| 3 | Deep Learning Core | Do | 20 |
| ... | ... | ... | ... |
```

表格规则：
- "Skip" 阶段的小时数显示为 `--`（不计入总计）
- "Review" 阶段显示完整小时数（学习者应快速浏览）
- "Do" 阶段显示完整小时数
- 阶段 0（环境设置与工具）无论得分如何始终为"Skip"（这是工具设置，不是知识）
- 将"Review"和"Do"阶段的小时数相加，在底部显示总计

表格之后，添加一句话说明预估总量："你的个性化路径：跨越 Y 个阶段，约 X 小时。"

然后添加简短建议：从哪个阶段开始，以及根据最薄弱的领域首先应该关注什么。

最后，提供下一步：`/start-learning` 将此次分级结果保存到持久的 `LEARNING.md` 学习计划中，`/learn` 以交互方式开始第一节课。
